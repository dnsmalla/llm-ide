# Design tokens

`tokens.json` is the one source for the app's look: the three themes (colour
roles), spacing, radii, the type scale and the category hues.

Generated by `scripts/gen-design-tokens.mjs` (`make design-tokens`):

| Output | Consumer |
|---|---|
| `mac/Sources/LlmIdeMac/Core/Platform/ThemeTokens.swift` | Mac app. `Theme.swift` builds `Color` and `Font` from these plain values. |
| `tokens.css` | CSS custom properties, `--tok-*`. `:root` is the default (dark) theme; each `[data-theme="<id>"]` block overrides the colours. For the Chrome extension and the System view (copies written by the same generator). |
| `ui/kit/src/styles/tokens.generated.css` | The same CSS plus web-only variables (`--tok-type-sans-family`, a cross-platform mono stack, text-style sizes, explicit weights). Shipped by the shared React package `ui/kit`, which the Tauri desktop, the phone PWA and the relay web view consume. |
| `ui/kit/src/themes.generated.ts` | Theme ids and names for the kit's theme switcher. |

Edit `tokens.json`, then run `make design-tokens`. `make contract-gates` runs
`node scripts/gen-design-tokens.mjs --check` and fails while an output is stale.

Colour values are `{"rgb":[r,g,b]}` (sRGB, 0..1) or `{"white":a}` / `{"black":a}`
(`Color.white` / `Color.black` at opacity `a`).

`textStyle` entries (`callout`, `caption`) follow the platform's text style, so
they carry no fixed size in CSS; only their weight is emitted.

Status, diff and gutter colours are not stored here: they map to the colour
roles in code (for example `success` is `accent3`), so changing a role updates
them too.
