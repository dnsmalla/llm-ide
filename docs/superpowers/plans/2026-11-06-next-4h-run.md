## Rules (each one is a defect a review found today)

1. **Copy the plan's code and tests verbatim.** Keep its comments and its line breaks. Never squash a file onto
   one long line, never shorten a test name, never drop an `assert`. Five tasks in a row lost plan tests this way.
2. **Do every step of the task, including the edits to existing files.** Skipped steps found today: the iPhone view
   that makes a screen reachable (`SourceRootSection()`), the Info.plist ATS block, the MEGA route's half of a
   storage switch, a docs section, a live-test file. Before committing, re-read the task's **Files** list and
   tick each path against `git diff --stat`.
3. **Security rules are not optional extras:** every setup route runs under `withUserLock` (409 `SYNC_BUSY`);
   switching storage kind clears every other kind's secrets; tokens and secrets are server-internal vault keys and
   never appear in a response, log or error text; OAuth `state` is random, single-use and checked; refresh tokens
   are persisted before the new access token is used; browser and iPhone network calls go only to the exact hosts
   the plan names and never follow a redirect off-host.
4. **iPhone:** every new app-target `.swift` file goes into `ios_app/MyApp.xcodeproj/project.pbxproj` (CI fails
   otherwise; SharedProtocol files need no entry). Info.plist: change only the keys the task names; keep the ATS
   rationale comment; `plutil -lint` it.
5. **Web CSP:** a new host goes into all four copies of `connect-src` (`web/vite.config.ts`, `web/scripts/serve.mjs`,
   `deploy/vps/llm-ide.com.nginx`, the Caddy line in `web/DEPLOY.md`) and into the code's allowed-host list; the
   scaffold test checks they agree.
6. **API version bump checklist** (only if a task adds or changes a route): `SERVER_API_VERSION` + one changelog
   line in `extension/server.mjs` (no literal `\n`), `ALL_ENDPOINTS` (public OAuth callbacks go in `PUBLIC_PATHS`
   only), `APP_API_VERSION` in `ui/screens/shell/core-api-floor.ts`, the version line in `docs/spec/api-server.md`
   and `docs/spec/cross-cutting.md`, a skip entry in `mac/Sources/APIContractLab/Routes.swift`, the schema and
   fixture, then `node scripts/http-inventory.mjs`.
7. **Plan tracking:** after you tick a box in `docs/superpowers/MASTER-PLAN.md`, run
   `node scripts/plan-status.mjs --fix`; the push gate fails on drift otherwise.
8. **Stage only your own paths** (`git add <paths>`, never `git add -A`). Conventional Commits, one concern each.
