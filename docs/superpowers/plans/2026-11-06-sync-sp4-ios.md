# Sync SP4: iPhone app sync tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With the desktop off, the native iPhone app reads the latest encrypted snapshots of the desktop's chats, meetings (with notes), plans/tasks and usage from the user's dedicated MEGA folder. It shows how old they are and queues chat prompts in the inbox. The replies appear once the desktop is back.

**Architecture:** Everything that can be tested without a phone goes in the `ios_app/SharedProtocol` package and is checked by `make test-shared-protocol`: the sync v1 envelope and the device side of enrollment (CryptoKit), the snapshot, request and reply models, the device state machine (`SyncDevice`), and a minimal HTTPS MEGA client (`MegaClient`, CommonCrypto + CryptoKit). Their inputs are the shared vectors and a fixture produced by running the **real megajs 1.3.10** (the desktop's MEGA client) against a fake MEGA API. The app adds one `SyncStore` (Keychain, Secure Enclave keys, foreground refresh) and reuses the History tab: when the desktop is unreachable, the tab is fed from the snapshot and shows "Last updated …, desktop offline".

**Tech Stack:** Swift 5.9 package (`swift-tools-version: 5.9`, iOS 16 / macOS 14), CryptoKit (P-256 ECDSA/ECDH, AES-GCM, HKDF, HMAC, SHA-256, `SecureEnclave`), CommonCrypto (AES-128 ECB/CBC/CTR and PBKDF2-HMAC-SHA512, for MEGA's own format only), Security (Keychain, `SecRandomCopyBytes`), swift-testing, SwiftUI (iOS 16). Node 20 + `megajs` 1.3.10, already pinned in `extension/package.json`, used only to generate the fixture.

**Spec:** `docs/superpowers/specs/2026-11-05-box-encrypted-sync-design.md` (§3 layout, §4 formats, §5 keys, §6 ceiling, §7 ordering, §8.3 MEGA, §11 privacy, §13 tests, §14 SP4 row, §15 Q8), ADR `docs/decisions/0020-box-encrypted-sync.md`. Read with:
- the SP2 plan `docs/superpowers/plans/2026-11-06-sync-sp2-enrollment.md`. Its "Device contract" section is normative for this plan; SP2 Task 1 copied it into `schema/sync/v1/README.md` "Enrollment (device contract)".
- the Node reference device `extension/tests/helpers/sync-device.mjs`. SP4 implements exactly what it does, in Swift.
- the desktop code that writes what the device reads: `extension/routes/sync/producer.mjs`, `kinds.mjs`, `consumer.mjs`, `enroll.mjs` and `extension/connectors/sync-store/mega.mjs`.

## Global Constraints

- **Mac app frozen:** no change under `mac/Sources/`. `mac/Package.swift` links `ios_app/SharedProtocol`, so every new SharedProtocol type also compiles into the Mac app. `cd mac && swift build` must still pass. The Mac already declares `SyncError` and `SyncProvider`, so never declare a type with either name. Every new top-level type in SharedProtocol starts with `Sync` or `Mega` and has none of those two names.
- **Depends on SP2 Tasks 1 and 2** (commits `bc5d2400`, `a4973a1f`: `extension/core/sync-enroll.mjs`, the `enroll` vectors, `routes/sync/enroll.mjs`). SP2 Tasks 3 to 7 may still be in progress. Never edit their files (`extension/tests/sync-enroll-malicious.test.mjs`, `tests/helpers/tamper-store.mjs`, `routes/sync/registry.mjs`, `ui/screens/settings/**`). The one shared file this plan changes is `scripts/sync-vectors.mjs` (Task 1, additive).
- **Malicious storage model** (SP2 Global Constraints, unchanged): MEGA, or anyone holding the dedicated account's login, can read, replace, replay or delete any file at any time. A value read from storage enters a trust decision only when it is authenticated by a key pinned from the QR: the desktop signing key (via `sfp`) or `es`. Verify before decrypt. Every refusal uses the Node error code (`SyncCryptoError.code`). The vector codes are the contract: if a Swift test reports a different code, fix the Swift code, never the vector.
- **Device rules** (device contract 4 to 6): read only `<sid>/d/<dir>/` after enrollment. Write only `in/<13-digit ms>-<requestId>.bin` there and the one claim under `e/<slot>/`. Never create `<sid>` or `d/<dir>`: a deleted device folder means "removed", and the device stops. Queue only `chat.send`. Text is 1 to 4,000 UTF-16 units and the sealed file is at most 65,536 bytes (`consumer.mjs LIMITS`).
- **Keys:** device ECDH and ECDSA are P-256. They live in the Secure Enclave when `SecureEnclave.isAvailable` (non-extractable; only the SE-bound blob is stored). Otherwise (Simulator) they are software keys in the Keychain. Every Keychain item is `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` and never synchronizable. `es` and the `E(*)` keys exist only in memory and are dropped once the wrap verifies. They are never written to the Keychain, to disk or to a log.
- **MEGA password (spec §8.3 item 4, Q8 default):** typed once and used only for the login call, then the field is cleared. It is **never stored**. The resumable session (session id + account master key, as powerful as the password, spec §8.3) is stored in the Keychain (ThisDeviceOnly). If MEGA refuses the session (`ESID`), the app asks for the password again. The account is the dedicated LLM-IDE account; 2FA is unsupported (`EMFAREQUIRED -26` → plain-words guidance).
- **No MEGA SDK, no new dependency.** The MEGA client uses only Foundation, CryptoKit, CommonCrypto and Security. Rationale in "Decision: MEGA client on iOS" below.
- **Refresh:** no long-poll, no background fetch, no push. Refresh on foreground, on pull-to-refresh, after queueing, and every 60 s while the app is in the foreground with a prompt pending.
- **Never log** keys, `es`, `dir`, the session id, the master key, the MEGA email or password, prompt text or decrypted content. The app has no logger for sync; do not add `print` calls.
- **Uncommitted iOS edits from another workstream:** at plan time `ios_app/MyApp.xcodeproj/project.pbxproj` and `ios_app/MyApp/Supporting/Info.plist` had uncommitted changes that are not ours. Read the current file before editing. Never revert their hunks. Stage only your own hunks (`git add -p <file>`). If a hunk cannot be separated, stop and ask.
- **Build gates** (as `.github/workflows/ios-ci.yml`): `make test-shared-protocol`, and the unsigned device build `cd ios_app && xcodebuild -project MyApp.xcodeproj -target MyApp -configuration Debug -sdk iphoneos CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO SYMROOT="$TMPDIR/ios-build" build`. ## Decision: MEGA client on iOS (grounded)

Spec §8.3 item 4 and §14 assumed "MEGA iOS SDK, `fastLogin` from a Keychain session dump". This plan replaces that with a **minimal HTTPS client in SharedProtocol**. The reasons follow.

| | Official SDK (`meganz/sdk`) | Minimal HTTPS client (chosen) |
|---|---|---|
| License | BSD-2 (spec §8.3). It also brings six prebuilt XCFrameworks (libcryptopp, libcurl, libsodium, libuv, libmediainfo, libzen) downloaded from a MEGA S3 URL, per its root `Package.swift`, read 2026-11-06. | Our code. megajs (MIT) is the reference read for porting. |
| Build | SwiftPM package (iOS 15+), compiles the whole C++ SDK (C++17, `ENABLE_CHAT`, libuv). CI build time not measured. | About 600 lines of Swift; builds in seconds. |
| Size | Not measured; C++ core plus six binary frameworks. | Negligible. |
| Where it can live | Only in the app target. In SharedProtocol it would also link into the **frozen Mac app**. It is then untestable by `make test-shared-protocol` and invisible to CI's SharedProtocol job. | SharedProtocol, unit-tested with swift-testing on macOS CI. |
| App key | The SDK constructor needs an app key (`API_EAPPKEY`, spec §8.3); obtaining one is not grounded. | None. megajs sends none, and the desktop already works this way. |
| Export compliance | It bundles non-OS crypto (Crypto++, libsodium) → `ITSAppUsesNonExemptEncryption` would very likely become `YES`, with paperwork. | OS crypto only (CryptoKit, CommonCrypto). Keeps the existing `false` arguable (see Task 10, flagged for the user). |
| Protocol risk | Official, maintained by MEGA. | Unofficial: the same risk the desktop already accepted with megajs. Mitigated by a fixture made by **running megajs itself** (Task 6), so the Swift client produces megajs's exact bytes for login, folder, upload and download. An opt-in live test covers the rest. |

What the device needs from MEGA is small: log in (v2 accounts only), resume a session, list the tree, download a file of at most 1 MiB + 4 KiB, upload a file of at most 64 KiB, create `in/` and `e/<slot>/`. It never deletes: one writer per file, spec §3. Our signed envelope is the security boundary, and MEGA's own encryption is defence in depth (spec §8.3 item 6). That is why the small port wins.

Spec §8.3 item 4 and §14 are amended in Task 10. The session the client keeps (sid + master key) has the same power as the SDK's `dumpSession()`, so the custody rule is unchanged.

```js
  const k = S.deviceKeys(hex(sync.rootHex), sync.ids, sync.epoch);
  const keyOf = { request: k.request, reply: k.reply, snapshot: k.snapshot, manifest: k.manifest };
  for (const n of sync.typedNegatives) {
    const env = structuredClone(sync[n.target].env);
    const m = n.mutate;
    let key = keyOf[n.target]; let expect = {}; let currentEpoch = 0;
    if (m.op === 'flip') { const x = b(env[m.field]); x[0] ^= 1; env[m.field] = x.toString('base64url'); }
    else if (m.op === 'truncate') env[m.field] = b(env[m.field]).subarray(0, -1).toString('base64url');
    else if (m.op === 'set') env[m.field] = m.value;
    else if (m.op === 'expect') expect = { [m.field]: m.value };
```

```swift
import Foundation
import CryptoKit
import Security

// MARK: - Sync v1 envelope, device side
//
// schema/sync/v1 = relay v1 bytes (schema/relay/v1) plus the sync purposes. A port of extension/core/sync-envelope.mjs:
// canonical enc, padding buckets, AES-256-GCM with AAD = enc(header ++ [extra]), ECDSA P-256 P1363 over
// "llmide/<purpose>/v1\0" || enc(header ++ [extra, nonce, ct]), verify before decrypt. The error codes are the Node
// ones; the shared vectors are the contract.

public struct SyncCryptoError: Error, Equatable, Sendable, CustomStringConvertible {
    public let code: String
    public init(_ code: String) { self.code = code }
    public var description: String { code }
}

public enum SyncB64 {
    public static func encode(_ data: Data) -> String {
        data.base64EncodedString().replacingOccurrences(of: "+", with: "-")
            .replacingOccurrences(of: "/", with: "_").replacingOccurrences(of: "=", with: "")
    }
    /// base64url without padding; nil for any other character (Node's `B64U` check), so `bad_base64` is exact.
    public static func decode(_ s: String) -> Data? {
        guard s.utf8.allSatisfy(isB64uByte) else { return nil }
        var t = s.replacingOccurrences(of: "-", with: "+").replacingOccurrences(of: "_", with: "/")
        while t.utf8.count % 4 != 0 { t += "=" }
        return Data(base64Encoded: t)
    }
    public static func isB64uByte(_ c: UInt8) -> Bool {
        (c >= 0x41 && c <= 0x5a) || (c >= 0x61 && c <= 0x7a) || (c >= 0x30 && c <= 0x39) || c == 0x2d || c == 0x5f
    }
    /// 16 random bytes as base64url, 22 characters: the contract's "Id22".
    public static func newId22() -> String { encode(SyncCrypto.randomBytes(16)) }
}

/// One field of the canonical encoding: u32be length, then u64be (integers) or the UTF-8 / raw bytes.
public enum SyncField: Equatable, Sendable {
    case int(Int), str(String), bytes(Data)
}

public enum SyncEnc {
    public static func enc(_ fields: [SyncField]) -> Data {
        var out = Data()
        for f in fields {
            let v: Data
            switch f {
            case .int(let n): v = withUnsafeBytes(of: UInt64(n).bigEndian) { Data($0) }
            case .str(let s): v = Data(s.utf8)
            case .bytes(let b): v = b
            }
            out.append(contentsOf: withUnsafeBytes(of: UInt32(v.count).bigEndian) { Array($0) })
            out.append(v)
        }
        return out
    }

    public static func decode(_ data: Data, count: Int) throws -> [Data] {
        let b = [UInt8](data)
        var out: [Data] = []
        var off = 0
        while off < b.count {
            guard off + 4 <= b.count else { throw SyncCryptoError("bad_encoding") }
            let n = Int(b[off]) << 24 | Int(b[off + 1]) << 16 | Int(b[off + 2]) << 8 | Int(b[off + 3])
            off += 4
            guard off + n <= b.count else { throw SyncCryptoError("bad_encoding") }
            out.append(Data(b[off..<(off + n)]))
            off += n
        }
        guard out.count == count else { throw SyncCryptoError("bad_encoding") }
        return out
    }
}

public enum SyncPadding {
    public static let buckets = [1024, 4096, 16384, 65536, 262_144, 1_048_576]
    public static let maxFrame = 1_048_576 - 4

    public static func pad(_ body: Data) throws -> Data {
        guard body.count <= maxFrame, let size = buckets.first(where: { $0 >= body.count + 4 }) else { throw SyncCryptoError("frame_too_large") }
        var out = [UInt8](repeating: 0, count: size)
        let n = UInt32(body.count)
        out[0] = UInt8(n >> 24); out[1] = UInt8(n >> 16 & 0xff); out[2] = UInt8(n >> 8 & 0xff); out[3] = UInt8(n & 0xff)
        out.replaceSubrange(4..<(4 + body.count), with: body)
        return Data(out)
    }

    public static func unpad(_ data: Data) throws -> Data {
        let b = [UInt8](data)
        guard buckets.contains(b.count) else { throw SyncCryptoError("bad_padding") }
        let n = Int(b[0]) << 24 | Int(b[1]) << 16 | Int(b[2]) << 8 | Int(b[3])
        guard n <= b.count - 4, b[(4 + n)...].allSatisfy({ $0 == 0 }) else { throw SyncCryptoError("bad_padding") }
        return Data(b[4..<(4 + n)])
    }
}

/// The JSON form written to the store (`Buffer.from(JSON.stringify(env))` on the desktop).
public struct SyncEnvelope: Codable, Equatable, Sendable {
    public var v: Int
    public var purpose: String, userId: String, desktopId: String, from: String, to: String
    public var epoch: Int
    public var session: String
    public var seq: Int
    public var issuedAt: Int
    public var tier: String
    public var nonce: String, ct: String, sig: String
    public var eph: String?

    static let fieldNames: Set<String> = ["v", "purpose", "userId", "desktopId", "from", "to", "epoch", "session", "seq",
                                          "issuedAt", "tier", "nonce", "ct", "sig", "eph"]

    public init(header h: SyncHeader, nonce: String, ct: String, sig: String, eph: String?) {
        v = 1; purpose = h.purpose; userId = h.userId; desktopId = h.desktopId; from = h.from; to = h.to; epoch = h.epoch
        session = h.session; seq = h.seq; issuedAt = h.issuedAt; tier = h.tier
        self.nonce = nonce; self.ct = ct; self.sig = sig; self.eph = eph
    }

    public var header: SyncHeader {
        SyncHeader(purpose: purpose, userId: userId, desktopId: desktopId, from: from, to: to, epoch: epoch,
                   session: session, seq: seq, issuedAt: issuedAt, tier: tier)
    }

    /// A store file → envelope, refusing in Node's order: unknown field, version, purpose, then shape and integers.
    public static func parse(_ data: Data) throws -> SyncEnvelope {
        guard let o = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any],
              Set(o.keys).isSubset(of: fieldNames) else { throw SyncCryptoError("bad_envelope") }
        guard (o["v"] as? Int) == 1 else { throw SyncCryptoError("bad_version") }
        guard let p = o["purpose"] as? String, SyncCrypto.purposes.contains(p) else { throw SyncCryptoError("bad_purpose") }
        guard let env = try? JSONDecoder().decode(SyncEnvelope.self, from: data) else { throw SyncCryptoError("bad_envelope") }
        guard [env.epoch, env.seq, env.issuedAt].allSatisfy({ $0 >= 0 && $0 <= 9_007_199_254_740_991 }) else {
            throw SyncCryptoError("bad_integer")
        }
        return env
    }

    public func data() -> Data { (try? JSONEncoder().encode(self)) ?? Data() }
}

public enum SyncCrypto {
    public static let purposes: Set<String> = ["request", "reply", "snapshot", "manifest", "syncwrap", "enroll", "enrollack"]

    public static func randomBytes(_ n: Int) -> Data {
        var d = Data(count: n)
        let status = d.withUnsafeMutableBytes { SecRandomCopyBytes(kSecRandomDefault, n, $0.baseAddress!) }
        precondition(status == errSecSuccess, "SecRandomCopyBytes failed")
        return d
    }
    public static func sha256(_ d: Data) -> Data { Data(SHA256.hash(data: d)) }
    public static func hex(_ d: Data) -> String { d.map { String(format: "%02x", $0) }.joined() }
    public static func hkdf(_ ikm: Data, salt: Data, info: Data) -> Data {
        HKDF<SHA256>.deriveKey(inputKeyMaterial: SymmetricKey(data: ikm), salt: salt, info: info, outputByteCount: 32)
            .withUnsafeBytes { Data($0) }
    }
    public static func hmac(_ key: Data, _ msg: Data) -> Data {
        Data(HMAC<SHA256>.authenticationCode(for: msg, using: SymmetricKey(data: key)))
    }
    /// Constant time for equal lengths.
    public static func equal(_ a: Data, _ b: Data) -> Bool {
        guard a.count == b.count else { return false }
        var r: UInt8 = 0
        for (x, y) in zip(a, b) { r |= x ^ y }
        return r == 0
    }

    static func context(_ purpose: String) -> Data { Data("llmide/\(purpose)/v1\u{0}".utf8) }

    /// `seal` in core/sync-envelope.mjs. `signer` returns a 64-byte P1363 ECDSA P-256 signature.
    public static func seal(header: SyncHeader, key: Data, plaintext: Data, signer: (Data) throws -> Data,
                            nonce: Data? = nil, extra: Data = Data()) throws -> SyncEnvelope {
        guard purposes.contains(header.purpose) else { throw SyncCryptoError("bad_purpose") }
        let n = nonce ?? randomBytes(12)
        let fields = header.fields
        let box = try AES.GCM.seal(try SyncPadding.pad(plaintext), using: SymmetricKey(data: key),
                                   nonce: try AES.GCM.Nonce(data: n), authenticating: SyncEnc.enc(fields + [.bytes(extra)]))
        let ct = box.ciphertext + box.tag
        let sig = try signer(context(header.purpose) + SyncEnc.enc(fields + [.bytes(extra), .bytes(n), .bytes(ct)]))
        return SyncEnvelope(header: header, nonce: SyncB64.encode(n), ct: SyncB64.encode(ct), sig: SyncB64.encode(sig),
                            eph: extra.isEmpty ? nil : SyncB64.encode(extra))
    }

    /// `open`: expected header values first (`bad_<field>`), then sizes, then the signature, then AES-GCM, then padding.
    public static func open(_ env: SyncEnvelope, key: Data, verifyKey: P256.Signing.PublicKey,
                            expect: [(String, SyncHeaderValue)] = []) throws -> Data {
        guard purposes.contains(env.purpose) else { throw SyncCryptoError("bad_purpose") }
        let header = env.header
        for (k, v) in expect where header.value(k) != v { throw SyncCryptoError("bad_\(k)") }
        let extra: Data
        if let e = env.eph, !e.isEmpty {
            guard let x = SyncB64.decode(e) else { throw SyncCryptoError("bad_base64") }
            extra = x
        } else { extra = Data() }
        guard let nonce = SyncB64.decode(env.nonce), let ct = SyncB64.decode(env.ct) else { throw SyncCryptoError("bad_base64") }
        guard nonce.count == 12, ct.count >= 16 + SyncPadding.buckets[0] else { throw SyncCryptoError("bad_ciphertext") }
        let fields = header.fields
        let message = context(env.purpose) + SyncEnc.enc(fields + [.bytes(extra), .bytes(nonce), .bytes(ct)])
        guard let raw = SyncB64.decode(env.sig), let sig = try? P256.Signing.ECDSASignature(rawRepresentation: raw),
              verifyKey.isValidSignature(sig, for: message) else { throw SyncCryptoError("bad_signature") }
        let plain: Data
        do {
            let box = try AES.GCM.SealedBox(nonce: AES.GCM.Nonce(data: nonce), ciphertext: ct.prefix(ct.count - 16), tag: ct.suffix(16))
            plain = try AES.GCM.open(box, using: SymmetricKey(data: key), authenticating: SyncEnc.enc(fields + [.bytes(extra)]))
        } catch { throw SyncCryptoError("bad_ciphertext") }
        return try SyncPadding.unpad(plain)
    }
}

    }

public enum SyncWrap {
    /// `syncWrapKey` in core/sync-envelope.mjs.
    public static func wrapKey(z: Data, ephSpki: Data, deviceEcdhSpki: Data, epoch: Int, deviceId: String,
                               desktopSigningSpki: Data, tier: String) -> Data {
        let salt = SyncCrypto.sha256(SyncEnc.enc([.bytes(ephSpki), .bytes(deviceEcdhSpki)]))
        let info = SyncEnc.enc([.str("llmide/syncwrap/v1"), .int(epoch), .str(deviceId), .bytes(SyncCrypto.sha256(deviceEcdhSpki)),
                                .bytes(SyncCrypto.sha256(desktopSigningSpki)), .str(tier)])
        return SyncCrypto.hkdf(z, salt: salt, info: info)
    }

    /// `unwrapSync`: same early refusals (purpose, to, epoch), then verify-before-decrypt by the pinned desktop key.
    public static func unwrap(_ env: SyncEnvelope, keys: SyncDeviceKeys, desktopSigningSpki: Data,
                              verifyKey: P256.Signing.PublicKey, currentEpoch: Int, deviceId: String) throws -> SyncWrapKeys {
        guard env.purpose == "syncwrap", let e = env.eph, !e.isEmpty else { throw SyncCryptoError("bad_purpose") }
        guard env.to == deviceId else { throw SyncCryptoError("bad_to") }
        guard env.epoch > currentEpoch else { throw SyncCryptoError("stale_epoch") }
        guard let ephSpki = SyncB64.decode(e) else { throw SyncCryptoError("bad_base64") }
        let z = try keys.sharedSecret(withSpki: ephSpki)
        let key = wrapKey(z: z, ephSpki: ephSpki, deviceEcdhSpki: keys.ecdhSpki, epoch: env.epoch, deviceId: deviceId,
                          desktopSigningSpki: desktopSigningSpki, tier: env.tier)
        let parts = try SyncEnc.decode(try SyncCrypto.open(env, key: key, verifyKey: verifyKey, expect: [("purpose", "syncwrap")]), count: 4)
        guard parts.allSatisfy({ $0.count == 32 }) else { throw SyncCryptoError("bad_wrap") }
        return SyncWrapKeys(request: parts[0], reply: parts[1], snapshot: parts[2], manifest: parts[3])
    }
}
```

```swift
    func sign(_ message: Data) throws -> Data

}

public final class SoftwareSyncDeviceKeys: SyncDeviceKeys {
    public let signing: P256.Signing.PrivateKey
    public let ecdh: P256.KeyAgreement.PrivateKey
    public init(signing: P256.Signing.PrivateKey = .init(), ecdh: P256.KeyAgreement.PrivateKey = .init()) {
        self.signing = signing
        self.ecdh = ecdh
    }
    /// PKCS#8 DER, the vectors' `*Pkcs8`.
    public convenience init(signingPkcs8: Data, ecdhPkcs8: Data) throws {
        self.init(signing: try .init(derRepresentation: signingPkcs8), ecdh: try .init(derRepresentation: ecdhPkcs8))

    }
```

```swift
import Foundation
import CryptoKit

/// The pairing QR's sync fields (device contract item 1).
public struct SyncPair: Codable, Equatable, Sendable {
    public var sid: String, sfp: String, dir: String, slot: String, es: String, st: String
    public init(sid: String, sfp: String, dir: String, slot: String, es: String, st: String) {
        self.sid = sid; self.sfp = sfp; self.dir = dir; self.slot = slot; self.es = es; self.st = st
    }
}

public struct SyncEnrollKeys: Equatable, Sendable {
    public let enroll: Data, enrollack: Data, bind: Data, sas: Data
}

public struct SyncClaimFields: Equatable, Sendable {
    public var deviceId: String
    public var ecdhSpki: Data
    public var signingSpki: Data
    public var name: String
    public init(deviceId: String, ecdhSpki: Data, signingSpki: Data, name: String) {
        self.deviceId = deviceId; self.ecdhSpki = ecdhSpki; self.signingSpki = signingSpki; self.name = name
    }
}

/// Sync v1 enrollment, device side (schema/sync/v1/README.md "Enrollment (device contract)"; port of
/// extension/core/sync-enroll.mjs). Each side computes the SAS only from values it holds or that were committed
/// before the other side revealed; nothing the storage supplies enters a trust decision.
public enum SyncEnroll {
    public static let nameMax = 64
    static let salt = SyncCrypto.sha256(Data("llmide-sync-enroll-v1".utf8))

    static func isB64u(_ s: String, _ n: Int) -> Bool { s.utf8.count == n && s.utf8.allSatisfy(SyncB64.isB64uByte) }

    /// `mega:<folder>` (folder `[A-Za-z0-9_.-]{1,64}`), or `memory:` (the test adapter).
    public static func isStore(_ st: String) -> Bool {
        if st == "memory:" { return true }
        guard st.hasPrefix("mega:") else { return false }
        let f = st.utf8.dropFirst(5)
        return (1...64).contains(f.count) && f.allSatisfy { SyncB64.isB64uByte($0) || $0 == 0x2e }
    }

    /// `llmide://pair?…` or `<origin>/#pair=<encoded query>`. Unknown parameters (the Host API fields) are ignored.
    public static func parsePair(_ url: String) throws -> SyncPair {
        let bad = SyncCryptoError("bad_pair")
        let query: String
        if url.hasPrefix("llmide://pair?") {
            query = String(url.dropFirst("llmide://pair?".count))
        } else if let r = url.range(of: "#pair=") {
            guard let q = String(url[r.upperBound...]).removingPercentEncoding else { throw bad }
            query = q
        } else { throw bad }
        var items: [String: String] = [:]
        for part in query.split(separator: "&") {
            let kv = part.split(separator: "=", maxSplits: 1, omittingEmptySubsequences: false)
            guard let k = String(kv[0]).replacingOccurrences(of: "+", with: " ").removingPercentEncoding,
                  let v = (kv.count > 1 ? String(kv[1]) : "").replacingOccurrences(of: "+", with: " ").removingPercentEncoding
            else { throw bad }
            if items[k] == nil { items[k] = v }   // URLSearchParams.get: the first one wins
        }
        guard items["sv"] == "1" else { throw bad }
        let p = SyncPair(sid: items["sid"] ?? "", sfp: items["sfp"] ?? "", dir: items["dir"] ?? "", slot: items["slot"] ?? "",
                         es: items["es"] ?? "", st: items["st"] ?? "")
        guard [p.sid, p.dir, p.slot, p.es].allSatisfy({ isB64u($0, 22) }), isB64u(p.sfp, 43), isStore(p.st) else { throw bad }
        return p
    }

    public static func enrollKeys(es: Data, sid: String, slot: String) throws -> SyncEnrollKeys {
        guard es.count == 16 else { throw SyncCryptoError("bad_secret") }
        func k(_ label: String) -> Data { SyncCrypto.hkdf(es, salt: salt, info: SyncEnc.enc([.str(label), .str(sid), .str(slot)])) }
        return SyncEnrollKeys(enroll: k("enroll"), enrollack: k("enrollack"), bind: k("bind"), sas: k("sas"))
    }

    public static func deviceId(signingSpki: Data) -> String { SyncB64.encode(SyncCrypto.sha256(signingSpki).prefix(16)) }

    public static func validName(_ n: String) -> Bool {
        (1...nameMax).contains(n.utf16.count) && !n.unicodeScalars.contains { $0.value < 0x20 || $0.value == 0x7f }
    }

    static func bound(_ p: SyncPair, _ tier: String, _ c: SyncClaimFields) -> [SyncField] {
        [.str(p.sid), .str(p.slot), .str(p.dir), .bytes(SyncB64.decode(p.sfp) ?? Data()), .str(tier), .str(c.deviceId),
         .bytes(c.ecdhSpki), .bytes(c.signingSpki), .str(c.name)]
    }

    public static func claimMac(bindKey: Data, pair: SyncPair, tier: String, claim: SyncClaimFields) -> Data {
        SyncCrypto.hmac(bindKey, SyncEnc.enc(bound(pair, tier, claim)))
    }

    public static func claimHash(_ c: SyncClaimFields) -> Data {
        SyncCrypto.sha256(SyncEnc.enc([.str("llmide/sync-claim/v1"), .str(c.deviceId), .bytes(c.ecdhSpki), .bytes(c.signingSpki), .str(c.name)]))
    }

    /// u32be(HMAC(E("sas"), enc(B ++ [nD]))[0..4]) mod 1,000,000, six digits with leading zeros.
    public static func sasCode(sasKey: Data, pair: SyncPair, tier: String, claim: SyncClaimFields, nD: Data) -> String {
        let h = [UInt8](SyncCrypto.hmac(sasKey, SyncEnc.enc(bound(pair, tier, claim) + [.bytes(nD)])))
        let v = UInt32(h[0]) << 24 | UInt32(h[1]) << 16 | UInt32(h[2]) << 8 | UInt32(h[3])
        let s = String(v % 1_000_000)
        return String(repeating: "0", count: 6 - s.count) + s
    }

    /// Contract 4c: the claim written to e/<slot>/<Id22>.bin; extra = the signing SPKI so the desktop verifies first.
    public static func sealClaim(pair: SyncPair, tier: String, name: String, keys: SyncDeviceKeys, issuedAt: Int,
                                 nonce: Data? = nil) throws -> SyncEnvelope {
        guard tier == "ios" || tier == "web" else { throw SyncCryptoError("bad_tier") }
        guard validName(name) else { throw SyncCryptoError("bad_name") }
        guard let es = SyncB64.decode(pair.es) else { throw SyncCryptoError("bad_secret") }
        let k = try enrollKeys(es: es, sid: pair.sid, slot: pair.slot)
        let c = SyncClaimFields(deviceId: deviceId(signingSpki: keys.signingSpki), ecdhSpki: keys.ecdhSpki, signingSpki: keys.signingSpki, name: name)
        let mac = claimMac(bindKey: k.bind, pair: pair, tier: tier, claim: c)
        let header = SyncHeader(purpose: "enroll", userId: "", desktopId: pair.sid, from: c.deviceId, to: pair.sid, epoch: 0,
                                session: pair.slot, seq: 0, issuedAt: issuedAt, tier: "")
        return try SyncCrypto.seal(header: header, key: k.enroll,
                                   plaintext: SyncEnc.enc([.bytes(c.ecdhSpki), .bytes(c.signingSpki), .str(name), .bytes(mac)]),
                                   signer: keys.sign, nonce: nonce, extra: keys.signingSpki)
    }

    /// Contract 4d: verify with the desktop key pinned by `sfp`; refuse an ack bound to anyone else's claim.
    public static func openAck(_ env: SyncEnvelope, pair: SyncPair, tier: String, claim: SyncClaimFields, keys: SyncEnrollKeys,
                               desktopVerifyKey: P256.Signing.PublicKey) throws -> (userId: String, nD: Data) {
        guard tier == "ios" || tier == "web" else { throw SyncCryptoError("bad_tier") }
        let pt = try SyncCrypto.open(env, key: keys.enrollack, verifyKey: desktopVerifyKey, expect: [
            ("purpose", "enrollack"), ("desktopId", .s(pair.sid)), ("from", .s(pair.sid)), ("to", .s(claim.deviceId)),
            ("epoch", 0), ("session", .s(pair.slot)), ("tier", .s(tier)),
        ])
        let p = try SyncEnc.decode(pt, count: 2)
        guard p[0].count == 16, p[1].count == 32 else { throw SyncCryptoError("bad_ack") }
        guard SyncCrypto.equal(p[1], claimHash(claim)) else { throw SyncCryptoError("ack_mismatch") }
        guard (1...128).contains(env.userId.utf8.count), env.userId.utf8.allSatisfy(SyncB64.isB64uByte) else {
            throw SyncCryptoError("bad_userId")
        }
        return (env.userId, p[0])
    }
}
```

```swift
    /// `expired`, `quota`, `needs_approval`, `turn_failed`, `refused` or `stale_epoch` (design 4.4).
    case failed(code: String)

    static func parse(_ data: Data, requestId: String) throws -> SyncReply {
        guard let o = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any], (o["v"] as? Int) == 1,
              o["requestId"] as? String == requestId, let ok = o["ok"] as? Bool else { throw SyncCryptoError("bad_reply") }

            return .answered(text: text, finishedAt: o["finishedAt"] as? Int ?? 0)
        }
        guard let code = o["code"] as? String else { throw SyncCryptoError("bad_reply") }
        return .failed(code: code)
    }
```

```swift
import Foundation
import CryptoKit

/// The device's half of the sync store (design 2.1). Paths are relative to the store root. `createFolders` = how many
/// of the path's last parent folders `put` may create: the device creates only `in/` (1) and `e/<slot>/` (2). A folder
/// the user deleted to revoke this phone (`<sid>/d/<dir>`) is therefore never recreated (design 5.3).
@MainActor
public protocol SyncRemoteStore: AnyObject {
    func get(_ path: String) async throws -> Data?
    func put(_ path: String, _ bytes: Data, createFolders: Int) async throws
}

public enum SyncPath {
    /// Largest file the device reads (design 2.1: 1,048,576 + 4,096).
    public static let maxFileBytes = 1_048_576 + 4_096
    /// 1 to 6 segments of `[A-Za-z0-9_.-]{1,64}`, never `.` or `..` (design 2.1), checked before any I/O.
    public static func check(_ path: String) throws -> [String] {
        let segs = path.split(separator: "/", omittingEmptySubsequences: false).map(String.init)
        guard (1...6).contains(segs.count), segs.allSatisfy(valid) else { throw SyncCryptoError("bad_path") }
        return segs
    }
    static func valid(_ s: String) -> Bool {
        s != "." && s != ".." && (1...64).contains(s.utf8.count) && s.utf8.allSatisfy { SyncB64.isB64uByte($0) || $0 == 0x2e }
    }
}

/// In-memory files: the test store, and the offline cache (last fetched ciphertext, re-verified on launch).
@MainActor
public final class SyncDictionaryStore: SyncRemoteStore {
    public var files: [String: Data]
    public init(files: [String: Data] = [:]) { self.files = files }
    public func get(_ path: String) async throws -> Data? { _ = try SyncPath.check(path); return files[path] }
    public func put(_ path: String, _ bytes: Data, createFolders: Int) async throws { _ = try SyncPath.check(path); files[path] = bytes }
}

/// Passes through and keeps every file it fetched, so a verified read can be cached as ciphertext.
@MainActor
public final class SyncRecordingStore: SyncRemoteStore {
    private let remote: SyncRemoteStore
    public private(set) var fetched: [String: Data] = [:]
    public init(remote: SyncRemoteStore) { self.remote = remote }
    public func get(_ path: String) async throws -> Data? {
        let d = try await remote.get(path)
        if let d { fetched[path] = d }
        return d
    }
    public func put(_ path: String, _ bytes: Data, createFolders: Int) async throws {
        try await remote.put(path, bytes, createFolders: createFolders)
    }
}

/// Everything the device keeps between launches. `pair.es` is non-empty only while enrolling; the app persists the
/// state only after the wrap verified, so `es` never reaches the Keychain.
public struct SyncDeviceState: Codable, Equatable, Sendable {
    public struct PrevReply: Codable, Equatable, Sendable {
        public var epoch: Int
        public var key: Data
        public var untilMs: Int
    }
    public var pair: SyncPair
    public var tier: String
    public var name: String
    public var deviceId: String
    /// The desktop signing SPKI, pinned at enrollment because its SHA-256 equalled `sfp` from the QR.
    public var desktopSpki: Data
    public var claimName: String
    public var userId: String?
    public var epoch = 0
    public var wrapKeys: SyncWrapKeys?
    public var prevReply: PrevReply?
    public var manifestSeq = 0
    public var requestSeq = 0
    public var isEnrolled: Bool { wrapKeys != nil && userId != nil }

    public init(pair: SyncPair, tier: String, name: String, deviceId: String, desktopSpki: Data, claimName: String) {
        self.pair = pair; self.tier = tier; self.name = name; self.deviceId = deviceId
        self.desktopSpki = desktopSpki; self.claimName = claimName
    }
}

/// The sync v1 device (schema/sync/v1/README.md "Enrollment (device contract)" and design 4.3-4.4); a port of
/// extension/tests/helpers/sync-device.mjs. Every file read from the store is untrusted until it verifies under the
/// desktop key pinned from the QR.
@MainActor
public final class SyncDevice {
    public static let ackPollMs = 2_000, ackWindowMs = 150_000, wrapWindowMs = 300_000, prevReplyMs = 86_400_000
    public static let maxText = 4_000, maxRequestBytes = 65_536
    static let kinds: Set<String> = ["chats", "meetings", "plans", "usage"]

    public private(set) var state: SyncDeviceState {
        didSet { if state != oldValue { onStateChange?(state) } }
    }
    public var onStateChange: ((SyncDeviceState) -> Void)?
    public let keys: SyncDeviceKeys
    private let desktopKey: P256.Signing.PublicKey
    private var enrollKeys: SyncEnrollKeys?   // memory only, dropped once the wrap verifies
    private var claimBytes: Data?

    private var base: String { "\(state.pair.sid)/d/\(state.pair.dir)" }
    private var slotDir: String { "\(state.pair.sid)/e/\(state.pair.slot)" }
    private var claim: SyncClaimFields {
        SyncClaimFields(deviceId: state.deviceId, ecdhSpki: keys.ecdhSpki, signingSpki: keys.signingSpki, name: state.name)
    }

    public init(state: SyncDeviceState, keys: SyncDeviceKeys) throws {
        guard state.deviceId == SyncEnroll.deviceId(signingSpki: keys.signingSpki) else { throw SyncCryptoError("bad_key") }
        self.state = state
        self.keys = keys
        desktopKey = try SyncSpki.signingKey(state.desktopSpki)
    }

    /// Contract 4b-4c: key.bin must hash to `sfp` from the QR and be a canonical P-256 SPKI; pin it; write the claim once.
    public static func begin(pair: SyncPair, tier: String = "ios", name: String, keys: SyncDeviceKeys,
                             store: SyncRemoteStore, nowMs: Int) async throws -> SyncDevice {
        guard let spki = try await store.get("\(pair.sid)/d/\(pair.dir)/key.bin"),
              SyncB64.encode(SyncCrypto.sha256(spki)) == pair.sfp else { throw SyncCryptoError("bad_desktop_key") }
        guard let es = SyncB64.decode(pair.es) else { throw SyncCryptoError("bad_secret") }
        let state = SyncDeviceState(pair: pair, tier: tier, name: name, deviceId: SyncEnroll.deviceId(signingSpki: keys.signingSpki),
                                    desktopSpki: spki, claimName: SyncB64.newId22())
        let d = try SyncDevice(state: state, keys: keys)
        d.enrollKeys = try SyncEnroll.enrollKeys(es: es, sid: pair.sid, slot: pair.slot)
        d.claimBytes = try SyncEnroll.sealClaim(pair: pair, tier: tier, name: name, keys: keys, issuedAt: nowMs).data()
        try await d.writeClaim(store)
        return d
    }

    /// The same name and bytes on every retry (contract 4c).
    public func writeClaim(_ store: SyncRemoteStore) async throws {
        guard let claimBytes else { throw SyncCryptoError("not_enrolling") }
        try await store.put("\(slotDir)/\(state.claimName).bin", claimBytes, createFolders: 2)
    }

    /// Contract 4d: nil until the desktop answered, then the 6-digit SAS.
    public func readAck(_ store: SyncRemoteStore) async throws -> String? {
        guard let ek = enrollKeys else { throw SyncCryptoError("not_enrolling") }
        guard let bytes = try await store.get("\(slotDir)/ack.bin") else { return nil }
        let r = try SyncEnroll.openAck(try SyncEnvelope.parse(bytes), pair: state.pair, tier: state.tier, claim: claim, keys: ek,
                                       desktopVerifyKey: desktopKey)
        state.userId = r.userId
        return SyncEnroll.sasCode(sasKey: ek.sas, pair: state.pair, tier: state.tier, claim: claim, nD: r.nD)
    }

    /// Contract 4e and 5 (rotation): true once a wrap for a higher epoch verified; `es` and E(*) are then dropped.
    public func readWrap(_ store: SyncRemoteStore, nowMs: Int) async throws -> Bool {
        guard let userId = state.userId else { throw SyncCryptoError("not_enrolling") }
        guard let bytes = try await store.get("\(base)/wrap.bin") else { return false }
        let env = try SyncEnvelope.parse(bytes)
        guard env.tier == state.tier, env.from == state.pair.sid, env.desktopId == state.pair.sid, env.userId == userId else {
            throw SyncCryptoError("bad_wrap")
        }
        guard env.epoch > state.epoch else { return false }
        let wk = try SyncWrap.unwrap(env, keys: keys, desktopSigningSpki: state.desktopSpki, verifyKey: desktopKey,
                                     currentEpoch: state.epoch, deviceId: state.deviceId)
        var next = state
        if let old = next.wrapKeys { next.prevReply = .init(epoch: next.epoch, key: old.reply, untilMs: nowMs + Self.prevReplyMs) }
        next.wrapKeys = wk
        next.epoch = env.epoch
        next.pair.es = ""
        state = next
        enrollKeys = nil
        claimBytes = nil
        return true
    }

    /// Design 4.3: verify the manifest, refuse rollback, fetch only the named blobs, check each file's SHA-256 before
    /// its envelope. A newer epoch pulls the new wrap first. A missing manifest means this device was removed.
    public func readSnapshot(_ store: SyncRemoteStore, nowMs: Int) async throws -> SyncSnapshot {
        try await readSnapshot(store, nowMs: nowMs, retry: true)
    }

    private func readSnapshot(_ store: SyncRemoteStore, nowMs: Int, retry: Bool) async throws -> SyncSnapshot {
        guard let userId = state.userId, state.wrapKeys != nil else { throw SyncCryptoError("not_enrolled") }
        guard let raw = try await store.get("\(base)/manifest.bin") else { throw SyncCryptoError("removed") }
        let env = try SyncEnvelope.parse(raw)
        if env.epoch > state.epoch {
            guard try await readWrap(store, nowMs: nowMs) else { throw SyncCryptoError("bad_epoch") }
        }
        guard let wk = state.wrapKeys else { throw SyncCryptoError("not_enrolled") }
        let sid = state.pair.sid
        let plain = try SyncCrypto.open(env, key: wk.manifest, verifyKey: desktopKey, expect: [
            ("purpose", "manifest"), ("userId", .s(userId)), ("desktopId", .s(sid)), ("from", .s(sid)),
            ("to", .s(state.deviceId)), ("epoch", .i(state.epoch)),
        ])
        guard let m = try? JSONDecoder().decode(SyncManifest.self, from: plain), m.v == 1, m.manifestSeq == env.seq, m.epoch == env.epoch
        else { throw SyncCryptoError("bad_manifest") }
        guard m.manifestSeq >= state.manifestSeq else { throw SyncCryptoError("rollback") }
        var snap = SyncSnapshot(manifest: m)
        for (kind, e) in m.kinds.sorted(by: { $0.key < $1.key }) {
            guard Self.kinds.contains(kind), Self.isBlobName(e.file) else { throw SyncCryptoError("bad_manifest") }
            guard let bytes = try await store.get("\(base)/\(e.file)") else {
                // Design 7: the desktop deletes old blobs after the new manifest; refetch the manifest once.
                if retry { return try await readSnapshot(store, nowMs: nowMs, retry: false) }
                throw SyncCryptoError("updating")
            }
            guard SyncCrypto.hex(SyncCrypto.sha256(bytes)) == e.sha256 else { throw SyncCryptoError("bad_blob") }
            let pt = try SyncCrypto.open(try SyncEnvelope.parse(bytes), key: wk.snapshot, verifyKey: desktopKey, expect: [
                ("purpose", "snapshot"), ("userId", .s(userId)), ("desktopId", .s(sid)), ("from", .s(sid)),
                ("to", .s(state.deviceId)), ("epoch", .i(state.epoch)), ("seq", .i(e.seq)),
            ])
            try Self.decode(kind, pt, into: &snap)
        }
        var next = state
        next.manifestSeq = m.manifestSeq
        if let p = next.prevReply, nowMs >= p.untilMs { next.prevReply = nil }
        state = next
        return snap
    }

    static func isBlobName(_ f: String) -> Bool {
        let u = Array(f.utf8)
        guard u.count == 2 + 32 + 4, f.hasPrefix("s/"), f.hasSuffix(".bin") else { return false }
        return u[2..<34].allSatisfy { ($0 >= 0x30 && $0 <= 0x39) || ($0 >= 0x61 && $0 <= 0x66) }
    }

    static func frame<T: Codable & Equatable & Sendable>(_: T.Type, _ kind: String, _ pt: Data) throws -> SyncKindFrame<T> {
        guard let f = try? JSONDecoder().decode(SyncKindFrame<T>.self, from: pt), f.v == 1, f.kind == kind else {
            throw SyncCryptoError("bad_blob")
        }
        return f
    }

    static func decode(_ kind: String, _ pt: Data, into s: inout SyncSnapshot) throws {
        var truncated = false
        switch kind {
        case "chats": let f = try frame(SyncChat.self, kind, pt); s.chats = f.items; truncated = f.truncated
        case "meetings": let f = try frame(SyncMeeting.self, kind, pt); s.meetings = f.items; truncated = f.truncated
        case "plans": let f = try frame(SyncPlan.self, kind, pt); s.plans = f.items; truncated = f.truncated
        default: let f = try frame(HostApiUsageGetResult.self, kind, pt); s.usage = f.items.first; truncated = f.truncated
        }
        if truncated { s.truncated.insert(kind) }
    }

    /// Design 4.4: one sealed `chat.send` into in/<13-digit issuedAt>-<requestId>.bin. Returns the requestId.
    public func sendRequest(_ store: SyncRemoteStore, text: String, nowMs: Int) async throws -> String {
        guard let wk = state.wrapKeys, let userId = state.userId else { throw SyncCryptoError("not_enrolled") }
        guard !text.isEmpty else { throw SyncCryptoError("empty") }
        guard text.utf16.count <= Self.maxText else { throw SyncCryptoError("too_long") }
        let requestId = SyncB64.newId22()
        let enc = JSONEncoder()
        enc.outputFormatting = .sortedKeys
        let plain = try enc.encode(SyncRequestPlain(requestId: requestId, text: text))
        let seq = state.requestSeq + 1
        let header = SyncHeader(purpose: "request", userId: userId, desktopId: state.pair.sid, from: state.deviceId, to: state.pair.sid,
                                epoch: state.epoch, session: "", seq: seq, issuedAt: nowMs, tier: "")
        let bytes = try SyncCrypto.seal(header: header, key: wk.request, plaintext: plain, signer: keys.sign).data()
        guard bytes.count <= Self.maxRequestBytes else { throw SyncCryptoError("too_long") }
        let ms = String(nowMs)
        try await store.put("\(base)/in/\(String(repeating: "0", count: max(0, 13 - ms.count)) + ms)-\(requestId).bin", bytes, createFolders: 1)
        state.requestSeq = seq
        return requestId
    }

    /// The reply in out/<requestId>.bin, or nil. A reply sealed under the previous epoch opens only with the reply key
    /// kept for 24 h after a rotation (contract 5).
    public func readReply(_ store: SyncRemoteStore, requestId: String, nowMs: Int) async throws -> SyncReply? {
        guard let wk = state.wrapKeys, let userId = state.userId else { throw SyncCryptoError("not_enrolled") }
        guard let bytes = try await store.get("\(base)/out/\(requestId).bin") else { return nil }
        let env = try SyncEnvelope.parse(bytes)
        let key: Data
        if env.epoch == state.epoch { key = wk.reply }
        else if let p = state.prevReply, p.epoch == env.epoch, nowMs < p.untilMs { key = p.key }
        else { throw SyncCryptoError("bad_epoch") }
        let sid = state.pair.sid
        let pt = try SyncCrypto.open(env, key: key, verifyKey: desktopKey, expect: [
            ("purpose", "reply"), ("userId", .s(userId)), ("desktopId", .s(sid)), ("from", .s(sid)), ("to", .s(state.deviceId)),
        ])
        return try SyncReply.parse(pt, requestId: requestId)
    }
}
```

```js
// cd extension && node scripts/mega-client-vectors.mjs          check the fixture against megajs (exit 1 on drift)
// cd extension && node scripts/mega-client-vectors.mjs --write  regenerate it
// Runs the REAL megajs 1.3.10 (the desktop's MEGA client, connectors/sync-store/mega.mjs) against an in-process fake
// MEGA API, so the iPhone's Swift client (ios_app/SharedProtocol MegaClient) is checked against megajs's own bytes:
// v2 login (PBKDF2-SHA512, RSA session id), hashcash, folder creation, upload (AES-CTR, condensed MAC, node key),
// multi-chunk download. No network. Random inputs (the RSA key) are kept in the fixture so the check is repeatable.
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { createCipheriv, generateKeyPairSync, pbkdf2Sync } from 'node:crypto';
import { Storage } from 'megajs';

const FILE = new URL('../../ios_app/SharedProtocol/Tests/SharedProtocolTests/Fixtures/mega-client.json', import.meta.url);
const e64 = (b) => Buffer.from(b).toString('base64url');
const d64 = (s) => Buffer.from(s, 'base64url');
const ecb = (key, data) => createCipheriv('aes-128-ecb', key, null).setAutoPadding(false).update(data);
const big = (buf) => BigInt(`0x${Buffer.from(buf).toString('hex') || '0'}`);
const bytesOf = (n) => { let h = n.toString(16); if (h.length % 2) h = `0${h}`; return Buffer.from(h, 'hex'); };
const mpi = (n) => { const bits = n.toString(2).length; return Buffer.concat([Buffer.from([bits >> 8, bits & 255]), bytesOf(n)]); };
const modPow = (b, e, m) => { let r = 1n; b %= m; while (e > 0n) { if (e & 1n) r = (r * b) % m; b = (b * b) % m; e >>= 1n; } return r; };
const modInv = (a, m) => { let [r0, r1, s0, s1] = [a % m, m, 1n, 0n]; while (r1 !== 0n) { const q = r0 / r1; [r0, r1] = [r1, r0 - q * r1]; [s0, s1] = [s1, s0 - q * s1]; } return ((s0 % m) + m) % m; };
const pattern = (n) => Buffer.from(Array.from({ length: n }, (_, i) => (i * 7 + 3) & 255));

function freshInputs() {
  const jwk = generateKeyPairSync('rsa', { modulusLength: 2048 }).privateKey.export({ format: 'jwk' });
  const [n, e, d, p, q] = ['n', 'e', 'd', 'p', 'q'].map((k) => big(d64(jwk[k])));
  const master = Buffer.alloc(16, 0x4d);
  let privk = Buffer.concat([mpi(p), mpi(q), mpi(d), mpi(modInv(p, q))]); // MEGA order p, q, d, u = p^-1 mod q
  privk = Buffer.concat([privk, Buffer.alloc((16 - (privk.length % 16)) % 16)]);
  const sidRaw = Buffer.concat([Buffer.from([0x53]), Buffer.alloc(42, 0x2a)]);
  const m = big(Buffer.concat([sidRaw, Buffer.alloc(200, 0x11)]));
  return {
    email: 'sync-it@example.com', password: 'correct horse battery staple', salt: e64(Buffer.alloc(32, 0x5a)),
    masterKeyHex: master.toString('hex'), privk: e64(ecb(master, privk)), csid: e64(mpi(modPow(m, e, n))), sid: e64(sidRaw),
    challenge: `1:255:1762300000:${e64(Buffer.alloc(48, 0x48))}`, mkdirKeyHex: '6b'.repeat(16), uploadKeyHex: '75'.repeat(24),
    plaintextHex: Buffer.from('{"v":1,"hello":"sync"}').toString('hex'), bigSize: 393232,
  };
}

async function run(inp) {
  const derived = pbkdf2Sync(Buffer.from(inp.password), d64(inp.salt), 100000, 32, 'sha512');
  const uh = e64(derived.subarray(16));
  const k = e64(ecb(derived.subarray(0, 16), Buffer.from(inp.masterKeyHex, 'hex')));
  const USER = 'USERHNDL';
  const nodes = [{ h: 'ROOTHNDL', t: 2, a: '', k: '', s: 0, ts: 1762300000, u: USER }];
  const blobs = {}; const uploads = {}; const sizes = {};
  let challenged = false; let token = null; let n = 0;
  const reply = (body, headers = {}) => new Response(Buffer.isBuffer(body) ? body : JSON.stringify(body), { status: 200, headers });
  const fetch = async (url, opts = {}) => {
    const u = new URL(url);
    if (u.pathname === '/cs') {
      if (!challenged) { challenged = true; return reply([-3], { 'X-Hashcash': inp.challenge }); }
      token ??= opts.headers?.['X-Hashcash'] ?? null;
      const [cmd] = JSON.parse(opts.body);
      if (cmd.a === 'us0') return reply([{ v: 2, s: inp.salt }]);
      if (cmd.a === 'us') return reply([cmd.uh === uh ? { k, csid: inp.csid, privk: inp.privk, u: USER } : -9]);
      if (cmd.a === 'ug') return reply([{ u: USER, name: 'sync' }]);
      if (cmd.a === 'f') return reply([{ f: nodes, ok: [] }]);
      if (cmd.a === 'u') { const t = `T${++n}`; sizes[t] = cmd.s; uploads[t] = Buffer.alloc(cmd.s); return reply([{ p: `https://fake.mega.test/ul/${t}` }]); }
      if (cmd.a === 'g') { const node = nodes.find((x) => x.h === cmd.n); return reply([{ g: `https://fake.mega.test/dl/${node.h}`, s: node.s }]); }
      if (cmd.a === 'p') {
        const out = cmd.n.map((x) => {
          const tok = x.t ? null : d64(x.h).toString();
          const node = { h: `NODE${String(++n).padStart(4, '0')}`, p: cmd.t, t: x.t, a: x.a, k: `${USER}:${x.k}`, s: x.t ? 0 : sizes[tok], ts: 1762300000 + n, u: USER };
          if (!x.t) blobs[node.h] = uploads[tok];
          nodes.push(node);
          return node;
        });
        return reply([{ f: out }]);
      }
      return reply([-2]);
    }
    const [, kind, id, range] = u.pathname.split('/');
    if (kind === 'ul') {
      const body = Buffer.from(opts.body); const at = Number(range);
      body.copy(uploads[id], at);
      return reply(at + body.length === sizes[id] ? Buffer.from(id) : Buffer.alloc(0)); // the last chunk answers the handle
    }
    if (kind === 'dl') { const [a, b] = range.split('-').map(Number); return reply(blobs[id].subarray(a, b + 1)); }
    throw new Error(`unexpected ${url}`);
  };

  const storage = await new Storage({ email: inp.email, password: inp.password, keepalive: false, fetch }).ready;
  if (storage.sid !== inp.sid) throw new Error('megajs derived another session id');
  const folder = await storage.root.mkdir({ name: 'llmide-sync', key: Buffer.alloc(16, 0x66) });
  const inFolder = await folder.mkdir({ name: 'in', key: Buffer.from(inp.mkdirKeyHex, 'hex') });
  const plain = Buffer.from(inp.plaintextHex, 'hex');
  const file = await folder.upload({ name: 'hello.bin', key: Buffer.from(inp.uploadKeyHex, 'hex'), size: plain.length }, plain).complete;
  const bigPlain = pattern(inp.bigSize);
  const bigFile = await folder.upload({ name: 'big.bin', size: bigPlain.length }, bigPlain).complete;
  if (!(await file.downloadBuffer({})).equals(plain) || !(await bigFile.downloadBuffer({})).equals(bigPlain)) throw new Error('megajs could not read back its upload');
  const node = (h) => nodes.find((x) => x.h === h);
  return {
    v: 1, megajs: '1.3.10',
    login: { email: inp.email, password: inp.password, salt: inp.salt, uh, k, privk: inp.privk, csid: inp.csid, sid: inp.sid, masterKeyHex: inp.masterKeyHex, userHandle: USER },
    hashcash: { challenge: inp.challenge, token },
    mkdir: { h: inFolder.nodeId, keyHex: inp.mkdirKeyHex, name: 'in', parent: folder.nodeId, a: node(inFolder.nodeId).a, k: node(inFolder.nodeId).k.split(':')[1] },
    upload: { keyHex: inp.uploadKeyHex, name: 'hello.bin', parent: folder.nodeId, plaintextHex: inp.plaintextHex, ciphertext: e64(blobs[file.nodeId]), a: node(file.nodeId).a, k: node(file.nodeId).k.split(':')[1] },
    big: { h: bigFile.nodeId, name: 'big.bin', size: inp.bigSize },
    nodes, blobs: Object.fromEntries(Object.entries(blobs).map(([h, b]) => [h, e64(b)])),
    inputs: inp,
  };
}

const write = process.argv.includes('--write');
const committed = write ? null : JSON.parse(readFileSync(FILE));
const out = await run(write ? freshInputs() : committed.inputs);
if (write) {
  mkdirSync(new URL('.', FILE), { recursive: true });
  writeFileSync(FILE, `${JSON.stringify(out, null, 1)}\n`);
  console.log('wrote', FILE.pathname);
} else {
  // big.bin's upload key is random each run, so only its plaintext round trip is compared.
  const strip = (o) => JSON.stringify({ ...o, nodes: o.nodes.filter((x) => x.h !== o.big.h), blobs: { ...o.blobs, [o.big.h]: null } });
  if (strip(out) !== strip(committed)) { console.error('mega client fixture out of date: node scripts/mega-client-vectors.mjs --write'); process.exit(1); }
  console.log('mega client fixture ok (megajs 1.3.10)');
}
process.exit(0);
```

```swift
import Foundation
import CommonCrypto
import CryptoKit

/// MEGA's own client-side format, ported from megajs 1.3.10 (dist/main.node-es.mjs: AES, CTR, MAC, prepareKeyV2,
/// mergeKeyMac/unmergeKeyMac, packAttributes/unpackAttributes, mpi2b/cryptoDecodePrivKey/cryptoRsaDecrypt,
/// generateHashcashToken). OS crypto only. Checked against megajs by Tests/…/Fixtures/mega-client.json
/// (extension/scripts/mega-client-vectors.mjs). This is MEGA's layer, not ours: the sync envelope does the security.
enum MegaCrypto {
    /// megajs `d64` is Node base64 decoding, which also accepts the url-safe alphabet and missing padding.
    static func d64(_ s: String) -> Data? {
        var t = s.replacingOccurrences(of: "-", with: "+").replacingOccurrences(of: "_", with: "/")
        while t.utf8.count % 4 != 0 { t += "=" }
        return Data(base64Encoded: t)
    }

    private static func crypt(_ op: Int, _ mode: Int, key: Data, iv: Data?, _ input: Data) -> Data {
        precondition(key.count == 16 && (mode == kCCModeCTR || input.count % 16 == 0), "AES block size")
        var ref: CCCryptorRef?
        let ivBytes = iv ?? Data(count: 16)
        let created = key.withUnsafeBytes { k in
            ivBytes.withUnsafeBytes { v in
                CCCryptorCreateWithMode(CCOperation(op), CCMode(mode), CCAlgorithm(kCCAlgorithmAES), CCPadding(ccNoPadding),
                                        mode == kCCModeECB ? nil : v.baseAddress, k.baseAddress, key.count, nil, 0, 0, CCModeOptions(0), &ref)
            }
        }
        precondition(created == CCCryptorStatus(kCCSuccess), "AES setup")
        defer { CCCryptorRelease(ref) }
        var out = Data(count: input.count)
        var moved = 0
        let status = input.withUnsafeBytes { i in
            out.withUnsafeMutableBytes { o in CCCryptorUpdate(ref, i.baseAddress, input.count, o.baseAddress, input.count, &moved) }
        }
        precondition(status == CCCryptorStatus(kCCSuccess) && moved == input.count, "AES update")
        return out
    }

    static func ecbEncrypt(_ key: Data, _ d: Data) -> Data { crypt(kCCEncrypt, kCCModeECB, key: key, iv: nil, d) }
    static func ecbDecrypt(_ key: Data, _ d: Data) -> Data { crypt(kCCDecrypt, kCCModeECB, key: key, iv: nil, d) }
    static func cbcEncryptZeroIV(_ key: Data, _ d: Data) -> Data { crypt(kCCEncrypt, kCCModeCBC, key: key, iv: Data(count: 16), d) }
    static func cbcDecryptZeroIV(_ key: Data, _ d: Data) -> Data { crypt(kCCDecrypt, kCCModeCBC, key: key, iv: Data(count: 16), d) }
    /// megajs CTR: IV = nonce (8 bytes) || 8 zero bytes, 128-bit big-endian counter. Same call encrypts and decrypts.
    static func ctr(_ key: Data, nonce: Data, _ d: Data) -> Data {
        crypt(kCCEncrypt, kCCModeCTR, key: key, iv: Data(nonce.prefix(8)) + Data(count: 8), d)
    }

    /// prepareKeyV2: PBKDF2-HMAC-SHA512(password, salt, 100,000, 32). First half = password key, second half = uh.
    static func pbkdf2SHA512(password: Data, salt: Data, rounds: UInt32 = 100_000) -> Data {
        var out = Data(count: 32)
        let status = password.withUnsafeBytes { p in
            salt.withUnsafeBytes { s in
                out.withUnsafeMutableBytes { o in
                    CCKeyDerivationPBKDF(CCPBKDFAlgorithm(kCCPBKDF2), p.bindMemory(to: CChar.self).baseAddress, password.count,
                                         s.bindMemory(to: UInt8.self).baseAddress, salt.count, CCPseudoRandomAlgorithm(kCCPRFHmacAlgSHA512),
                                         rounds, o.bindMemory(to: UInt8.self).baseAddress, 32)
                }
            }
        }
        precondition(status == Int32(kCCSuccess), "PBKDF2")
        return out
    }

    /// megajs MAC + condense: CBC-MAC per chunk (boundaries after 128 KiB, then +256 KiB, … up to +1 MiB steps), each
    /// chunk MAC started from nonce||nonce, the last partial block zero-padded; the chunk MACs folded to 8 bytes.
    static func condensedMac(key: Data, nonce: Data, plaintext: Data) -> Data {
        let n8 = [UInt8](nonce.prefix(8))
        var mac = n8 + n8
        var macs: [[UInt8]] = []
        var p = [UInt8](plaintext)
        p += [UInt8](repeating: 0, count: (16 - p.count % 16) % 16)
        var pos = 0, posNext = 131_072, increment = 131_072
        var i = 0
        while i < p.count {
            for j in 0..<16 { mac[j] ^= p[i + j] }
            mac = [UInt8](ecbEncrypt(key, Data(mac)))
            pos += 16
            if pos >= posNext {
                macs.append(mac)
                mac = n8 + n8
                if increment < 1_048_576 { increment += 131_072 }
                posNext += increment
            }
            i += 16
        }
        macs.append(mac)   // condense() always pushes the open chunk, even a fresh nonce||nonce one
        var acc = [UInt8](repeating: 0, count: 16)
        for m in macs {
            for j in 0..<16 { acc[j] ^= m[j] }
            acc = [UInt8](ecbEncrypt(key, Data(acc)))
        }
        return Data([acc[0] ^ acc[4], acc[1] ^ acc[5], acc[2] ^ acc[6], acc[3] ^ acc[7],
                     acc[8] ^ acc[12], acc[9] ^ acc[13], acc[10] ^ acc[14], acc[11] ^ acc[15]])
    }

    /// 24-byte upload key (AES key 16 + nonce 8) and 8-byte MAC → the 32-byte node key (megajs mergeKeyMac).
    static func mergeKeyMac(_ key24: Data, mac: Data) -> Data {
        var k = [UInt8](key24) + [UInt8](mac)
        for i in 0..<16 { k[i] ^= k[16 + i] }
        return Data(k)
    }
    /// The inverse: [0..16) AES key, [16..24) nonce, [24..32) MAC. A 16-byte folder key comes back unchanged (zero tail).
    static func unmergeKeyMac(_ key: Data) -> Data {
        var k = [UInt8](key) + [UInt8](repeating: 0, count: max(0, 32 - key.count))
        for i in 0..<16 { k[i] ^= k[16 + i] }
        return Data(k)
    }

    /// packAttributes({ n: name }) then CBC with a zero IV. Names are sync path segments ([A-Za-z0-9_.-]), never escaped.
    static func encryptAttributes(name: String, key16: Data) -> String {
        var at = [UInt8]("MEGA{\"n\":\"\(name)\"}".utf8)
        at += [UInt8](repeating: 0, count: (16 - at.count % 16) % 16)
        return SyncB64.encode(cbcEncryptZeroIV(key16, Data(at)))
    }
    /// decryptAttributes + unpackAttributes: the name, or nil when the key is not this node's.
    static func decryptAttributes(_ a: Data, key: Data) -> String? {
        guard !a.isEmpty, a.count % 16 == 0, key.count == 16 || key.count == 32 else { return nil }
        let plain = [UInt8](cbcDecryptZeroIV(Data(unmergeKeyMac(key).prefix(16)), a))
        let text = String(decoding: plain.prefix { $0 != 0 }, as: UTF8.self)
        guard text.hasPrefix("MEGA{\""), let o = (try? JSONSerialization.jsonObject(with: Data(text.dropFirst(4).utf8))) as? [String: Any]
        else { return nil }
        return o["n"] as? String
    }

    /// MEGA MPI: 2-byte big-endian bit count, then ceil(bits/8) bytes (mpi2b).
    static func mpi(_ b: ArraySlice<UInt8>) throws -> (value: Data, rest: ArraySlice<UInt8>) {
        guard b.count >= 2 else { throw MegaClient.Failure.badResponse }
        let bits = Int(b[b.startIndex]) << 8 | Int(b[b.startIndex + 1])
        let len = (bits + 7) / 8
        guard b.count >= 2 + len else { throw MegaClient.Failure.badResponse }
        let start = b.startIndex + 2
        return (Data(b[start..<(start + len)]), b[(start + len)...])
    }

    /// The login's RSA step (cryptoRsaDecrypt): sid = b64u(first 43 bytes of csid^d mod p·q, minimal big-endian).
    static func sessionId(csid: Data, privk: Data) throws -> String {
        let (p, r1) = try mpi([UInt8](privk)[...])
        let (q, r2) = try mpi(r1)
        let (d, _) = try mpi(r2)
        let (c, _) = try mpi([UInt8](csid)[...])
        let m = MegaBigUInt.modPow(MegaBigUInt(c), MegaBigUInt(d), MegaBigUInt(p) * MegaBigUInt(q)).bigEndianBytes
        guard m.count >= 43 else { throw MegaClient.Failure.badResponse }
        return SyncB64.encode(m.prefix(43))
    }

    /// generateHashcashToken: "1:<easiness>:<_>:<token>" → "1:<token>:<b64u of the 4-byte counter>".
    static func hashcash(_ challenge: String) throws -> String {
        let parts = challenge.split(separator: ":", omittingEmptySubsequences: false).map(String.init)
        guard parts.count >= 4, parts[0] == "1", let easiness = Int(parts[1]), (0...255).contains(easiness),
              let token = d64(parts[3]), token.count == 48 else { throw MegaClient.Failure.badResponse }
        let threshold = UInt32(((easiness & 63) << 1) + 1) << UInt32((easiness >> 6) * 7 + 3)
        var buf = [UInt8](repeating: 0, count: 4 + 262_144 * 48)
        let t = [UInt8](token)
        for i in 0..<262_144 { buf.replaceSubrange((4 + i * 48)..<(4 + i * 48 + 48), with: t) }
        while true {
            let h = Array(SHA256.hash(data: buf))
            if (UInt32(h[0]) << 24 | UInt32(h[1]) << 16 | UInt32(h[2]) << 8 | UInt32(h[3])) <= threshold {
                return "1:\(parts[3]):\(SyncB64.encode(Data(buf[0..<4])))"
            }
            var j = 0
            while true { buf[j] &+= 1; if buf[j] != 0 { break }; j += 1 }
        }
    }
}

/// Just enough unsigned arithmetic for one RSA decryption at login: little-endian UInt32 limbs, schoolbook multiply,
/// Montgomery modPow. shortcut: not constant-time; it runs once per login on the user's own device. Upgrade to a
/// vetted big-integer library if anything else ever needs RSA here.
struct MegaBigUInt: Equatable {
    private(set) var limbs: [UInt32]

    init(limbs: [UInt32]) { self.limbs = limbs; normalize() }
    init(_ bigEndian: Data) {
        let b = [UInt8](bigEndian)
        var l: [UInt32] = []
        var i = b.count
        while i > 0 {
            var w: UInt32 = 0
            for k in 0..<4 where i - 1 - k >= 0 { w |= UInt32(b[i - 1 - k]) << (8 * k) }
            l.append(w)
            i -= 4
        }
        self.init(limbs: l)
    }

    private mutating func normalize() { while limbs.last == 0 { limbs.removeLast() } }

    var bigEndianBytes: Data {
        var out: [UInt8] = []
        for w in limbs.reversed() { out += [UInt8(w >> 24), UInt8(w >> 16 & 0xff), UInt8(w >> 8 & 0xff), UInt8(w & 0xff)] }
        return Data(out.drop { $0 == 0 })
    }
    var bitWidth: Int { limbs.last.map { limbs.count * 32 - $0.leadingZeroBitCount } ?? 0 }
    func bit(_ i: Int) -> Bool { limbs[i / 32] >> UInt32(i % 32) & 1 == 1 }

    static func * (a: MegaBigUInt, b: MegaBigUInt) -> MegaBigUInt {
        guard !a.limbs.isEmpty, !b.limbs.isEmpty else { return MegaBigUInt(limbs: []) }
        var r = [UInt32](repeating: 0, count: a.limbs.count + b.limbs.count)
        for i in 0..<a.limbs.count {
            var c: UInt64 = 0
            for j in 0..<b.limbs.count {
                let s = UInt64(r[i + j]) + UInt64(a.limbs[i]) * UInt64(b.limbs[j]) + c
                r[i + j] = UInt32(truncatingIfNeeded: s)
                c = s >> 32
            }
            r[i + b.limbs.count] = UInt32(c)
        }
        return MegaBigUInt(limbs: r)
    }

    private static func geq(_ a: [UInt32], _ b: [UInt32]) -> Bool {
        for i in stride(from: a.count - 1, through: 0, by: -1) where a[i] != b[i] { return a[i] > b[i] }
        return true
    }
    private static func sub(_ a: inout [UInt32], _ b: [UInt32]) {
        var borrow: Int64 = 0
        for i in 0..<a.count {
            let d = Int64(a[i]) - Int64(b[i]) - borrow
            a[i] = UInt32(truncatingIfNeeded: d)
            borrow = d < 0 ? 1 : 0
        }
    }

    /// self mod m by binary long division. Setup only (R² mod m, the base mod m).
    func mod(_ m: MegaBigUInt) -> MegaBigUInt {
        let mm = m.limbs + [0]
        var r = [UInt32](repeating: 0, count: mm.count)
        for i in stride(from: bitWidth - 1, through: 0, by: -1) {
            var carry: UInt32 = bit(i) ? 1 : 0
            for j in 0..<r.count { let top = r[j] >> 31; r[j] = r[j] << 1 | carry; carry = top }
            if Self.geq(r, mm) { Self.sub(&r, mm) }
        }
        return MegaBigUInt(limbs: r)
    }

    /// base^exp mod m for an odd m (RSA moduli are odd), Montgomery (CIOS) with R = 2^(32k).
    static func modPow(_ base: MegaBigUInt, _ exp: MegaBigUInt, _ m: MegaBigUInt) -> MegaBigUInt {
        let n = m.limbs
        precondition(!n.isEmpty && n[0] & 1 == 1, "odd modulus")
        let k = n.count
        var inv: UInt32 = 1
        for _ in 0..<5 { inv = inv &* (2 &- n[0] &* inv) }   // n0^-1 mod 2^32 by Newton
        let ninv = 0 &- inv
        func pad(_ x: MegaBigUInt) -> [UInt32] { x.limbs + [UInt32](repeating: 0, count: k - x.limbs.count) }
        func mont(_ a: [UInt32], _ b: [UInt32]) -> [UInt32] {
            var t = [UInt32](repeating: 0, count: k + 2)
            for i in 0..<k {
                var c: UInt64 = 0
                for j in 0..<k {
                    let s = UInt64(t[j]) + UInt64(a[i]) * UInt64(b[j]) + c
                    t[j] = UInt32(truncatingIfNeeded: s); c = s >> 32
                }
                var s = UInt64(t[k]) + c
                t[k] = UInt32(truncatingIfNeeded: s); t[k + 1] = UInt32(truncatingIfNeeded: s >> 32)
                let u = UInt64(t[0] &* ninv)
                s = UInt64(t[0]) + u * UInt64(n[0]); c = s >> 32
                for j in 1..<max(k, 1) where j < k {
                    s = UInt64(t[j]) + u * UInt64(n[j]) + c
                    t[j - 1] = UInt32(truncatingIfNeeded: s); c = s >> 32
                }
                s = UInt64(t[k]) + c
                t[k - 1] = UInt32(truncatingIfNeeded: s)
                t[k] = t[k + 1] &+ UInt32(truncatingIfNeeded: s >> 32)
                t[k + 1] = 0
            }
            var r = Array(t[0...k])
            if geq(r, n + [0]) { sub(&r, n + [0]) }
            return Array(r[0..<k])
        }
        let r2 = pad(MegaBigUInt(limbs: [UInt32](repeating: 0, count: 2 * k) + [1]).mod(m))   // R² mod m
        let one = pad(MegaBigUInt(limbs: [1]))
        let xR = mont(pad(base.mod(m)), r2)
        var acc = mont(one, r2)
        for i in stride(from: exp.bitWidth - 1, through: 0, by: -1) {
            acc = mont(acc, acc)
            if exp.bit(i) { acc = mont(acc, xR) }
        }
        return MegaBigUInt(limbs: mont(acc, one))
    }
}
```

```swift
import Foundation

/// A minimal MEGA API client for the dedicated sync account (design §8.3; SP4 decision "MEGA client on iOS": no SDK).
/// It does only what the device needs: v2 login, a saved session, the folder tree, download (≤ 1 MiB + 4 KiB), upload
/// (≤ 128 KiB, one chunk), and creating `in/` and `e/<slot>/`. HTTPS only; it never deletes (design §3, one writer per
/// file). Protocol ported from megajs 1.3.10 and checked against it (Fixtures/mega-client.json). Paths are relative to
/// the sync folder `folder` in the Cloud Drive root, the same rule as connectors/sync-store/mega.mjs.
@MainActor
public final class MegaClient: SyncRemoteStore {
    public struct Session: Codable, Equatable, Sendable {
        public var sid: String
        /// The account master key: with `sid` as powerful as the password (spec §8.3). Keychain only.
        public var masterKey: Data
        public init(sid: String, masterKey: Data) { self.sid = sid; self.masterKey = masterKey }
    }
    public enum Failure: Error, Equatable, Sendable {
        case authFailed, mfaRequired, sessionExpired, accountVersion, rateLimited, quota, tooLarge, badResponse
        case http(Int), api(Int)
    }
    public typealias Transport = (URLRequest) async throws -> (Data, HTTPURLResponse)
    public typealias Sleep = (UInt64) async throws -> Void

    public static let defaultGateway = URL(string: "https://g.api.mega.co.nz/")!
    private static let urlSession = URLSession(configuration: .ephemeral)
    public static let urlSessionTransport: Transport = { request in
        let (data, response) = try await urlSession.data(for: request)
        guard let http = response as? HTTPURLResponse else { throw Failure.badResponse }
        return (data, http)
    }
    public static let realSleep: Sleep = { try await Task.sleep(nanoseconds: $0) }
    /// shortcut: one upload chunk. The device writes requests ≤ 64 KiB and small claims; upgrade if that changes.
    static let maxUpload = 131_072

    public let folder: String
    public private(set) var session: Session
    private let transport: Transport
    private let gateway: URL
    private let sleep: Sleep
    private let randomBytes: (Int) -> Data
    private var counter = UInt64.random(in: 1..<10_000_000_000)

    public init(folder: String, session: Session, transport: @escaping Transport = MegaClient.urlSessionTransport,
                gateway: URL = MegaClient.defaultGateway, sleep: @escaping Sleep = MegaClient.realSleep,
                randomBytes: @escaping (Int) -> Data = SyncCrypto.randomBytes) {
        self.folder = folder; self.session = session; self.transport = transport; self.gateway = gateway
        self.sleep = sleep; self.randomBytes = randomBytes
    }

    // MARK: API transport (megajs API.request)

    static func failure(_ n: Int) -> Failure {
        switch n {
        case -15: return .sessionExpired
        case -26: return .mfaRequired
        case -3, -4, -6, -18, -19: return .rateLimited
        case -17, -24: return .quota
        default: return .api(n)
        }
    }

    static func api(_ cmd: [String: Any], id: UInt64, sid: String?, transport: Transport, gateway: URL, sleep: Sleep) async throws -> Any {
        let body = try JSONSerialization.data(withJSONObject: [cmd])
        var hashcash: String?
        var challenges = 0, busy = 0
        while true {
            var c = URLComponents(url: gateway.appendingPathComponent("cs"), resolvingAgainstBaseURL: false)!
            c.queryItems = [URLQueryItem(name: "id", value: String(id))] + (sid.map { [URLQueryItem(name: "sid", value: $0)] } ?? [])
            var req = URLRequest(url: c.url!)
            req.httpMethod = "POST"
            req.setValue("application/json", forHTTPHeaderField: "Content-Type")
            if let hashcash { req.setValue(hashcash, forHTTPHeaderField: "X-Hashcash") }
            req.httpBody = body
            let (data, resp) = try await transport(req)
            if let challenge = resp.value(forHTTPHeaderField: "X-Hashcash"), challenges < 2 {
                challenges += 1
                hashcash = try await Task.detached(priority: .userInitiated) { try MegaCrypto.hashcash(challenge) }.value
                continue
            }
            var result: Any?
            if resp.statusCode == 200 { result = try? JSONSerialization.jsonObject(with: data, options: [.fragmentsAllowed]) }
            else if resp.statusCode == 500 || resp.statusCode == 503 { result = -3 }   // megajs: "Server Too Busy" → EAGAIN
            else { throw Failure.http(resp.statusCode) }
            if let list = result as? [Any] { result = list.first }
            if let n = result as? Int, n < 0 {
                if n == -3, busy < 4 { busy += 1; try await sleep(UInt64(1 << busy) * 1_000_000_000); continue }
                throw failure(n)
            }
            guard let result else { throw Failure.badResponse }
            return result
        }
    }

    private func call(_ cmd: [String: Any]) async throws -> Any {
        counter += 1
        return try await Self.api(cmd, id: counter, sid: session.sid, transport: transport, gateway: gateway, sleep: sleep)
    }

    // MARK: Login (megajs Storage.login, v2 accounts only)

    /// Email + password → a resumable session. The password is used here and nowhere else; nothing stores it.
    public static func login(email: String, password: String, transport: @escaping Transport = urlSessionTransport,
                             gateway: URL = defaultGateway, sleep: @escaping Sleep = realSleep) async throws -> Session {
        let user = email.lowercased()
        var id = UInt64.random(in: 1..<10_000_000_000)
        func call(_ cmd: [String: Any]) async throws -> Any {
            id += 1
            do { return try await api(cmd, id: id, sid: nil, transport: transport, gateway: gateway, sleep: sleep) }
            catch Failure.api(-9), Failure.api(-16) { throw Failure.authFailed }   // ENOENT / EBLOCKED at login
        }
        guard let pre = try await call(["a": "us0", "user": user]) as? [String: Any], let v = pre["v"] as? Int else { throw Failure.badResponse }
        guard v == 2, let salt = (pre["s"] as? String).flatMap(MegaCrypto.d64) else { throw Failure.accountVersion }
        let derived = MegaCrypto.pbkdf2SHA512(password: Data(password.utf8), salt: salt)
        guard let r = try await call(["a": "us", "user": user, "uh": SyncB64.encode(Data(derived.suffix(16)))]) as? [String: Any],
              let k = (r["k"] as? String).flatMap(MegaCrypto.d64), k.count == 16,
              let csid = (r["csid"] as? String).flatMap(MegaCrypto.d64),
              let privk = (r["privk"] as? String).flatMap(MegaCrypto.d64), !privk.isEmpty, privk.count % 16 == 0
        else { throw Failure.badResponse }
        let master = MegaCrypto.ecbDecrypt(Data(derived.prefix(16)), k)
        return Session(sid: try MegaCrypto.sessionId(csid: csid, privk: MegaCrypto.ecbDecrypt(master, privk)), masterKey: master)
    }

    /// Kills this session on MEGA (megajs `sml`). Best effort.
    public func logout() async { _ = try? await call(["a": "sml"]) }

    // MARK: Tree

    struct Node { let h: String; let p: String?; let t: Int; let name: String?; let key: Data?; let s: Int; let ts: Int }

    private func tree() async throws -> [Node] {
        guard let r = try await call(["a": "f", "c": 1]) as? [String: Any], let f = r["f"] as? [[String: Any]] else { throw Failure.badResponse }
        return f.compactMap(node)
    }

    /// loadMetadata: each "owner:key" alternative, AES-ECB with the master key, until the attributes decrypt.
    private func node(_ o: [String: Any]) -> Node? {
        guard let h = o["h"] as? String, let t = o["t"] as? Int else { return nil }
        var name: String?, key: Data?
        if t <= 1, let k = o["k"] as? String, let a = (o["a"] as? String).flatMap(MegaCrypto.d64) {
            for alt in k.split(separator: "/") {
                guard let part = alt.split(separator: ":").last, let enc = MegaCrypto.d64(String(part)),
                      enc.count == 16 || enc.count == 32 else { continue }
                let plain = MegaCrypto.ecbDecrypt(session.masterKey, enc)
                if let n = MegaCrypto.decryptAttributes(a, key: plain) { name = n; key = plain; break }
            }
        }
        return Node(h: h, p: o["p"] as? String, t: t, name: name, key: key, s: o["s"] as? Int ?? 0, ts: o["ts"] as? Int ?? 0)
    }

    private func folderChild(_ nodes: [Node], _ parent: String, _ name: String) -> String? {
        nodes.first { $0.p == parent && $0.t == 1 && $0.name == name }?.h   // desktop folderNamed: the first one
    }
    private func syncFolder(_ nodes: [Node]) -> String? {
        guard let root = nodes.first(where: { $0.t == 2 }) else { return nil }
        return folderChild(nodes, root.h, folder)
    }
    private func folderHandle(_ nodes: [Node], _ segs: [String]) -> String? {
        var h = syncFolder(nodes)
        for s in segs { h = h.flatMap { folderChild(nodes, $0, s) } }
        return h
    }
    /// The newest node of that name (design 7: until the old one's delete lands, a reader takes the newest).
    private func newestFile(_ nodes: [Node], in dir: String, named name: String) -> Node? {
        nodes.filter { $0.p == dir && $0.t == 0 && $0.name == name }.enumerated()
            .max { ($0.element.ts, $0.offset) < ($1.element.ts, $1.offset) }?.element
    }

    // MARK: SyncRemoteStore

    public func get(_ path: String) async throws -> Data? {
        let segs = try SyncPath.check(path)
        let nodes = try await tree()
        guard let dir = folderHandle(nodes, Array(segs.dropLast())), let file = newestFile(nodes, in: dir, named: segs.last!),
              let key = file.key, key.count == 32 else { return nil }
        guard file.s <= SyncPath.maxFileBytes else { throw Failure.tooLarge }
        if file.s == 0 { return Data() }
        guard let r = try await call(["a": "g", "g": 1, "ssl": 2, "n": file.h]) as? [String: Any], let g = r["g"] as? String,
              let url = URL(string: "\(g)/0-\(file.s - 1)"), url.scheme == "https" else { throw Failure.badResponse }
        let (data, resp) = try await transport(URLRequest(url: url))
        if resp.statusCode == 509 { throw Failure.quota }
        guard resp.statusCode == 200 else { throw Failure.http(resp.statusCode) }
        guard data.count == file.s else { throw Failure.badResponse }
        let k = MegaCrypto.unmergeKeyMac(key)
        let aes = Data(k.prefix(16)), nonce = Data(k[16..<24])
        let plain = MegaCrypto.ctr(aes, nonce: nonce, data)
        guard MegaCrypto.condensedMac(key: aes, nonce: nonce, plaintext: plain) == Data(k[24..<32]) else { throw Failure.badResponse }
        return plain
    }

    public func put(_ path: String, _ bytes: Data, createFolders: Int) async throws {
        let segs = try SyncPath.check(path)
        guard !bytes.isEmpty, bytes.count <= Self.maxUpload else { throw Failure.tooLarge }
        var nodes = try await tree()
        guard var dir = syncFolder(nodes) else { throw SyncCryptoError("removed") }
        let parents = Array(segs.dropLast())
        for (i, name) in parents.enumerated() {
            if let next = folderChild(nodes, dir, name) { dir = next; continue }
            guard parents.count - i <= createFolders else { throw SyncCryptoError("removed") }
            let fk = randomBytes(16)
            guard let r = try await call(["a": "p", "t": dir, "n": [["h": "xxxxxxxx", "t": 1,
                                                                    "a": MegaCrypto.encryptAttributes(name: name, key16: fk),
                                                                    "k": SyncB64.encode(MegaCrypto.ecbEncrypt(session.masterKey, fk))]]]) as? [String: Any],
                  let h = ((r["f"] as? [[String: Any]])?.first)?["h"] as? String else { throw Failure.badResponse }
            nodes.append(Node(h: h, p: dir, t: 1, name: name, key: fk, s: 0, ts: 0))
            dir = h
        }
        let key24 = randomBytes(24)
        let aes = Data(key24.prefix(16)), nonce = Data(key24.suffix(8))
        let nodeKey = MegaCrypto.mergeKeyMac(key24, mac: MegaCrypto.condensedMac(key: aes, nonce: nonce, plaintext: bytes))
        guard let u = try await call(["a": "u", "ssl": 2, "s": bytes.count, "ms": 0, "r": 0, "e": 0, "v": 2]) as? [String: Any],
              let p = u["p"] as? String, let url = URL(string: "\(p)/0"), url.scheme == "https" else { throw Failure.badResponse }
        var req = URLRequest(url: url)
        req.httpMethod = "POST"
        req.httpBody = MegaCrypto.ctr(aes, nonce: nonce, bytes)
        let (handle, resp) = try await transport(req)
        guard resp.statusCode == 200 else { throw resp.statusCode == 509 ? Failure.quota : Failure.http(resp.statusCode) }
        if let n = Int(String(decoding: handle, as: UTF8.self)), n < 0 { throw Self.failure(n) }
        guard !handle.isEmpty else { throw Failure.badResponse }
        _ = try await call(["a": "p", "t": dir, "n": [["h": SyncB64.encode(handle), "t": 0,
                                                      "a": MegaCrypto.encryptAttributes(name: segs.last!, key16: aes),
                                                      "k": SyncB64.encode(MegaCrypto.ecbEncrypt(session.masterKey, nodeKey))]]])
    }
}
```

```swift
import Foundation
import CryptoKit
import Security
import UIKit
import SharedProtocol

/// The iPhone's sync tier (design 2026-11-05 §6, SP4): with the desktop off, read the last encrypted snapshot from the
/// dedicated MEGA folder and queue chat prompts. The crypto, the device contract and the MEGA protocol live in
/// SharedProtocol (`SyncDevice`, `MegaClient`). This class keeps state in the Keychain and on disk and refreshes only in
/// the foreground: iOS gives no long-poll and there is no push.
@MainActor
final class SyncStore: ObservableObject {
    enum Phase: Equatable { case off, needsPassword, ready, removed }
    enum EnrollStep: Equatable { case login, working(String), sas(String), done, failed(String) }

    struct Queued: Codable, Identifiable, Equatable {
        let id: String
        let text: String
        let issuedAtMs: Int
        var answer: String?
        var code: String?
        var isPending: Bool { answer == nil && code == nil }
    }

    private struct StoredKeys: Codable { var secureEnclave: Bool; var signing: Data; var ecdh: Data }
    private struct StoredMega: Codable { var email: String; var folder: String; var session: MegaClient.Session }

    @Published private(set) var phase: Phase = .off
    @Published private(set) var snapshot: SyncSnapshot?
    @Published private(set) var queued: [Queued] = []
    @Published private(set) var lastError: String?
    @Published private(set) var refreshing = false
    @Published private(set) var enrollStep: EnrollStep?
    @Published private(set) var megaEmail = ""

    private var device: SyncDevice?
    private var mega: MegaClient?
    private var pendingPair: SyncPair?
    private var enrollTask: Task<Void, Never>?
    private var foregroundTask: Task<Void, Never>?

    private var nowMs: Int { Int(Date().timeIntervalSince1970 * 1000) }

    init() { restore() }

    // MARK: Launch

    private func restore() {
        guard let st = Keychain.load(SyncDeviceState.self, .state), st.isEnrolled,
              let sk = Keychain.load(StoredKeys.self, .keys), let keys = try? Self.loadKeys(sk),
              let d = try? SyncDevice(state: st, keys: keys) else { return }
        attach(d)
        queued = Self.read([Queued].self, "queue.json") ?? []
        if let m = Keychain.load(StoredMega.self, .mega) {
            megaEmail = m.email
            mega = MegaClient(folder: m.folder, session: m.session)
            phase = .ready
        } else {
            phase = .needsPassword
        }
        // The last verified ciphertext, re-verified: something to show before the network answers, or with none.
        if let cache = Self.read([String: Data].self, "snapshot-cache.json"), !cache.isEmpty {
            Task { snapshot = try? await d.readSnapshot(SyncDictionaryStore(files: cache), nowMs: nowMs) }
        }
    }

    private func attach(_ d: SyncDevice) {
        device = d
        d.onStateChange = { _ = Keychain.save($0, .state) }
    }

    private static func makeKeys() throws -> (SyncDeviceKeys, StoredKeys) {
        if SecureEnclaveSyncDeviceKeys.isAvailable {
            let k = try SecureEnclaveSyncDeviceKeys()
            return (k, StoredKeys(secureEnclave: true, signing: k.signingBlob, ecdh: k.ecdhBlob))
        }
        // No Secure Enclave (Simulator): software keys, Keychain ThisDeviceOnly.
        let k = SoftwareSyncDeviceKeys()
        return (k, StoredKeys(secureEnclave: false, signing: k.signing.rawRepresentation, ecdh: k.ecdh.rawRepresentation))
    }

    private static func loadKeys(_ s: StoredKeys) throws -> SyncDeviceKeys {
        if s.secureEnclave { return try SecureEnclaveSyncDeviceKeys(signingBlob: s.signing, ecdhBlob: s.ecdh) }
        return SoftwareSyncDeviceKeys(signing: try .init(rawRepresentation: s.signing), ecdh: try .init(rawRepresentation: s.ecdh))
    }

    // MARK: Enrollment (device contract 4a-4e)

    func startEnrollment(_ pair: SyncPair) {
        guard pair.st.hasPrefix("mega:") else { lastError = "This code is not for a MEGA sync folder."; return }
        pendingPair = pair
        // shortcut: let the scanner sheet finish dismissing before this sheet presents (a sheet presented mid-dismiss is
        // dropped by SwiftUI). Upgrade by moving the scanner into the enrollment sheet if this ever flakes.
        Task { try? await Task.sleep(nanoseconds: 600_000_000); enrollStep = .login }
    }

    func enroll(email: String, password: String, name: String) {
        guard let pair = pendingPair else { return }
        enrollTask?.cancel()
        enrollTask = Task { await runEnrollment(pair: pair, email: email, password: password, name: name) }
    }

    func cancelEnrollment() {
        enrollTask?.cancel()
        enrollTask = nil
        enrollStep = nil
        pendingPair = nil
    }

    private func runEnrollment(pair: SyncPair, email: String, password: String, name: String) async {
        let folder = String(pair.st.dropFirst("mega:".count))
        do {
            enrollStep = .working("Signing in to MEGA…")
            let session = try await MegaClient.login(email: email, password: password)
            let client = MegaClient(folder: folder, session: session)
            enrollStep = .working("Checking the desktop's key…")
            let (keys, stored) = try Self.makeKeys()
            let d = try await SyncDevice.begin(pair: pair, name: name, keys: keys, store: client, nowMs: nowMs)
            enrollStep = .working("Waiting for the desktop…")
            let sas = try await poll(SyncDevice.ackWindowMs) { try await d.readAck(client) }
            enrollStep = .sas(sas)
            UIAccessibility.post(notification: .announcement, argument: "Code ready. Compare it with the desktop.")
            _ = try await poll(SyncDevice.wrapWindowMs) { try await d.readWrap(client, nowMs: self.nowMs) ? true : nil }
            // Enrolled. Only now does anything reach the Keychain, and `es` is already gone from the state.
            await mega?.logout()
            _ = Keychain.save(stored, .keys)
            _ = Keychain.save(d.state, .state)
            _ = Keychain.save(StoredMega(email: email, folder: folder, session: session), .mega)
            attach(d)
            mega = client
            megaEmail = email
            queued = []
            Self.write(queued, "queue.json")
            phase = .ready
            enrollStep = .done
            await refresh()
        } catch is CancellationError {
        } catch {
            enrollStep = .failed(Self.message(for: error))
        }
    }

    private func poll<T>(_ windowMs: Int, _ step: () async throws -> T?) async throws -> T {
        let deadline = nowMs + windowMs
        while true {
            do { if let v = try await step() { return v } }
            catch MegaClient.Failure.rateLimited { try await Task.sleep(nanoseconds: 8_000_000_000) }
            guard nowMs < deadline else { throw SyncCryptoError("timeout") }
            try await Task.sleep(nanoseconds: UInt64(SyncDevice.ackPollMs) * 1_000_000)
        }
    }

    // MARK: Reading and queueing

    func refresh() async {
        guard phase == .ready, let device, let mega, !refreshing else { return }
        refreshing = true
        defer { refreshing = false }
        do {
            let rec = SyncRecordingStore(remote: mega)
            snapshot = try await device.readSnapshot(rec, nowMs: nowMs)
            Self.write(rec.fetched, "snapshot-cache.json")
            var resend: [String] = []
            for i in queued.indices where queued[i].isPending {
                guard let r = try await device.readReply(mega, requestId: queued[i].id, nowMs: nowMs) else { continue }
                switch r {
                case .answered(let text, _): queued[i].answer = text
                case .failed(let code):
                    queued[i].code = code
                    if code == "stale_epoch" { resend.append(queued[i].text) }   // contract 5: send again under the new epoch
                }
            }
            let cutoff = nowMs - 7 * 86_400_000   // the desktop deletes replies after 7 days
            queued.removeAll { $0.issuedAtMs < cutoff || $0.code == "stale_epoch" }
            Self.write(queued, "queue.json")
            lastError = nil
            for text in resend { await send(text) }
        } catch {
            fail(error)
        }
    }

    func send(_ text: String) async {
        guard phase == .ready, let device, let mega else { return }
        do {
            let id = try await device.sendRequest(mega, text: text, nowMs: nowMs)
            queued.append(Queued(id: id, text: text, issuedAtMs: nowMs))
            Self.write(queued, "queue.json")
            lastError = nil
        } catch {
            fail(error)
        }
    }

    func signIn(password: String) async {
        guard let device else { return }
        let folder = String(device.state.pair.st.dropFirst("mega:".count))
        do {
            let session = try await MegaClient.login(email: megaEmail, password: password)
            _ = Keychain.save(StoredMega(email: megaEmail, folder: folder, session: session), .mega)
            mega = MegaClient(folder: folder, session: session)
            phase = .ready
            lastError = nil
            await refresh()
        } catch {
            lastError = Self.message(for: error)
        }
    }

    func removeFromPhone() async {
        await mega?.logout()
        for item in [Keychain.Item.state, .keys, .mega] { Keychain.delete(item) }
        try? FileManager.default.removeItem(at: Self.dir)
        device = nil; mega = nil; snapshot = nil; queued = []; lastError = nil; megaEmail = ""
        phase = .off
    }

    /// Foreground only: refresh now, then every 60 s while a prompt waits for its reply.
    func setForeground(_ on: Bool) {
        foregroundTask?.cancel()
        foregroundTask = nil
        guard on else { return }
        foregroundTask = Task { [weak self] in
            await self?.refresh()
            while !Task.isCancelled {
                try? await Task.sleep(nanoseconds: 60_000_000_000)
                guard let self, !Task.isCancelled else { return }
                if self.queued.contains(where: \.isPending) { await self.refresh() }
            }
        }
    }

    private func fail(_ error: Error) {
        if let f = error as? MegaClient.Failure, f == .sessionExpired || f == .authFailed {
            Keychain.delete(.mega)
            mega = nil
            phase = .needsPassword
        }
        if (error as? SyncCryptoError)?.code == "removed" { phase = .removed }
        lastError = Self.message(for: error)
    }

    // MARK: Plain-words messages

    static func message(for error: Error) -> String {
        if let f = error as? MegaClient.Failure {
            switch f {
            case .authFailed: return "MEGA refused the email or password."
            case .mfaRequired: return "This MEGA account has two-step login on. Use the dedicated LLM-IDE account, with two-step login off."
            case .sessionExpired: return "Your MEGA sign-in ended. Sign in again."
            case .accountVersion: return "This MEGA account is too old for this app. Create a new dedicated account."
            case .rateLimited: return "MEGA is busy. Try again in a minute."
            case .quota: return "The MEGA account is over its storage or transfer quota."
            case .tooLarge, .badResponse, .http, .api: return "Couldn't read from MEGA (\(f))."
            }
        }
        if error is URLError { return "No connection to MEGA." }
        switch (error as? SyncCryptoError)?.code {
        case "removed": return "This iPhone was removed from sync. Set it up again from the desktop."
        case "updating": return "The desktop is updating the snapshot. Pull to refresh in a moment."
        case "too_long": return "That prompt is too long."
        case "empty": return "Type a prompt first."
        case "timeout": return "The desktop didn't answer in time. Start again on the desktop."
        case "bad_desktop_key": return "This code doesn't match the desktop's key. Start again on the desktop."
        case "ack_mismatch": return "Someone else answered this pairing code. Start again on the desktop and keep the code private."
        case let code?: return "The sync folder holds data this iPhone cannot verify (\(code)). Nothing from it is shown."
        case nil: return "Something went wrong."
        }
    }

    static func replyText(_ code: String) -> String {
        switch code {
        case "expired": return "Too old when the desktop saw it, or this iPhone's clock is wrong."
        case "quota": return "Today's limit for queued prompts was reached."
        case "needs_approval": return "The desktop needed an approval it can't take from a queued prompt."
        case "turn_failed": return "The desktop could not finish this prompt."
        case "refused": return "The desktop refused this prompt."
        default: return "The desktop could not answer (\(code))."
        }
    }

    // MARK: Files (Data Protection: complete) and Keychain (ThisDeviceOnly)

    private static var dir: URL {
        FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0].appendingPathComponent("sync", isDirectory: true)
    }
    private static func write<T: Encodable>(_ value: T, _ name: String) {
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        guard let data = try? JSONEncoder().encode(value) else { return }
        try? data.write(to: dir.appendingPathComponent(name), options: [.atomic, .completeFileProtection])
    }
    private static func read<T: Decodable>(_ type: T.Type, _ name: String) -> T? {
        guard let data = try? Data(contentsOf: dir.appendingPathComponent(name)) else { return nil }
        return try? JSONDecoder().decode(type, from: data)
    }

    enum Keychain {
        enum Item: String { case state = "device-state", keys = "device-keys", mega = "mega-session" }
        private static func base(_ item: Item) -> [String: Any] {
            [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: "com.llmide.sync", kSecAttrAccount as String: item.rawValue]
        }
        @discardableResult
        static func save<T: Encodable>(_ value: T, _ item: Item) -> Bool {
            delete(item)
            guard let data = try? JSONEncoder().encode(value) else { return false }
            var q = base(item)
            q[kSecValueData as String] = data
            q[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly
            return SecItemAdd(q as CFDictionary, nil) == errSecSuccess
        }
        static func load<T: Decodable>(_ type: T.Type, _ item: Item) -> T? {
            var q = base(item)
            q[kSecReturnData as String] = true
            q[kSecMatchLimit as String] = kSecMatchLimitOne
            var out: AnyObject?
            guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess, let data = out as? Data else { return nil }
            return try? JSONDecoder().decode(type, from: data)
        }
        static func delete(_ item: Item) { SecItemDelete(base(item) as CFDictionary) }
```
