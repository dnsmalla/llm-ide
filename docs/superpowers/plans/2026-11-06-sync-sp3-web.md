# Sync SP3: the web app (PWA) sync tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With the desktop off, the web app (`web/`) pairs with the desktop through the user's MEGA folder, reads the latest verified encrypted snapshots (chats, meetings with notes, plans/tasks, usage) with a clear "last updated, desktop offline" age, and queues chat prompts whose replies appear when the desktop is back.

**Architecture:** A new `web/src/sync/` folder implements the device side of the sync v1 device contract in WebCrypto: the envelope (`envelope.ts`), enrollment crypto (`enroll.ts`), non-extractable device keys persisted in IndexedDB (`keystore.ts`), the device steps over any store (`device.ts`, a WebCrypto twin of SP2's Node reference device), a browser MEGA store on megajs 1.3.10 (`mega-store.ts`), and a React-free controller (`controller.ts`) that polls, tracks staleness and switches between offline sync and the live Host API. The existing `ReadPanel` renders the snapshot through the same `ReadState` the Host API read controller fills; a new `SyncTier` screen adds pairing, unlock, staleness and the prompt inbox. Tests run the shared vectors, a fake desktop built from the shipped Node core, a malicious store, the shared fake MEGA, and (e2e) the real desktop sync code in-process.

**Tech Stack:** TypeScript 5.9 + React 19 (web/), WebCrypto (ECDSA/ECDH P-256 with `deriveBits`, HKDF-SHA-256, HMAC-SHA-256, AES-256-GCM), IndexedDB, `megajs` 1.3.10 (MIT, exact pin), Vite 7, `node --test --experimental-strip-types` (Node 22).

**Spec:** `docs/superpowers/specs/2026-11-05-box-encrypted-sync-design.md` (§3 layout, §4 formats, §5 keys, §6 ceiling, §7 ordering, §8.3 MEGA incl. PWA access, §11 privacy, §12 failures, §13 tests, §14 SP3 row, §15 Q5/Q8), ADR `docs/decisions/0020-box-encrypted-sync.md`. Read with: the SP2 plan `docs/superpowers/plans/2026-11-06-sync-sp2-enrollment.md`, **section "Device contract (SP3 WebCrypto, SP4 Swift)" — normative for this plan**, its Node reference device (`extension/tests/helpers/sync-device.mjs`, SP2 Task 2), `schema/sync/v1/README.md` ("Enrollment (device contract)"), `extension/core/sync-envelope.mjs`, `extension/core/sync-enroll.mjs`, `extension/routes/sync/{producer,consumer,kinds}.mjs`, `extension/connectors/sync-store/{index,mega}.mjs`, and the existing web client (`web/src/relay/{wire,crypto}.ts`, `web/src/read/controller.ts`, `web/src/screens/ReadPanel.tsx`, `web/src/App.tsx`).

## Global Constraints

- **Prerequisite: SP2 is committed.** This plan uses SP2's names exactly: `extension/core/sync-enroll.mjs` (`pairUrl`, `parsePair`, `enrollKeys`, `openClaim`, `sealAck`, `sealClaim`, `sasCode`, `newId22`, `p256Spki`), the `enroll` block and `keys.deviceSigningPkcs8`/`keys.deviceSigningSpki` in `schema/sync/v1/vectors/v1.json`, `extension/routes/sync/enroll.mjs` (`startEnrollment`, `pollEnrollment`, `confirmEnrollment`), and `writeDeviceWrap` in `producer.mjs`. Task 1 Step 1 checks this and stops if SP2 is missing.
- **The device contract is normative:** SP2 plan "Device contract" items 1–6 and `schema/sync/v1/README.md` "Enrollment". The browser is always tier `"web"`. Two deliberate, documented deviations (Task 9 records them in the README): a missing `manifest.bin` with `key.bin` present means "waiting for the first snapshot", not "removed" (the desktop publishes up to 60 s after confirm); the device swaps to the new epoch's keys as soon as a newer `wrap.bin` verifies (it is desktop-signed), not after the new manifest verifies.
- **Malicious storage model** (SP2): MEGA, or anyone holding the MEGA login, can read, replace, replay or delete any file at any time. No byte read from storage is used before it is verified with the desktop key pinned from the QR's `sfp`, or the enrollment keys derived from the QR's `es`. A refused file changes no persisted device state.
- **Keys are never extractable.** Every private key and every symmetric key is created or imported with `extractable: false`. ECDH uses `deriveBits`; raw HKDF/ECDH output is zeroed right after import. No code in `web/src/sync/` calls `exportKey("pkcs8" | "jwk" | "raw")`, or `generateKey`/`importKey("raw" | "pkcs8")` with `true` (a source test enforces it). Public keys are exported only as SPKI.
- **MEGA password:** typed once per app session, passed only to the megajs login, never stored (not in IndexedDB, `localStorage`, controller state, or logs). megajs deletes it from its options after deriving the key. The MEGA email may be remembered in the IndexedDB device record (decision D2). No 2FA code is ever sent (spec §8.3; the dedicated account has 2FA off).
- **No plaintext ever written to MEGA.** The device writes exactly two kinds of files: its sealed `enroll` claim (`<sid>/e/<slot>/<Id22>.bin`) and sealed `request` envelopes (`<sid>/d/<dir>/in/<13-digit ms>-<requestId>.bin`). It never replaces or deletes a file (one writer per file, spec §3), and never creates `<sync folder>`, `<sid>` or `d/<dir>`.
- **Read-only ceiling:** the only request the web app can send is `{"v":1,"requestId":<Id22>,"class":"chat.send","text":<1..4000 chars>}` (spec §4.4, `consumer.mjs` `parseRequest`). At most 5 prompts wait per device (decision D8).
- **Nothing decrypted is persisted.** Snapshots and reply texts live in memory for the session only; prompt texts too (only `requestId` + `issuedAt` are persisted, decision D3). Lock drops them.
- **`megajs` 1.3.10, exact pin** in `web/package.json` (same as SP1 `extension/package.json`), loaded with a dynamic `import("megajs")` so its chunk loads only when sync is used. Every newly locked package must be MIT or ISC (checked in Task 6).
- **CSP: one minimal change.** `connect-src` gains exactly `https://g.api.mega.co.nz https://*.userstorage.mega.co.nz` in `web/vite.config.ts`, `web/scripts/serve.mjs`, `deploy/vps/llm-ide.com.nginx` and the Caddy example in `web/DEPLOY.md`. `script-src` stays `'self'`; no `unsafe-eval`, no `wasm-unsafe-eval`.
- **Tests:** `cd web && npm test` (`node --test --experimental-strip-types tests/*.test.mjs`) and `npx tsc --noEmit -p .`. No real network: MEGA is `extension/tests/helpers/fake-mega.mjs`; the desktop is either `web/tests/helpers/fake-desktop.mjs` (shipped Node core, no DB) or, in `tests/e2e/`, the real desktop sync code. A test that needs `extension/node_modules` skips with a reason when it is absent (Windows CI installs no extension dependencies).
- **Do not modify** any extension production file, `schema/**` vectors, `scripts/sync-vectors.mjs`, or anything under `desktop/src-tauri/`. The one extension change is the test helper `extension/tests/helpers/fake-mega.mjs` (accept `Uint8Array`, Task 6).
- **Web conventions** (`web/tests/scaffold.test.mjs`): exact version pins only; no `dangerouslySetInnerHTML`, `innerHTML`, `eval(` or `new Function` in `web/src`; every string from storage renders as React text or through the shared `Markdown` view.
- **Accessibility:** every input has a `<label htmlFor>`; progress uses `role="status"` + `aria-live="polite"`; errors use `role="alert"` (`StatusBanner severity="error"`); the SAS has a spoken `aria-label`; focus moves to the SAS heading when it appears; everything is reachable by keyboard with native buttons, `details`/`summary` and forms.
- Commit on `main` (user rule: no branches), Conventional Commits, one concern per commit, each message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not push.

```ts
// Sync v1 envelope (schema/sync/v1) in WebCrypto for a device: relay v1 bytes plus the sync purposes. A port of
// extension/core/sync-envelope.mjs with the same error codes, checked against schema/sync/v1/vectors/v1.json.
// Verify before decrypt; unknown fields, purposes and versions fail closed. Every key is a non-extractable CryptoKey.
import { b64u, concat, decodeEnc as rawDecodeEnc, enc, pad, unb64u, unpad, utf8 } from "../relay/wire.ts";

// TypeScript 5.7 narrows BufferSource to ArrayBuffer-backed views; WebCrypto accepts any Uint8Array at runtime.
const subtle: any = globalThis.crypto.subtle;
const ECDSA = { name: "ECDSA", hash: "SHA-256" } as const;
export const PURPOSES = ["request", "reply", "snapshot", "manifest", "syncwrap", "enroll", "enrollack"] as const;
export type SyncPurpose = (typeof PURPOSES)[number];
export interface SyncHeader {
  purpose: SyncPurpose; userId: string; desktopId: string; from: string; to: string;
  epoch: number; session: string; seq: number; issuedAt: number; tier: "" | "web" | "ios";
}
export interface SyncEnvelope extends SyncHeader { v: 1; nonce: string; ct: string; sig: string; eph?: string }
export interface WrapKeys { request: CryptoKey; reply: CryptoKey; snapshot: CryptoKey; manifest: CryptoKey }
const ID_KEYS = ["purpose", "userId", "desktopId", "from", "to", "epoch", "session", "seq", "issuedAt", "tier"] as const;
const ENV_KEYS = new Set<string>(["v", ...ID_KEYS, "nonce", "ct", "sig", "eph"]);

export class SyncCryptoError extends Error {
  readonly code: string;
  constructor(code: string) { super(code); this.code = code; this.name = "SyncCryptoError"; }
}
export const fail = (code: string): never => { throw new SyncCryptoError(code); };
/** wire.ts throws plain Errors whose message is the code (bad_encoding, bad_padding, bad_base64, frame_too_large…). */
function coded<T>(f: () => T): T {
  try { return f(); } catch (e) {
    if (e instanceof SyncCryptoError) throw e;
    const m = e instanceof Error ? e.message : "";
    throw new SyncCryptoError(/^[a-z_]+$/.test(m) ? m : "bad_encoding");
  }
}
export const decodeEnc = (b: Uint8Array, count: number) => coded(() => rawDecodeEnc(b, count));
const b64 = (s: unknown): Uint8Array => (typeof s === "string" ? coded(() => unb64u(s)) : fail("bad_base64"));
export const hex = (b: Uint8Array) => Array.from(b, (x) => x.toString(16).padStart(2, "0")).join("");
const context = (p: string) => utf8(`llmide/${p}/v1\0`);
const headerFields = (h: SyncHeader) => [1, h.purpose, h.userId, h.desktopId, h.from, h.to, h.epoch, h.session, h.seq, h.issuedAt, h.tier];
const headerOf = (e: SyncHeader): SyncHeader => Object.fromEntries(ID_KEYS.map((k) => [k, e[k]])) as unknown as SyncHeader;

export async function sha256(...parts: Uint8Array[]): Promise<Uint8Array> {
  return new Uint8Array(await subtle.digest("SHA-256", concat(...parts)));
}
export const importAes = (raw: Uint8Array, usage: "encrypt" | "decrypt"): Promise<CryptoKey> => subtle.importKey("raw", raw, "AES-GCM", false, [usage]);
export const importVerify = (spki: Uint8Array): Promise<CryptoKey> => subtle.importKey("spki", spki, { name: "ECDSA", namedCurve: "P-256" }, false, ["verify"]);

export async function seal(o: { header: SyncHeader; key: CryptoKey; plaintext: Uint8Array; signingKey: CryptoKey; nonce?: Uint8Array; extra?: Uint8Array }): Promise<SyncEnvelope> {
  if (!PURPOSES.includes(o.header.purpose)) fail("bad_purpose");
  const nonce = o.nonce ?? globalThis.crypto.getRandomValues(new Uint8Array(12));
  const extra = o.extra ?? new Uint8Array(0);
  const fields = headerFields(o.header);
  const body = coded(() => pad(o.plaintext));
  const ct = new Uint8Array(await subtle.encrypt({ name: "AES-GCM", iv: nonce, additionalData: coded(() => enc([...fields, extra])), tagLength: 128 }, o.key, body));
  const sig = new Uint8Array(await subtle.sign(ECDSA, o.signingKey, concat(context(o.header.purpose), coded(() => enc([...fields, extra, nonce, ct])))));
  return { v: 1, ...headerOf(o.header), nonce: b64u(nonce), ct: b64u(ct), sig: b64u(sig), ...(extra.length ? { eph: b64u(extra) } : {}) };
}

export async function open(o: { env: unknown; key: CryptoKey; verifyKey: CryptoKey; expect?: Partial<SyncHeader> }): Promise<Uint8Array> {
  const env = o.env as SyncEnvelope;
  if (!env || typeof env !== "object" || Array.isArray(env) || Object.keys(env).some((k) => !ENV_KEYS.has(k))) fail("bad_envelope");
  if (env.v !== 1) fail("bad_version");
  if (!PURPOSES.includes(env.purpose)) fail("bad_purpose");
  const header = headerOf(env);
  for (const [k, v] of Object.entries(o.expect ?? {})) if ((header as unknown as Record<string, unknown>)[k] !== v) fail(`bad_${k}`);
  const extra = env.eph ? b64(env.eph) : new Uint8Array(0);
  const nonce = b64(env.nonce); const ct = b64(env.ct);
  if (nonce.length !== 12 || ct.length < 16 + 1024) fail("bad_ciphertext");
  const fields = headerFields(header);
  let ok = false;
  try { ok = await subtle.verify(ECDSA, o.verifyKey, b64(env.sig), concat(context(env.purpose), enc([...fields, extra, nonce, ct]))); } catch { ok = false; }
  if (!ok) fail("bad_signature");
  let pt: ArrayBuffer;
  try { pt = await subtle.decrypt({ name: "AES-GCM", iv: nonce, additionalData: enc([...fields, extra]), tagLength: 128 }, o.key, ct); }
  catch { return fail("bad_ciphertext"); }
  return coded(() => unpad(new Uint8Array(pt)));
}

/** Device side of the syncwrap (design 5.2 step 5): ECDH by deriveBits, HKDF, verify with the pinned key, then import. */
export async function unwrapSync(o: { env: SyncEnvelope; ecdhPrivate: CryptoKey; deviceEcdhSpki: Uint8Array; desktopSigningSpki: Uint8Array;
  verifyKey: CryptoKey; currentEpoch: number; deviceId: string }): Promise<WrapKeys> {
  const env = o.env;
  if (env?.purpose !== "syncwrap" || !env.eph) fail("bad_purpose");
  if (env.to !== o.deviceId) fail("bad_to");
  if (!(env.epoch > o.currentEpoch)) fail("stale_epoch");
  const ephSpki = b64(env.eph);
  let ephKey: CryptoKey;
  try { ephKey = await subtle.importKey("spki", ephSpki, { name: "ECDH", namedCurve: "P-256" }, false, []); } catch { return fail("bad_key"); }
  const z = new Uint8Array(await subtle.deriveBits({ name: "ECDH", public: ephKey }, o.ecdhPrivate, 256));
  const hk = await subtle.importKey("raw", z, "HKDF", false, ["deriveBits"]);
  z.fill(0);
  const [devHash, deskHash] = [await sha256(o.deviceEcdhSpki), await sha256(o.desktopSigningSpki)];
  const info = coded(() => enc(["llmide/syncwrap/v1", env.epoch, o.deviceId, devHash, deskHash, env.tier]));
  const raw = new Uint8Array(await subtle.deriveBits({ name: "HKDF", hash: "SHA-256", salt: await sha256(enc([ephSpki, o.deviceEcdhSpki])), info }, hk, 256));
  const wrapKey = await importAes(raw, "decrypt");
  raw.fill(0);
  const parts = decodeEnc(await open({ env, key: wrapKey, verifyKey: o.verifyKey, expect: { purpose: "syncwrap" } }), 4);
  if (parts.some((p) => p.length !== 32)) fail("bad_wrap");
  const [rq, rp, sn, mf] = parts;
  const out = { request: await importAes(rq, "encrypt"), reply: await importAes(rp, "decrypt"), snapshot: await importAes(sn, "decrypt"), manifest: await importAes(mf, "decrypt") };
  for (const p of parts) p.fill(0);
  return out;
}
```

```ts
// Sync v1 enrollment, device side (schema/sync/v1/README.md "Enrollment"; SP2 extension/core/sync-enroll.mjs is the
// desktop twin). The enrollment secret es is turned into non-extractable keys at once and its bytes are zeroed; the
// SAS is computed only from values this device holds or that the desktop committed before it revealed nD.
import { b64u, enc, unb64u, utf8 } from "../relay/wire.ts";
import { decodeEnc, fail, importVerify, open, seal, sha256, type SyncEnvelope } from "./envelope.ts";

const subtle: any = globalThis.crypto.subtle;
export const ID22 = /^[A-Za-z0-9_-]{22}$/;
export const NAME_MAX = 64;
const FP43 = /^[A-Za-z0-9_-]{43}$/;
const ST_RE = /^(mega:[A-Za-z0-9_.-]{1,64}|memory:)$/; // memory: is the test adapter only; the controller refuses it
const USER_RE = /^[A-Za-z0-9_-]{1,128}$/;
const PAIR_FIELDS = ["sid", "sfp", "dir", "slot", "es", "st"] as const;
export type Tier = "web" | "ios";
export interface Pair { sid: string; sfp: string; dir: string; slot: string; es: string; st: string }
export interface Claim { deviceId: string; ecdhSpki: Uint8Array; signingSpki: Uint8Array; name: string }
export interface EnrollKeys { enroll: CryptoKey; enrollack: CryptoKey; bind: CryptoKey; sas: CryptoKey }
type Bound = Pick<Pair, "sid" | "slot" | "dir" | "sfp"> & Claim & { tier: Tier };

export const newId22 = () => b64u(globalThis.crypto.getRandomValues(new Uint8Array(16)));

export function parsePair(url: unknown): Pair {
  if (typeof url !== "string") fail("bad_pair");
  const u = url as string;
  let q = "";
  if (u.startsWith("llmide://pair?")) q = u.slice("llmide://pair?".length);
  else {
    const i = u.indexOf("#pair=");
    if (i < 0) fail("bad_pair");
    try { q = decodeURIComponent(u.slice(i + "#pair=".length)); } catch { fail("bad_pair"); }
  }
  const s = new URLSearchParams(q);
  if (s.get("sv") !== "1") fail("bad_pair");
  const p = Object.fromEntries(PAIR_FIELDS.map((k) => [k, s.get(k) ?? ""])) as unknown as Pair;
  if (![p.sid, p.dir, p.slot, p.es].every((v) => ID22.test(v)) || !FP43.test(p.sfp) || !ST_RE.test(p.st)) fail("bad_pair");
  return p;
}

export async function enrollKeys(es: Uint8Array, sid: string, slot: string): Promise<EnrollKeys> {
  if (es.length !== 16) fail("bad_secret");
  const hk = await subtle.importKey("raw", es, "HKDF", false, ["deriveBits"]);
  const salt = await sha256(utf8("llmide-sync-enroll-v1"));
  const raw = async (label: string) => new Uint8Array(await subtle.deriveBits({ name: "HKDF", hash: "SHA-256", salt, info: enc([label, sid, slot]) }, hk, 256));
  const make = async (label: string, alg: unknown, usage: string): Promise<CryptoKey> => {
    const r = await raw(label);
    try { return await subtle.importKey("raw", r, alg, false, [usage]); } finally { r.fill(0); }
  };
  const hmac = { name: "HMAC", hash: "SHA-256" };
  return { enroll: await make("enroll", "AES-GCM", "encrypt"), enrollack: await make("enrollack", "AES-GCM", "decrypt"),
    bind: await make("bind", hmac, "sign"), sas: await make("sas", hmac, "sign") };
}

export const deviceIdOf = async (signingSpki: Uint8Array) => b64u((await sha256(signingSpki)).subarray(0, 16));

/** A canonical P-256 SPKI (re-export gives the same bytes), returned as a non-extractable verify key. The temporary
 *  import is extractable only to compare bytes; it is a public key. */
export async function p256Spki(bytes: Uint8Array): Promise<CryptoKey> {
  let k: CryptoKey;
  try { k = await subtle.importKey("spki", bytes, { name: "ECDSA", namedCurve: "P-256" }, true, ["verify"]); } catch { return fail("bad_key"); }
  const again = new Uint8Array(await subtle.exportKey("spki", k));
  if (again.length !== bytes.length || again.some((x, i) => x !== bytes[i])) fail("bad_key");
  return importVerify(bytes);
}

export const validName = (n: unknown): n is string =>
  typeof n === "string" && n.length >= 1 && n.length <= NAME_MAX && !/[\u0000-\u001f\u007f]/.test(n);
const checkTier = (t: unknown) => { if (t !== "web" && t !== "ios") fail("bad_tier"); };
const bound = (f: Bound) => [f.sid, f.slot, f.dir, unb64u(f.sfp), f.tier, f.deviceId, f.ecdhSpki, f.signingSpki, f.name];
const equal = (a: Uint8Array, b: Uint8Array) => { let d = a.length ^ b.length; for (let i = 0; i < Math.min(a.length, b.length); i++) d |= a[i] ^ b[i]; return d === 0; };

export const claimMac = async (bind: CryptoKey, f: Bound) => new Uint8Array(await subtle.sign("HMAC", bind, enc(bound(f))));
export const claimHash = (c: Claim) => sha256(enc(["llmide/sync-claim/v1", c.deviceId, c.ecdhSpki, c.signingSpki, c.name]));
export async function sasCode(sasKey: CryptoKey, f: Bound & { nD: Uint8Array }): Promise<string> {
  const h = new Uint8Array(await subtle.sign("HMAC", sasKey, enc([...bound(f), f.nD])));
  return String(new DataView(h.buffer).getUint32(0) % 1_000_000).padStart(6, "0");
}

/** Contract 4c: the claim for e/<slot>/<Id22>.bin; extra = the signing SPKI so the desktop verifies before decrypting. */
export async function sealClaim(o: { pair: Pair; tier: Tier; name: string; ecdhSpki: Uint8Array; signingSpki: Uint8Array; signingKey: CryptoKey;
  issuedAt: number; keys: EnrollKeys; nonce?: Uint8Array }): Promise<SyncEnvelope> {
  checkTier(o.tier);
  if (!validName(o.name)) fail("bad_name");
  const deviceId = await deviceIdOf(o.signingSpki);
  const mac = await claimMac(o.keys.bind, { ...o.pair, tier: o.tier, deviceId, ecdhSpki: o.ecdhSpki, signingSpki: o.signingSpki, name: o.name });
  return seal({ header: { purpose: "enroll", userId: "", desktopId: o.pair.sid, from: deviceId, to: o.pair.sid, epoch: 0, session: o.pair.slot, seq: 0, issuedAt: o.issuedAt, tier: "" },
    key: o.keys.enroll, plaintext: enc([o.ecdhSpki, o.signingSpki, o.name, mac]), signingKey: o.signingKey, extra: o.signingSpki, nonce: o.nonce });
}

/** Contract 4d: verify the ack with the key pinned by sfp; refuse an ack bound to anyone else's claim. */
export async function openAck(o: { env: unknown; pair: Pair; tier: Tier; claim: Claim; keys: EnrollKeys; desktopVerifyKey: CryptoKey }): Promise<{ userId: string; nD: Uint8Array }> {
  checkTier(o.tier);
  const pt = await open({ env: o.env, key: o.keys.enrollack, verifyKey: o.desktopVerifyKey,
    expect: { purpose: "enrollack", desktopId: o.pair.sid, from: o.pair.sid, to: o.claim.deviceId, epoch: 0, session: o.pair.slot, tier: o.tier } });
  const [nD, hash] = decodeEnc(pt, 2);
  if (nD.length !== 16 || hash.length !== 32) fail("bad_ack");
  if (!equal(hash, await claimHash(o.claim))) fail("ack_mismatch");
  const userId = (o.env as SyncEnvelope).userId;
  if (typeof userId !== "string" || !USER_RE.test(userId)) fail("bad_userId");
  return { userId, nD: new Uint8Array(nD) };
}
```

```ts
// This browser's sync identity (design 5.1): P-256 ECDH and ECDSA pairs generated non-extractable, and one device record
// in IndexedDB holding CryptoKey objects (structured clone keeps them non-extractable), public SPKIs, the pinned desktop
// SPKI, the epoch, the wrap keys and counters. Never the MEGA password, never decrypted content.
import type { WrapKeys } from "./envelope.ts";

const subtle: any = globalThis.crypto.subtle;
export interface DeviceKeyPairs { ecdhPrivate: CryptoKey; ecdhSpki: Uint8Array; signingPrivate: CryptoKey; signingSpki: Uint8Array }
export interface LinkedDevice extends DeviceKeyPairs {
  v: 1; sid: string; dir: string; st: string; tier: "web"; name: string; deviceId: string; userId: string;
  desktopSpki: Uint8Array; epoch: number; keys: WrapKeys; prevReply: { epoch: number; key: CryptoKey; until: number } | null;
  manifestSeq: number; reqSeq: number; pending: Array<{ requestId: string; issuedAt: number }>; megaEmail: string;
}
export interface KeyStore { load(): Promise<LinkedDevice | null>; save(d: LinkedDevice): Promise<void>; clear(): Promise<void> }

export async function generateDeviceKeys(): Promise<DeviceKeyPairs> {
  const ecdh = await subtle.generateKey({ name: "ECDH", namedCurve: "P-256" }, false, ["deriveBits"]);
  const sig = await subtle.generateKey({ name: "ECDSA", namedCurve: "P-256" }, false, ["sign", "verify"]);
  return {
    ecdhPrivate: ecdh.privateKey, ecdhSpki: new Uint8Array(await subtle.exportKey("spki", ecdh.publicKey)),
    signingPrivate: sig.privateKey, signingSpki: new Uint8Array(await subtle.exportKey("spki", sig.publicKey)),
  };
}

/** Tests, and the fallback when this browser has no usable IndexedDB (the link then lasts for this page only). */
export function memoryKeyStore(): KeyStore {
  let rec: LinkedDevice | null = null;
  return { load: async () => rec, save: async (d) => { rec = d; }, clear: async () => { rec = null; } };
}

const DB = "llmide-sync"; const STORE = "device"; const KEY = "device";
const req = <T>(r: IDBRequest<T>) => new Promise<T>((res, rej) => { r.onsuccess = () => res(r.result); r.onerror = () => rej(r.error); });
const done = (t: IDBTransaction) => new Promise<void>((res, rej) => { t.oncomplete = () => res(); t.onerror = () => rej(t.error); t.onabort = () => rej(t.error); });

export function indexedDbKeyStore(idb: IDBFactory | undefined = globalThis.indexedDB): KeyStore | null {
  if (!idb) return null;
  let dbp: Promise<IDBDatabase> | null = null;
  const db = () => (dbp ??= new Promise<IDBDatabase>((res, rej) => {
    const r = idb.open(DB, 1);
    r.onupgradeneeded = () => { r.result.createObjectStore(STORE); };
    r.onsuccess = () => res(r.result);
    r.onerror = () => { dbp = null; rej(r.error); };
  }));
  const write = async (fn: (s: IDBObjectStore) => void) => { const t = (await db()).transaction(STORE, "readwrite"); const end = done(t); fn(t.objectStore(STORE)); await end; };
  return {
    async load() { return ((await req((await db()).transaction(STORE, "readonly").objectStore(STORE).get(KEY))) as LinkedDevice | undefined) ?? null; },
    save: (d) => write((s) => { s.put(d, KEY); }),
    clear: () => write((s) => { s.delete(KEY); }),
  };
}
```

```js
// A desktop built from the shipped Node core (extension/core/sync-envelope.mjs + sync-enroll.mjs), the same functions the
// SP1/SP2 desktop calls, with the producer's exact headers (extension/routes/sync/producer.mjs) and the consumer's reply
// format (consumer.mjs). It runs over any SyncStore and needs no database, so it also runs on Windows CI. The real desktop
// code is exercised in tests/e2e/sync-desktop-e2e.test.mjs.
import { createPublicKey, randomBytes } from 'node:crypto';
import * as S from '../../../extension/core/sync-envelope.mjs';
import * as E from '../../../extension/core/sync-enroll.mjs';

const bytesOf = (env) => Buffer.from(JSON.stringify(env));

export function createFakeDesktop({ store, userId = 'user-AAAAAAAAAAAAAAAAAAAAAA', tier = 'web', webOrigin = 'https://llm-ide.com', st = 'memory:' } = {}) {
  const signing = S.newSigningKey();
  const d = { store, userId, sid: E.newId22(), epoch: 1, root: randomBytes(32), seq: 1000, signing, prevRoot: null, devices: new Map(), lastSas: null };
  const next = () => ++d.seq;
  const ids = (deviceId) => ({ userId, desktopId: d.sid, deviceId });
  const keysOf = (deviceId, root = d.root, epoch = d.epoch) => S.deviceKeys(root, ids(deviceId), epoch);
  let pending = null;
  return Object.assign(d, {
    /** Settings "Add a phone or browser": key.bin first, then the QR. */
    async open(now = Date.now()) {
      const es = randomBytes(16);
      const pair = { sid: d.sid, sfp: S.spkiFingerprint(signing.spki), dir: E.newId22(), slot: E.newId22(), es: es.toString('base64url'), st };
      pending = { pair, keys: E.enrollKeys(es, pair.sid, pair.slot), claim: null };
      d.lastSas = null;
      await store.put(`${d.sid}/d/${pair.dir}/key.bin`, signing.spki);
      return E.pairUrl(pair, tier, webOrigin);
    },
    /** Pin the one claim, write the signed ack; returns the desktop's SAS, or null while there is no single claim. */
    async take(now = Date.now()) {
      const dir = `${d.sid}/e/${pending.pair.slot}`;
      const files = (await store.list(dir)).filter((f) => f.name !== 'ack.bin');
      if (files.length !== 1) return null;
      const claim = E.openClaim({ env: JSON.parse(Buffer.from(await store.get(`${dir}/${files[0].name}`)).toString()), pair: pending.pair, tier, keys: pending.keys });
      const nD = randomBytes(16);
      await store.put(`${dir}/ack.bin`, bytesOf(E.sealAck({ userId, pair: pending.pair, tier, claim, nD, keys: pending.keys, signingKey: signing.privateKey, seq: next(), issuedAt: now })));
      pending.claim = claim;
      d.lastSas = E.sasCode(pending.keys.sas, { ...pending.pair, tier, ...claim, nD });
      return d.lastSas;
    },
    /** "Codes match": registry row (tier = the desktop's choice), wrap.bin, then the slot is deleted. */
    async confirm(now = Date.now()) {
      const dev = { ...pending.claim, dir: pending.pair.dir, tier };
      d.devices.set(dev.deviceId, dev);
      await d.writeWrap(dev, now);
      await store.removeTree(`${d.sid}/e/${pending.pair.slot}`);
      pending = null;
      return dev;
    },
    async writeWrap(dev, now = Date.now(), wrapTier = dev.tier) {
      const w = S.makeSyncWrap({ ids: ids(dev.deviceId), epoch: d.epoch, tier: wrapTier, deviceEcdhSpki: dev.ecdhSpki, desktopSigningSpki: signing.spki,
        keys: keysOf(dev.deviceId), signingKey: signing.privateKey, seq: next(), issuedAt: now });
      await store.put(`${d.sid}/d/${dev.dir}/wrap.bin`, bytesOf(w));
    },
    /** producer.mjs publishOnce for one device: fresh blob names, then the manifest. kinds = { chats: { items }, … }. */
    async publish(dev, kinds, now = Date.now(), { validFor = 45 * 60_000 } = {}) {
      const base = `${d.sid}/d/${dev.dir}`;
      const dk = keysOf(dev.deviceId);
      const header = (purpose, seq) => ({ purpose, userId, desktopId: d.sid, from: d.sid, to: dev.deviceId, epoch: d.epoch, session: '', seq, issuedAt: now, tier: '' });
      const entries = {};
      for (const [kind, body] of Object.entries(kinds)) {
        const seq = next();
        const frame = Buffer.from(JSON.stringify({ v: 1, kind, generatedAt: now, truncated: false, ...body }));
        const bytes = bytesOf(S.seal({ header: header('snapshot', seq), key: dk.snapshot, plaintext: frame, signingKey: signing.privateKey }));
        const file = `s/${randomBytes(16).toString('hex')}.bin`;
        await store.put(`${base}/${file}`, bytes);
        entries[kind] = { file, seq, sha256: S.sha256(bytes).toString('hex') };
      }
      const manifestSeq = next();
      const m = { v: 1, manifestSeq, epoch: d.epoch, generatedAt: now, validUntil: now + validFor, kinds: entries };
      await store.put(`${base}/manifest.bin`, bytesOf(S.seal({ header: header('manifest', manifestSeq), key: dk.manifest, plaintext: Buffer.from(JSON.stringify(m)), signingKey: signing.privateKey })));
      return m;
    },
    /** Design 5.3: new root, epoch + 1, a new wrap per device; the old root answers old-epoch requests with stale_epoch. */
    async rotate(now = Date.now()) {
      d.prevRoot = { root: d.root, epoch: d.epoch };
      d.root = randomBytes(32); d.epoch += 1;
      for (const dev of d.devices.values()) await d.writeWrap(dev, now);
    },
    /** consumer.mjs drainOnce, minus the turn: verify each request, answer it, delete the inbox file. */
    async drain(dev, answer = (req) => ({ ok: true, text: `echo: ${req.text}` }), now = Date.now()) {
      const base = `${d.sid}/d/${dev.dir}`;
      const verifyKey = createPublicKey({ key: Buffer.from(dev.signingSpki), format: 'der', type: 'spki' });
      const out = [];
      for (const f of await store.list(`${base}/in`)) {
        const env = JSON.parse(Buffer.from(await store.get(`${base}/in/${f.name}`)).toString());
        const old = env.epoch !== d.epoch && d.prevRoot && env.epoch === d.prevRoot.epoch;
        const root = old ? d.prevRoot.root : d.root; const epoch = old ? d.prevRoot.epoch : d.epoch;
        const req = JSON.parse(S.open({ env, key: keysOf(dev.deviceId, root, epoch).request, verifyKey,
          expect: { purpose: 'request', userId, desktopId: d.sid, from: dev.deviceId, to: d.sid, epoch } }).toString());
        const body = old ? { ok: false, code: 'stale_epoch' } : answer(req);
        const plain = { v: 1, requestId: req.requestId, ...(body.ok ? { ok: true, text: body.text, finishedAt: now } : body) };
        await store.put(`${base}/out/${req.requestId}.bin`, bytesOf(S.seal({ header: { purpose: 'reply', userId, desktopId: d.sid, from: d.sid, to: dev.deviceId,
          epoch, session: '', seq: next(), issuedAt: now, tier: '' }, key: keysOf(dev.deviceId, root, epoch).reply, plaintext: Buffer.from(JSON.stringify(plain)), signingKey: signing.privateKey })));
        await store.remove(`${base}/in/${f.name}`);
        out.push({ name: f.name, header: env, ...req });
      }
      return out;
    },
  });
}
```

```ts
// The browser's side of the sync v1 device contract (schema/sync/v1/README.md "Enrollment" items 1-6; design 4.3-4.4,
// 5.3). A WebCrypto twin of the Node reference device (extension/tests/helpers/sync-device.mjs). Every byte read from
// storage is verified with the desktop key pinned by the QR's sfp before use, and persisted state moves only after a
// file verified. The device writes only its sealed claim and sealed requests, each under a new unique name.
import { b64u, unb64u, utf8 } from "../relay/wire.ts";
import { fail, hex, importVerify, open, seal, sha256, unwrapSync, type SyncEnvelope } from "./envelope.ts";
import { deviceIdOf, enrollKeys, newId22, openAck, p256Spki, sasCode, sealClaim, type EnrollKeys, type Pair } from "./enroll.ts";
import { generateDeviceKeys, type DeviceKeyPairs, type LinkedDevice } from "./keystore.ts";
import { KINDS, type Snapshot } from "./kinds.ts";

export interface DeviceStore { get(path: string): Promise<Uint8Array | null>; put(path: string, bytes: Uint8Array, mkdirFrom?: number): Promise<void> }
export type BlobCache = Map<string, { sha256: string; frame: unknown }>;
export const MAX_TEXT = 4000;
export const PREV_REPLY_MS = 86_400_000;
export const REPLY_CODES = ["expired", "quota", "needs_approval", "turn_failed", "refused", "stale_epoch"] as const;
export type Reply = { v: 1; requestId: string; ok: true; text: string; finishedAt: number }
  | { v: 1; requestId: string; ok: false; code: (typeof REPLY_CODES)[number] };
export interface Enrolling {
  pair: Pair; keys: EnrollKeys; dev: DeviceKeyPairs; deviceId: string; name: string; claimPath: string; claimBytes: Uint8Array;
  desktopSpki: Uint8Array; desktopVerify: CryptoKey; userId: string | null;
}

const td = new TextDecoder("utf-8", { fatal: true });
function json(bytes: Uint8Array, code: string): any { try { return JSON.parse(td.decode(bytes)); } catch { return fail(code); } }
const exactKeys = (o: unknown, keys: string[]) => !!o && typeof o === "object" && !Array.isArray(o) && Object.keys(o).sort().join() === [...keys].sort().join();
const safeInt = (n: unknown): n is number => Number.isSafeInteger(n) && (n as number) >= 0;
const base = (d: { sid: string; dir: string }) => `${d.sid}/d/${d.dir}`;
const BLOB_FILE = /^s\/[0-9a-f]{32}\.bin$/;
const HEX64 = /^[0-9a-f]{64}$/;
const claimOf = (e: Enrolling) => ({ deviceId: e.deviceId, ecdhSpki: e.dev.ecdhSpki, signingSpki: e.dev.signingSpki, name: e.name });
const verifyKeys = new WeakMap<LinkedDevice, Promise<CryptoKey>>();
function verifyKeyOf(d: LinkedDevice): Promise<CryptoKey> {
  let k = verifyKeys.get(d);
  if (!k) { k = importVerify(d.desktopSpki); verifyKeys.set(d, k); }
  return k;
}

/** Contract 4a-4c: pin the desktop key by sfp, make this browser's keys, write the claim once. */
export async function startPairing(store: DeviceStore, pair: Pair, { name, now }: { name: string; now: number }): Promise<Enrolling> {
  const spki = await store.get(`${pair.sid}/d/${pair.dir}/key.bin`);
  if (!spki || b64u(await sha256(spki)) !== pair.sfp) fail("bad_desktop_key");
  let desktopVerify: CryptoKey;
  try { desktopVerify = await p256Spki(spki!); } catch { return fail("bad_desktop_key"); }
  const es = unb64u(pair.es);
  const keys = await enrollKeys(es, pair.sid, pair.slot);
  es.fill(0);
  const dev = await generateDeviceKeys();
  const env = await sealClaim({ pair, tier: "web", name, ecdhSpki: dev.ecdhSpki, signingSpki: dev.signingSpki, signingKey: dev.signingPrivate, issuedAt: now, keys });
  const e: Enrolling = { pair: { ...pair, es: "" }, keys, dev, deviceId: await deviceIdOf(dev.signingSpki), name, claimPath: `${pair.sid}/e/${pair.slot}/${newId22()}.bin`,
    claimBytes: utf8(JSON.stringify(env)), desktopSpki: new Uint8Array(spki!), desktopVerify, userId: null };
  await store.put(e.claimPath, e.claimBytes, 1);
  return e;
}

/** Contract 4d: the 6-digit code to show, or null while there is no ack. Throws on a forged ack or one for another claim. */
export async function readAck(store: DeviceStore, e: Enrolling): Promise<string | null> {
  const bytes = await store.get(`${e.pair.sid}/e/${e.pair.slot}/ack.bin`);
  if (!bytes) return null;
  const { userId, nD } = await openAck({ env: json(bytes, "bad_envelope"), pair: e.pair, tier: "web", claim: claimOf(e), keys: e.keys, desktopVerifyKey: e.desktopVerify });
  e.userId = userId;
  const sas = await sasCode(e.keys.sas, { ...e.pair, tier: "web", ...claimOf(e), nD });
  nD.fill(0);
  return sas;
}

function checkWrapHeader(env: SyncEnvelope, sid: string, userId: string) {
  if (!env || env.tier !== "web" || env.from !== sid || env.desktopId !== sid || env.userId !== userId) fail("bad_wrap");
}

/** Contract 4e: the first wrap.bin, verified with the pinned key; the linked record, or null while there is none. */
export async function readFirstWrap(store: DeviceStore, e: Enrolling, { megaEmail }: { megaEmail: string }): Promise<LinkedDevice | null> {
  if (!e.userId) return null;
  const bytes = await store.get(`${e.pair.sid}/d/${e.pair.dir}/wrap.bin`);
  if (!bytes) return null;
  const env = json(bytes, "bad_envelope") as SyncEnvelope;
  checkWrapHeader(env, e.pair.sid, e.userId);
  const keys = await unwrapSync({ env, ecdhPrivate: e.dev.ecdhPrivate, deviceEcdhSpki: e.dev.ecdhSpki, desktopSigningSpki: e.desktopSpki,
    verifyKey: e.desktopVerify, currentEpoch: 0, deviceId: e.deviceId });
  return { v: 1, sid: e.pair.sid, dir: e.pair.dir, st: e.pair.st, tier: "web", name: e.name, deviceId: e.deviceId, userId: e.userId,
    ...e.dev, desktopSpki: e.desktopSpki, epoch: env.epoch, keys, prevReply: null, manifestSeq: 0, reqSeq: 0, pending: [], megaEmail };
}

/** Contract 5: take wrap.bin when it is for a newer epoch. false = nothing newer. The old reply key stays 24 h. */
async function readNewerWrap(store: DeviceStore, d: LinkedDevice, now: number): Promise<boolean> {
  const bytes = await store.get(`${base(d)}/wrap.bin`);
  if (!bytes) return fail("removed");
  const env = json(bytes, "bad_envelope") as SyncEnvelope;
  checkWrapHeader(env, d.sid, d.userId);
  if (!safeInt(env.epoch) || !(env.epoch > d.epoch)) return false;
  const keys = await unwrapSync({ env, ecdhPrivate: d.ecdhPrivate, deviceEcdhSpki: d.ecdhSpki, desktopSigningSpki: d.desktopSpki,
    verifyKey: await verifyKeyOf(d), currentEpoch: d.epoch, deviceId: d.deviceId });
  d.prevReply = { epoch: d.epoch, key: d.keys.reply, until: now + PREV_REPLY_MS };
  d.keys = keys;
  d.epoch = env.epoch;
  return true;
}

/** Design 4.3: manifest (rollback-checked, epoch-checked), then each named blob by its SHA-256, then its envelope. */
export async function readSnapshot(store: DeviceStore, d: LinkedDevice, now: number, cache: BlobCache = new Map()): Promise<Snapshot | null> {
  const raw = await store.get(`${base(d)}/manifest.bin`);
  if (!raw) {
    if (!(await store.get(`${base(d)}/key.bin`))) fail("removed");
    return null; // linked, but the desktop has not published for this device yet
  }
  const env = json(raw, "bad_envelope") as SyncEnvelope;
  if (!safeInt(env?.epoch)) fail("bad_envelope");
  if (env.epoch > d.epoch && !(await readNewerWrap(store, d, now))) fail("bad_epoch");
  if (env.epoch < d.epoch) fail("rollback");
  const verifyKey = await verifyKeyOf(d);
  const expect = { userId: d.userId, desktopId: d.sid, from: d.sid, to: d.deviceId, epoch: d.epoch, session: "", tier: "" as const };
  const m = json(await open({ env, key: d.keys.manifest, verifyKey, expect: { ...expect, purpose: "manifest" } }), "bad_manifest");
  if (!exactKeys(m, ["v", "manifestSeq", "epoch", "generatedAt", "validUntil", "kinds"]) || m.v !== 1 || m.epoch !== d.epoch || m.manifestSeq !== env.seq
    || ![m.manifestSeq, m.generatedAt, m.validUntil].every(safeInt) || !m.kinds || typeof m.kinds !== "object" || Array.isArray(m.kinds)) fail("bad_manifest");
  if (m.manifestSeq < d.manifestSeq) fail("rollback");
  const kinds: Record<string, unknown> = {};
  const keep = new Set<string>();
  for (const [kind, e] of Object.entries(m.kinds as Record<string, any>)) {
    if (!(KINDS as readonly string[]).includes(kind) || !exactKeys(e, ["file", "seq", "sha256"]) || !BLOB_FILE.test(e.file) || !safeInt(e.seq) || !HEX64.test(e.sha256)) fail("bad_manifest");
    const ck = `${d.epoch}:${e.file}`;
    keep.add(ck);
    const hit = cache.get(ck);
    if (hit && hit.sha256 === e.sha256) { kinds[kind] = hit.frame; continue; }
    const bytes = await store.get(`${base(d)}/${e.file}`);
    if (!bytes) fail("updating");
    if (hex(await sha256(bytes!)) !== e.sha256) fail("bad_blob");
    const frame = json(await open({ env: json(bytes!, "bad_envelope"), key: d.keys.snapshot, verifyKey, expect: { ...expect, purpose: "snapshot", seq: e.seq } }), "bad_snapshot");
    if (!frame || frame.v !== 1 || frame.kind !== kind || !Array.isArray(frame.items) || typeof frame.truncated !== "boolean" || !safeInt(frame.generatedAt)) fail("bad_snapshot");
    cache.set(ck, { sha256: e.sha256, frame });
    kinds[kind] = frame;
  }
  for (const k of [...cache.keys()]) if (!keep.has(k)) cache.delete(k);
  d.manifestSeq = m.manifestSeq;
  return { generatedAt: m.generatedAt, validUntil: m.validUntil, manifestSeq: m.manifestSeq, kinds: kinds as Snapshot["kinds"] };
}

/** Design 4.4: the only class a device may queue (read-only ceiling, design 6). */
export async function sendRequest(store: DeviceStore, d: LinkedDevice, text: string, now: number): Promise<string> {
  if (typeof text !== "string" || text.length < 1 || text.length > MAX_TEXT) fail("bad_text");
  const requestId = newId22();
  const env = await seal({ header: { purpose: "request", userId: d.userId, desktopId: d.sid, from: d.deviceId, to: d.sid, epoch: d.epoch, session: "", seq: d.reqSeq + 1, issuedAt: now, tier: "" },
    key: d.keys.request, plaintext: utf8(JSON.stringify({ v: 1, requestId, class: "chat.send", text })), signingKey: d.signingPrivate });
  await store.put(`${base(d)}/in/${String(now).padStart(13, "0")}-${requestId}.bin`, utf8(JSON.stringify(env)), 3);
  d.reqSeq += 1;
  d.pending.push({ requestId, issuedAt: now });
  return requestId;
}

/** Design 4.4: out/<requestId>.bin under the current reply key, or the previous one for 24 h after a rotation. */
export async function readReply(store: DeviceStore, d: LinkedDevice, requestId: string, now: number): Promise<Reply | null> {
  const bytes = await store.get(`${base(d)}/out/${requestId}.bin`);
  if (!bytes) return null;
  const env = json(bytes, "bad_envelope") as SyncEnvelope;
  const prev = d.prevReply && now < d.prevReply.until ? d.prevReply : null;
  const key = env?.epoch === d.epoch ? d.keys.reply : prev && env?.epoch === prev.epoch ? prev.key : fail("bad_epoch");
  const r = json(await open({ env, key, verifyKey: await verifyKeyOf(d), expect: { purpose: "reply", userId: d.userId, desktopId: d.sid, from: d.sid, to: d.deviceId, session: "", tier: "" } }), "bad_reply");
  const ok = r?.ok === true
    ? exactKeys(r, ["v", "requestId", "ok", "text", "finishedAt"]) && typeof r.text === "string" && r.text.length <= 100_000 && safeInt(r.finishedAt)
    : r?.ok === false && exactKeys(r, ["v", "requestId", "ok", "code"]) && (REPLY_CODES as readonly string[]).includes(r.code);
  if (!ok || r.v !== 1 || r.requestId !== requestId) fail("bad_reply");
  d.pending = d.pending.filter((p) => p.requestId !== requestId);
  return r as Reply;
}
```

```ts
// The browser's view of the MEGA sync folder (design 8.3; the desktop side is extension/connectors/sync-store/mega.mjs).
// It logs in to the dedicated account with a password typed this session; megajs drops the password after deriving the
// key and nothing here keeps it. Reads take the newest node of a name (the desktop replaces by upload-then-delete).
// Writes create only new, uniquely named files and never replace or delete anything (one writer per file, design 3).
import type { DeviceStore } from "./device.ts";

export interface OpenedStore extends DeviceStore { close(): Promise<void> }
export const MAX_FILE_BYTES = 1048576 + 4096;
const SEGMENT = /^[A-Za-z0-9_.-]{1,64}$/;
const EMAIL_RE = /^[^\s@]{1,64}@[^\s@]{1,190}\.[^\s@]{2,63}$/;
const RATE_LIMITED = new Set([-3, -4, -6, -18, -19]); // EAGAIN, ERATELIMIT, ETOOMANY, ETEMPUNAVAIL, ETOOMANYCONNECTIONS
const NETWORK_RE = /Failed to fetch|NetworkError|Load failed|fetch failed/i;

export class SyncStoreError extends Error {
  readonly code: string;
  constructor(code: string) { super(code); this.code = code; this.name = "SyncStoreError"; }
}

export function checkPath(path: string): string[] {
  const segs = typeof path === "string" ? path.split("/") : [];
  if (segs.length < 1 || segs.length > 6 || segs.some((s) => !SEGMENT.test(s) || s === "." || s === "..")) throw new SyncStoreError("SYNC_BAD_PATH");
  return segs;
}

/** megajs reports API errors as plain Errors whose message reads "ENAME (-n): ..." (its ERRORS table). */
export const megaErrorNumber = (e: unknown): number | null => {
  const m = /\((-\d+)\)/.exec(String((e as Error | undefined)?.message ?? ""));
  return m ? Number(m[1]) : null;
};

/** The SP1 table (extension/connectors/sync-store/mega.mjs classifyMegaError), with the browsers' fetch failure texts. */
export function classifyMegaError(e: unknown, duringLogin = false): string {
  const n = megaErrorNumber(e);
  const text = String((e as Error | undefined)?.message ?? "");
  if (n === -15) return "SYNC_SESSION_EXPIRED";
  if (n === -26) return "SYNC_MFA_REQUIRED";
  if ((n !== null && RATE_LIMITED.has(n)) || /maybe caused by rate limit/.test(text)) return "SYNC_RATE_LIMITED";
  if (n === -17 || n === -24 || /returned a 509 status/.test(text)) return "SYNC_QUOTA";
  if (n === -16) return "SYNC_AUTH_FAILED"; // EBLOCKED
  if (duringLogin && (n === -9 || /invalid credentials|Account version not supported/.test(text))) return "SYNC_AUTH_FAILED";
  if (n === null && NETWORK_RE.test(text)) return "SYNC_UNREACHABLE";
  return "SYNC_IO";
}

interface MegaNode {
  nodeId: string; name: string; directory: boolean; size?: number; timestamp?: number; children?: MegaNode[];
  mkdir(name: string): Promise<MegaNode>;
  upload(o: { name: string; size: number }, data: Uint8Array): { complete: Promise<unknown> };
  downloadBuffer(o: object): Promise<Uint8Array>;
}
export interface MegaSession { root: MegaNode; close(): Promise<void> | void }
export type MegaLogin = (c: { email: string; password: string }, o: { onLost: (e: unknown) => void }) => Promise<MegaSession>;

export const megaLogin: MegaLogin = async ({ email, password }, { onLost }) => {
  const { Storage } = await import("megajs"); // its own chunk: loaded only when sync is used
  // A fresh options object: megajs deletes options.password once it has derived the key. No 2FA code is ever sent.
  const s = new Storage({ email, password, keepalive: true, autoload: true });
  const api = s.api as unknown as { on(ev: string, fn: (e: unknown) => void): void; close(): void };
  api.on("error", onLost); // a dead keepalive poll: the next operation reports SYNC_SESSION_EXPIRED
  try { return (await s.ready) as unknown as MegaSession; } catch (e) { try { api.close(); } catch { /* already closed */ } throw e; }
};

export async function openMegaStore({ email, password, folder }: { email: string; password: string; folder: string },
  { login = megaLogin }: { login?: MegaLogin } = {}): Promise<OpenedStore> {
  if (typeof email !== "string" || !EMAIL_RE.test(email)) throw new SyncStoreError("SYNC_BAD_EMAIL");
  if (typeof password !== "string" || password.length < 1 || password.length > 1024) throw new SyncStoreError("SYNC_BAD_PASSWORD");
  if (!SEGMENT.test(folder) || folder === "." || folder === "..") throw new SyncStoreError("SYNC_BAD_PATH");
  let lost = false;
  let session: MegaSession;
  try { session = await login({ email, password }, { onLost: () => { lost = true; } }); }
  catch (e) { throw new SyncStoreError(classifyMegaError(e, true)); }

  const kids = (n: MegaNode | null) => n?.children ?? [];
  const folderNamed = (n: MegaNode | null, name: string) => kids(n).find((c) => c.directory && c.name === name) ?? null;
  const newest = (n: MegaNode, name: string) => kids(n).filter((c) => !c.directory && c.name === name)
    .sort((a, b) => (a.timestamp ?? 0) - (b.timestamp ?? 0)).at(-1) ?? null; // stable sort: same second keeps upload order
  const op = async <T>(fn: () => Promise<T>): Promise<T> => {
    if (lost) throw new SyncStoreError("SYNC_SESSION_EXPIRED");
    try { return await fn(); } catch (e) { throw e instanceof SyncStoreError ? e : new SyncStoreError(classifyMegaError(e)); }
  };
  /** Folders below the sync folder; segments at index >= mkdirFrom may be created, the rest must exist. */
  const walk = async (segs: string[], mkdirFrom: number) => {
    let node = folderNamed(session.root, folder);
    if (!node) return null; // the desktop creates the sync folder; a device never does
    for (let i = 0; i < segs.length; i++) {
      const next = folderNamed(node, segs[i]);
      if (next) node = next;
      else if (i >= mkdirFrom) node = await node.mkdir(segs[i]);
      else return null;
    }
    return node;
  };

  return {
    get: (path) => op(async () => {
      const segs = checkPath(path);
      const dir = await walk(segs.slice(0, -1), Infinity);
      const f = dir ? newest(dir, segs[segs.length - 1]) : null;
      if (!f) return null;
      if ((f.size ?? 0) > MAX_FILE_BYTES) throw new SyncStoreError("SYNC_TOO_LARGE");
      try { return new Uint8Array(await f.downloadBuffer({})); }
      catch (e) { if (megaErrorNumber(e) === -9) return null; throw e; } // deleted on the server, packet not here yet
    }),
    put: (path, bytes, mkdirFrom = Infinity) => op(async () => {
      const segs = checkPath(path);
      if (bytes.length > MAX_FILE_BYTES) throw new SyncStoreError("SYNC_TOO_LARGE");
      const dir = await walk(segs.slice(0, -1), mkdirFrom);
      if (!dir) throw new SyncStoreError("SYNC_MISSING");
      const name = segs[segs.length - 1];
      if (newest(dir, name)) return; // names are unique per write, so this is a retry of a write that landed
      await dir.upload({ name, size: bytes.length }, bytes).complete;
    }),
    async close() { lost = true; try { await session.close(); } catch { /* already closed */ } },
  };
}
```

```ts
const codeOf = (e: unknown): string => (e && typeof e === "object" && typeof (e as { code?: unknown }).code === "string" ? (e as { code: string }).code : "");
export function textOf(e: unknown): string {
  const code = codeOf(e);
  if (TEXT[code]) return TEXT[code];
  if (e instanceof SyncCryptoError) return `Storage returned data that failed verification (${code}). Nothing from it was used.`;
  if (code.startsWith("SYNC_")) return `MEGA operation failed (${code}).`;
  return "Something went wrong.";
}
export function folderOf(st: string): string {
  const m = /^mega:([A-Za-z0-9_.-]{1,64})$/.exec(st);
  if (!m || m[1] === "." || m[1] === "..") throw new SyncCryptoError("unsupported_store");
  return m[1];
}

function defaultDeps(): SyncDeps {
  const g = globalThis as unknown as { addEventListener?: (t: string, f: () => void) => void; removeEventListener?: (t: string, f: () => void) => void };
  return {
    keystore: indexedDbKeyStore() ?? memoryKeyStore(),
    openStore: (c) => openMegaStore(c),
    now: () => Date.now(),
    sleep: (ms) => new Promise((r) => setTimeout(r, ms)),
    setTimer: (fn, ms) => setTimeout(fn, ms),
    clearTimer: (t) => clearTimeout(t as Parameters<typeof clearTimeout>[0]),
    confirm: (m) => globalThis.confirm?.(m) ?? true,
    online: () => globalThis.navigator?.onLine ?? true,
    onNetwork: (fn) => {
      const on = () => fn(true); const off = () => fn(false);
      g.addEventListener?.("online", on); g.addEventListener?.("offline", off);
      return () => { g.removeEventListener?.("online", on); g.removeEventListener?.("offline", off); };
    },
    takePairLink,
  };
}

export function createSyncController(deps: Partial<SyncDeps> = {}) {
  const d: SyncDeps = { ...defaultDeps(), ...deps };
  let state: SyncState = { phase: "none", pairStep: null, sas: null, busy: false, error: null, notice: null, online: d.online(), email: "",
    snapshot: null, stale: false, checkedAt: null, pending: [], answered: [] };
  const subs = new Set<() => void>();
  const set = (p: Partial<SyncState>) => { state = { ...state, ...p }; for (const fn of subs) fn(); };
  let device: LinkedDevice | null = null;
  let store: OpenedStore | null = null;
  let pair: Pair | null = null;
  let pairRun = 0; // bumped by cancel/new link/dispose: a running pair() with an older number stops at its next poll
  let paused = false; let disposed = false; let refreshing = false;
  let timer: unknown = null; let backoff = POLL_MS;
  let offNet: (() => void) | null = null;
  const texts = new Map<string, string>(); // prompt texts, this session only
  const cache: BlobCache = new Map();

  const pendingView = (): QueuedPrompt[] => (device?.pending ?? []).map((p) => ({ ...p, text: texts.get(p.requestId) ?? null }));
  const clearTimer = () => { if (timer !== null) d.clearTimer(timer); timer = null; };
  const schedule = () => {
    clearTimer();
    if (store && device && !paused && !disposed && state.online && state.phase === "ready") timer = d.setTimer(() => { timer = null; void refresh(); }, backoff);
  };
  const closeStore = async () => { clearTimer(); const s = store; store = null; cache.clear(); if (s) await s.close().catch(() => {}); };
  const save = async () => {
    if (!device) return;
    try { await d.keystore.save(device); } catch { d.keystore = memoryKeyStore(); await d.keystore.save(device); set({ notice: NOT_REMEMBERED }); }
  };

  async function waitFor<T>(run: number, probe: () => Promise<T | null>, ms: number): Promise<T> {
    const until = d.now() + ms;
    for (;;) {
      if (run !== pairRun || disposed) throw new SyncCryptoError("cancelled");
      const v = await probe();
      if (v !== null) return v;
      if (d.now() >= until) throw new SyncCryptoError("pair_timeout");
      await d.sleep(PAIR_POLL_MS);
    }
  }

  function acceptLink(url: string): boolean {
    try {
      const p = parsePair(url.trim());
      folderOf(p.st);
      void closeStore();
      pairRun += 1; pair = p;
      set({ phase: "pairing", pairStep: null, sas: null, busy: false, error: null, snapshot: null,
        notice: device ? "Pairing again replaces this browser's current sync link." : null });
      return true;
    } catch (e) { set({ error: textOf(e) }); return false; }
  }

  async function pairNow(i: { email: string; password: string; name: string }) {
    const p = pair;
    if (!p || state.busy) return;
    const run = ++pairRun;
    set({ busy: true, error: null, pairStep: "login", sas: null });
    let s: OpenedStore | null = null;
    try {
      s = await d.openStore({ email: i.email, password: i.password, folder: folderOf(p.st) });
      set({ pairStep: "claiming" });
      const e = await startPairing(s, p, { name: i.name, now: d.now() });
      pair = null; // the enrollment secret now lives only inside e's non-extractable derived keys
      const open = s;
      const sas = await waitFor(run, () => readAck(open, e), ACK_WAIT_MS);
      set({ pairStep: "sas", sas });
      const linked = await waitFor(run, () => readFirstWrap(open, e, { megaEmail: i.email }), WRAP_WAIT_MS);
      await closeStore();
      device = linked; store = s; s = null; texts.clear();
      await save();
      backoff = POLL_MS;
      set({ phase: "ready", pairStep: null, sas: null, busy: false, email: i.email, snapshot: null, answered: [], pending: [] });
      await refresh();
    } catch (e) {
      if (s) await s.close().catch(() => {});
      if (run !== pairRun) return; // cancelled: cancelPairing already set the state
      set({ busy: false, pairStep: null, sas: null, error: textOf(e), phase: pair ? "pairing" : device ? "locked" : "none" });
    }
  }

  async function unlock(i: { email: string; password: string }) {
    if (!device || state.busy) return;
    set({ busy: true, error: null });
    try {
      const s = await d.openStore({ email: i.email, password: i.password, folder: folderOf(device.st) });
      await closeStore();
      store = s;
      if (device.megaEmail !== i.email) { device.megaEmail = i.email; await save(); }
      backoff = POLL_MS;
      set({ phase: "ready", busy: false, email: i.email });
      await refresh();
    } catch (e) { set({ busy: false, error: textOf(e) }); }
  }

  async function refresh() {
    const s = store; const dev = device;
    if (!s || !dev || paused || disposed || refreshing || !state.online || state.phase !== "ready") return;
    refreshing = true; clearTimer(); set({ busy: true });
    try {
      let snap: Snapshot | null;
      try { snap = await readSnapshot(s, dev, d.now(), cache); }
      catch (e) { if (codeOf(e) !== "updating") throw e; snap = await readSnapshot(s, dev, d.now(), cache); } // design 7: refetch the manifest once
      const answered: Answered[] = [];
      let problem: unknown = null;
      for (const p of [...dev.pending]) {
        const text = texts.get(p.requestId) ?? null;
        try {
          const r = await readReply(s, dev, p.requestId, d.now());
          if (r) { texts.delete(p.requestId); answered.push({ ...p, text, ok: r.ok, reply: r.ok ? r.text : null, code: r.ok ? null : r.code }); }
          else if (d.now() - p.issuedAt > PENDING_DROP_MS) {
            dev.pending = dev.pending.filter((x) => x.requestId !== p.requestId);
            answered.push({ ...p, text, ok: false, reply: null, code: "expired" });
          }
        } catch (e) { problem ??= e; } // a refused reply keeps the prompt pending; the genuine one may still come
      }
      await save();
      backoff = POLL_MS;
      const shown = snap ?? state.snapshot;
      set({ busy: false, snapshot: shown, stale: !!shown && d.now() > shown.validUntil, checkedAt: d.now(), error: problem ? textOf(problem) : null,
        notice: shown ? null : "Waiting for the desktop's first snapshot.", pending: pendingView(), answered: [...answered, ...state.answered].slice(0, MAX_ANSWERED) });
    } catch (e) {
      const code = codeOf(e);
      await save();
      if (code === "removed") { await closeStore(); set({ busy: false, phase: "removed", snapshot: null, error: null }); return; }
      if (code === "SYNC_SESSION_EXPIRED" || code === "SYNC_AUTH_FAILED") {
        await closeStore(); set({ busy: false, phase: "locked", snapshot: null, error: TEXT.SYNC_SESSION_EXPIRED }); return;
      }
      if (code.startsWith("SYNC_")) backoff = Math.min(backoff * 2, MAX_BACKOFF_MS);
      set({ busy: false, error: textOf(e), checkedAt: d.now(), pending: pendingView() });
    } finally { refreshing = false; schedule(); }
  }

  async function send(text: string): Promise<boolean> {
    const s = store; const dev = device;
    if (!s || !dev || state.phase !== "ready") return false;
    if (dev.pending.length >= MAX_PENDING) { set({ error: `${MAX_PENDING} prompts are already waiting for the desktop.` }); return false; }
    try {
      const id = await sendRequest(s, dev, text, d.now());
      texts.set(id, text);
      await save();
      set({ pending: pendingView(), error: null, notice: "Queued. It runs when the desktop is back." });
      return true;
    } catch (e) { set({ error: textOf(e) }); return false; }
  }

  return {
    getState: () => state,
    subscribe: (fn: () => void) => { subs.add(fn); return () => { subs.delete(fn); }; },
    async start() {
      if (offNet || disposed) return;
      offNet = d.onNetwork((on) => { set({ online: on }); if (on) void refresh(); else clearTimer(); });
      const link = d.takePairLink();
      try { device = await d.keystore.load(); } catch { device = null; d.keystore = memoryKeyStore(); set({ notice: NOT_REMEMBERED }); }
      set({ phase: device ? "locked" : "none", email: device?.megaEmail ?? "", pending: pendingView() });
      if (link) acceptLink(link);
    },
    acceptLink,
    pair: pairNow,
    cancelPairing() { pairRun += 1; pair = null; set({ phase: device ? "locked" : "none", pairStep: null, sas: null, busy: false, error: null }); },
    unlock,
    refresh,
    send,
    async lock() {
      pairRun += 1; await closeStore(); texts.clear();
      set({ phase: device ? "locked" : "none", snapshot: null, answered: [], pending: pendingView(), error: null, notice: null, stale: false, busy: false });
    },
    async forget() {
      if (!d.confirm(FORGET_SYNC_CONFIRM)) return;
      pairRun += 1; await closeStore(); device = null; pair = null; texts.clear();
      try { await d.keystore.clear(); } catch { /* nothing kept */ }
      set({ phase: "none", snapshot: null, answered: [], pending: [], error: null, notice: null, stale: false, email: "", busy: false });
    },
    pause() { paused = true; clearTimer(); },
    resume() { if (!paused) return; paused = false; void refresh(); },
    dispose() { disposed = true; pairRun += 1; offNet?.(); offNet = null; void closeStore(); subs.clear(); },
  };
}

export type SyncController = ReturnType<typeof createSyncController>;
```

```tsx
const when = (ms: number) => new Date(ms).toLocaleString();
const openLink = (href: string) => { if (/^https?:\/\//.test(href)) window.open(href, "_blank", "noopener,noreferrer"); };
const STEP: Record<string, string> = { login: "Signing in to MEGA…", claiming: "Sending this browser's keys to the desktop…" };

  needs_approval: "The desktop needed an approval it cannot take from here. Ask again with the desktop on.",

function Frame({ children, hostPaired }: { children: ReactNode; hostPaired: boolean }) {
  return (
    <main className="web-app">
      <header className="web-header">
        <h1>LLM-IDE · offline sync</h1>
        <span className="chat-spacer" />
        {hostPaired && <span className="chat-muted">Desktop not reachable</span>}
      </header>
      {children}
    </main>
  );
}

function PairView({ state, sync }: { state: SyncState; sync: Actions }) {
  const ids = [useId(), useId(), useId(), useId()];
  const [name, setName] = useState("Browser");
  const [email, setEmail] = useState(state.email);
  const [password, setPassword] = useState("");
  const sasHeading = useRef<HTMLHeadingElement>(null);
  useEffect(() => { if (state.pairStep === "sas") sasHeading.current?.focus(); }, [state.pairStep]);
  const submit = (e: FormEvent) => {
    e.preventDefault();
    const pw = password;
    setPassword("");
    void sync.pair({ email: email.trim(), password: pw, name: name.trim() });
  };
  if (state.pairStep === "sas" && state.sas) {
    const sas = state.sas;
    return (
      <section aria-labelledby={ids[0]}>
        <h2 id={ids[0]} ref={sasHeading} tabIndex={-1}>Check the code</h2>
        <p>The desktop shows a 6-digit code. If it is the same as this one, press <strong>Codes match</strong> on the desktop.</p>
        <output className="web-sync-sas" aria-label={`Pairing code ${sas.split("").join(" ")}`}>{sas.slice(0, 3)} {sas.slice(3)}</output>
        <p role="status" aria-live="polite">Waiting for the desktop…</p>
        <button type="button" onClick={sync.cancelPairing}>Cancel</button>
      </section>
    );
  }
  return (
    <form className="web-form" onSubmit={submit} aria-describedby={ids[3]}>
      <h2>Add this browser to offline sync</h2>
      <p id={ids[3]}>Use the dedicated MEGA account the desktop syncs to. The password is used for this session only and is never stored.</p>
      {state.notice && <StatusBanner severity="info" message={state.notice} />}
      <label htmlFor={ids[0]}>Name for this browser</label>
      <input id={ids[0]} value={name} maxLength={64} required onChange={(e) => setName(e.target.value)} />
      <label htmlFor={ids[1]}>MEGA email</label>
      <input id={ids[1]} type="email" autoComplete="username" value={email} required onChange={(e) => setEmail(e.target.value)} />
      <label htmlFor={ids[2]}>MEGA password</label>
      <input id={ids[2]} type="password" autoComplete="current-password" value={password} required onChange={(e) => setPassword(e.target.value)} />
      <p className="web-status" role="status" aria-live="polite">{state.busy ? STEP[state.pairStep ?? "login"] ?? "" : ""}</p>
      {state.error && <StatusBanner severity="error" message={state.error} />}
      <div className="web-actions">
        <button type="submit" disabled={state.busy}>Continue</button>
        <button type="button" onClick={sync.cancelPairing}>Cancel</button>
      </div>
    </form>
  );
}

function UnlockView({ state, sync }: { state: SyncState; sync: Actions }) {
  const ids = [useId(), useId()];
  const [email, setEmail] = useState(state.email);
  const [password, setPassword] = useState("");
  const submit = (e: FormEvent) => { e.preventDefault(); const pw = password; setPassword(""); void sync.unlock({ email: email.trim(), password: pw }); };
  return (
    <form className="web-form" onSubmit={submit}>
      <h2>Unlock offline sync</h2>
      <p>Enter the sync account's MEGA password for this session. It is never stored.</p>
      <label htmlFor={ids[0]}>MEGA email</label>
      <input id={ids[0]} type="email" autoComplete="username" value={email} required onChange={(e) => setEmail(e.target.value)} />
      <label htmlFor={ids[1]}>MEGA password</label>
      <input id={ids[1]} type="password" autoComplete="current-password" value={password} required onChange={(e) => setPassword(e.target.value)} />
      {state.error && <StatusBanner severity="error" message={state.error} />}
      {state.notice && <StatusBanner severity="info" message={state.notice} />}
      <div className="web-actions">
        <button type="submit" disabled={state.busy}>{state.busy ? "Unlocking…" : "Unlock"}</button>
        <button type="button" onClick={() => void sync.forget()}>Forget this browser</button>
      </div>
    </form>
  );
}

function Inbox({ state, sync }: { state: SyncState; sync: Actions }) {
  const id = useId();
  const [draft, setDraft] = useState("");
  const submit = async (e: FormEvent) => { e.preventDefault(); const t = draft.trim(); if (t && (await sync.send(t))) setDraft(""); };
  return (
    <section className="web-read" aria-label="Queued prompts">
      <h2>Ask the desktop later</h2>
      <p className="chat-muted">Prompts wait in your storage and run when the desktop is back, read-only: no file changes and no approvals.</p>
      <form className="web-form" onSubmit={(e) => void submit(e)}>
        <label htmlFor={id}>Prompt for the desktop</label>
        <textarea id={id} value={draft} maxLength={MAX_TEXT} rows={3} onChange={(e) => setDraft(e.target.value)} />
        <button type="submit" disabled={!draft.trim() || !state.online}>Queue prompt</button>
      </form>
      {state.pending.length > 0 && (
        <ul className="web-list" aria-label="Waiting for the desktop">
          {state.pending.map((p) => <li key={p.requestId} className="web-msg web-user">{p.text ?? "(sent earlier)"} <span className="chat-muted">· queued {when(p.issuedAt)}</span></li>)}
        </ul>
      )}
      {state.answered.length > 0 && (
        <ul className="web-list" aria-label="Answers">
          {state.answered.map((a) => (
            <li key={a.requestId} className="web-msg web-assistant">
              {a.text && <p className="chat-muted">{a.text}</p>}
              {a.ok && a.reply !== null ? <Markdown text={a.reply} onOpenLink={openLink} /> : <p>{REPLY_TEXT[a.code ?? ""] ?? "No answer."}</p>}
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}

function ReadyView({ state, sync }: { state: SyncState; sync: Actions }) {
  const [openId, setOpenId] = useState<string | null>(null);
  const snap = state.snapshot;
  const read = snapshotReadState(snap, openId);
  return (
    <>
      <p role="status" aria-live="polite">{snap ? `Desktop last seen ${when(snap.generatedAt)}` : "No snapshot yet."}{state.checkedAt ? ` · checked ${when(state.checkedAt)}` : ""}</p>
      {snap && state.stale && <StatusBanner severity="warning" message={`Desktop offline or storage withholding updates. This snapshot was due for renewal at ${when(snap.validUntil)}.`} />}
      {!state.online && <StatusBanner severity="info" message="You are offline. Showing what was loaded in this session." />}
      {state.notice && <StatusBanner severity="info" message={state.notice} />}
      {state.error && <StatusBanner severity="error" message={state.error} />}
      <div className="web-actions">
        <button type="button" onClick={() => void sync.refresh()} disabled={state.busy || !state.online}>Check now</button>
        <button type="button" onClick={() => void sync.lock()}>Lock</button>
        <button type="button" onClick={() => void sync.forget()}>Forget this browser</button>
      </div>
      <div className="web-shell">
        <ReadPanel capabilities={READ} state={read} onOpen={(id) => setOpenId(id)} onOlder={() => {}} onClose={() => setOpenId(null)} onMore={() => {}} />
        {!read.open && <Inbox state={state} sync={sync} />}
      </div>
    </>
  );
}

export function SyncTier({ state, sync, hostPaired }: SyncTierProps) {
  return (
    <Frame hostPaired={hostPaired}>
      {state.phase === "pairing" ? <PairView state={state} sync={sync} />
        : state.phase === "locked" ? <UnlockView state={state} sync={sync} />
        : state.phase === "removed" ? (
          <section>
            <h2>This browser was removed from sync</h2>
            <p>The desktop removed it, or its folder was deleted in MEGA. Pair again from the desktop to keep using offline sync.</p>
            <button type="button" onClick={() => void sync.forget()}>Forget this browser</button>
          </section>
        )
        : <ReadyView state={state} sync={sync} />}
    </Frame>
  );
}
```

```tsx
import { useEffect, useState, useSyncExternalStore } from "react";
import type { ConnectionState } from "./host-api/connection.ts";
import { initialHostUrl } from "./host-api/url.ts";
import { lastHostUrl } from "./host-api/storage.ts";
import { createAppModel, type AppModel, type Session } from "./app-model.ts";
import { createSyncController, type SyncController } from "./sync/controller.ts";
import { PairingScreen } from "./screens/PairingScreen.tsx";
import { WebChat } from "./screens/WebChat.tsx";
import { ReadPanel } from "./screens/ReadPanel.tsx";
import { SyncLinkEntry, SyncTier } from "./screens/SyncTier.tsx";

/** The session's connection state, re-rendered on every change. */
function useConnection(session: Session | null): ConnectionState | null {
  const [, bump] = useState(0);
  useEffect(() => session?.connection.onState(() => bump((n) => n + 1)), [session]);
  return session?.connection.state ?? null;
}

function Chat({ session, conn, onForget }: { session: Session; conn: ConnectionState; onForget: () => void }) {
  const { connection: c, controller, read } = session;
  const state = useSyncExternalStore(controller.subscribe, controller.getState, controller.getState);
  const readState = useSyncExternalStore(read.subscribe, read.getState, read.getState);
  const capabilities = state.capabilities ?? c.capabilities;
  return (
    <div className="web-shell">
      <ReadPanel capabilities={capabilities} state={readState} onOpen={(id, t) => void read.open(id, t)}
        onOlder={() => void read.older()} onClose={read.close} onMore={() => void read.moreSessions()} />
      {!readState.open && (
        <WebChat hostName={c.hello?.hostName ?? "Host"} connection={conn} capabilities={capabilities} state={state}
          onSend={(t) => void controller.send(t)} onStop={() => void controller.cancel()} onClear={() => void controller.clearHistory()}
          onForget={onForget} onAnswer={(r, a) => void controller.answerQuestion(r, a)} onDecline={(r) => void controller.declineQuestion(r)}
          onTool={(r, d) => void controller.answerTool(r, d)} />
      )}
    </div>
  );
}

export function App({ model: given, sync: givenSync }: { model?: AppModel; sync?: SyncController }) {
  const [model] = useState(() => given ?? createAppModel(initialHostUrl(import.meta.env.VITE_HOST_API_URL, lastHostUrl().get())));
  const [sync] = useState(() => givenSync ?? createSyncController());
  const s = useSyncExternalStore(model.subscribe, model.getState, model.getState);
  const sy = useSyncExternalStore(sync.subscribe, sync.getState, sync.getState);
  const conn = useConnection(s.session);
  useEffect(() => { model.start(); return model.dispose; }, [model]);
  useEffect(() => { void sync.start(); return sync.dispose; }, [sync]);
  const live = conn?.kind === "ready";
  useEffect(() => { if (live) sync.pause(); else sync.resume(); }, [live, sync]);
  // Desktop reachable: the live Host API. Not reachable (or never paired over Host API) and this browser is linked to
  // sync: the snapshot. A pairing link always opens the sync pairing.
  const hostDown = !s.session || conn?.kind === "reconnecting" || conn?.kind === "failed";
  if (sy.phase === "pairing" || (sy.phase !== "none" && hostDown)) return <SyncTier state={sy} sync={sync} hostPaired={s.session !== null} />;
  if (s.session && conn) return <Chat session={s.session} conn={conn} onForget={model.forget} />;
  return <PairingScreen initialUrl={model.initialUrl} busy={s.busy} error={s.error} revokedNotice={s.notice} onSubmit={(u, p) => void model.attempt(u, p)}
    footer={<SyncLinkEntry onLink={sync.acceptLink} error={sy.phase === "none" ? sy.error : null} />} />;
}
```
