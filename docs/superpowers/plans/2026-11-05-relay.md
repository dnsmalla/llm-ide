# Relay (accounts sub-project 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carry end-to-end-encrypted Host API v1 frames between a user's desktop and one of that user's linked devices through an always-on relay inside `account-service`, so the retired SSH tunnel (`/host-api/*`, `/api/*`) is replaced by one outbound connection from the desktop. This slice is relay phases R1 and R2 (connect, authenticate, forward live envelopes). It adds no snapshots and no queue.

**Architecture:** The relay is a new unit `account-service/src/relay/`, running in the same process and database as the account service. It accepts WebSocket connections at `/relay/v1` and authenticates each one with the bearer token that already exists (desktop: OAuth access token; device: the client-held device token from linking v1), plus a signature over a challenge made with the key registered for that token. It then forwards opaque envelopes only between the desktop and devices of the same account. The Tauri Rust host keeps every private key. It holds the outbound relay connection, decrypts and verifies envelopes, and passes the plain Host API frames into the local core's existing gateway over a loopback bridge path that only it can open (the bus host proof). The browser or phone side is a WebCrypto library with a `SocketLike` adapter, so `web/src/host-api/connection.ts` runs unchanged on top of it.

**Tech Stack:** Node 22 (`node:crypto`, `node:test`, `better-sqlite3` 13.0.3), the house RFC 6455 parser (`extension/server/ws-server.mjs`, copied), WebCrypto (TypeScript, tested under Node's `globalThis.crypto.subtle`), Rust (RustCrypto `p256` 0.13.2 + `ecdh`, `hkdf` 0.12.4, `aes-gcm`, `tungstenite` with rustls), Tauri 2.

**Spec:** [relay design](2026-10-31-relay-design.md) (sections 2, 4, 5.2, 9 to 12) and its [security review](2026-10-31-relay-security-review.md); [accounts and device linking design](../specs/2026-11-05-accounts-and-device-linking-design.md) (sections 3, 4.5, 4.6, 5, 6); [ADR 0018](../../decisions/0018-tauri-desktop-node-core-relay.md), [ADR 0019](../../decisions/0019-public-accounts-desktop-data.md); [device linking v1](2026-11-05-device-linking-v1.md); [Host API v1](../../../schema/host-api/v1/README.md); [VPS deployment](../../../deploy/vps/README.md).

## Global Constraints

- The relay makes **no LLM call, runs no code, writes no user file, makes no outbound network call and loads no connector**. `account-service` never imports `extension/` (ADR 0019 decision 1; relay design section 1 non-goals). A boundary check enforces this (Task 2).
- The relay holds **no key that can decrypt or sign** anything. It stores token hashes, public keys and ciphertext only (relay 2.2; accounts design 5).
- **Release gate G-EXT (relay D9):** an independent external review of the written spec and this code must finish, with findings resolved or accepted in writing, **before `/relay/v1` is reachable from any network beyond loopback or a private test network**. Nothing in this plan adds a public nginx route. Internal review does not count.
- `account-service` runtime dependencies stay exactly `@simplewebauthn/server` 14.0.3, `better-sqlite3` 13.0.3 and `nodemailer` 10.3.1 (accounts design 6.2, `scripts/check-boundary.mjs`). No new npm dependency.
- Append-only numbered migrations (ADR 0008): add `0005_relay.sql` and never edit `0001` to `0004`.
- Tokens appear only in `Authorization` headers or in the first WebSocket message, **never in a URL path or query** (relay M6). Logs and audit rows never contain tokens, proofs, envelope bodies, frame text or headers.
- IP addresses are kept at most **72 hours** (relay D5; the existing `purge()` nulls `audit_events.ip`). Relay tables store no IP.
- Crypto: platform primitives only. Use `node:crypto` in Node, `crypto.subtle` in browsers, RustCrypto in the Tauri host, and the platform CSPRNG everywhere; `Math.random` is banned in relay code (relay 4.2, L3). AES-256-GCM uses a 96-bit random nonce and a 128-bit tag, with a **hard cap of 2^24 messages per key**. Signatures are ECDSA P-256 / SHA-256 with raw `r||s` (IEEE P1363). Every message type is signed. Canonical binary encoding is used for every signed byte string and AAD, never JSON.
- Server binds stay loopback: the core on `127.0.0.1` (ADR 0004), the account service on `127.0.0.1:3470` behind nginx.
- Remote turns run under the existing remote-safe ceiling: `startHostTurn` uses `mode: AUTO_READ_ONLY` (`extension/routes/agent-v2.mjs:1046`), never Bypass (relay D2, H2). This plan must not widen it.
- Conventional Commits, one concern per commit, on `main` (no feature branches; user memory overrides CLAUDE.md "ask before main"). Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Mac tests, if run: `LLMIDE_KEYCHAIN_BACKEND=memory`. Port-binding tests run unsandboxed.

## Rulings

**Ruling R-1: the relay lives inside `account-service`, in the same process, as unit `src/relay/`.** Accounts design A8 and ADR 0019 decision 1 already name it a unit of that service, and the link origin `wss://accounts.llm-ide.com/relay/v1` is fixed there (design 3). Running it in the same process is the smallest secure option. Authentication reads `devices` and `desktop_tokens`, and keeping one process keeps one SQLite writer (the single-writer rule). It also makes revocation instant: a `DELETE /v1/devices/:id` closes the live socket in the same call, where a second process would have to poll. Isolation comes from three things. The relay holds nothing worth stealing (no keys, no plaintext). A boundary rule lets `src/relay/` import only `node:crypto`, `node:events`, its own files, `../rate-limit.mjs` and `../guard.mjs`, and forbids networking, child-process, `vm`, mail and WebAuthn imports. The relay also has its own caps and close codes. `shortcut: one process; split relay into its own systemd unit when it starts storing snapshots/inbox at volume (later slice R3), reading the DB through a narrow auth query`.

**Ruling R-2: the wire is JSON text messages over WebSocket (WSS in production), with a closed message set, and the house RFC 6455 parser is copied into the service.** Copying `extension/server/ws-server.mjs` (already reviewed and tested: masking, UTF-8, frame cap, back-pressure close 1013) to `account-service/src/relay/ws.mjs` keeps the dependency rule intact. The message cap rises to 1,572,864 bytes, enough for a base64url 1 MiB padded ciphertext plus header. Control messages are `challenge`, `auth`, `ready`, `peer`, `err`, `ping`, `pong` and `env` (spec in Task 1). Unknown types or fields close the socket with 1008.

**Ruling R-3: per-device authentication uses the tokens that exist, made sender-constrained by a challenge signature.** On connect the relay sends a 256-bit challenge. The first client message must be `{t:"auth", token, proof}` within 10 s, where `proof = ECDSA-P256(signing key registered for that token, "llmide/relay/auth/v1\n" + challenge + "\n" + role + "\n" + tokenHash)`.
- Desktop: the token is the OAuth access token (15 min). `tokenHash` = hex SHA-256 of the token string, exactly `desktop_tokens.id_hash`. The key is `devices.signing_key` of the account's linked desktop.
- Device: the token is the client-held 32-byte device token. `tokenHash` = hex SHA-256 of the **decoded 32 bytes**, as `account-service/public/link.js` stores it in `devices.token_hash`. The device must be `linked`, of kind `web` or `ios`, and seen within 30 days (relay L2).
A stolen bearer token alone cannot connect (relay H5). A desktop renews by sending `auth` again on the same socket with a refreshed access token; the relay accepts it only if it resolves to the same desktop row. Browsers cannot set WebSocket headers, so tokens travel in the first message and never in the URL. Origin rule: a `desktop` or `ios` connection must send **no** `Origin`; a `web` device must send an `Origin` that is in `ACCOUNTS_ALLOWED_WEB_ORIGINS`. That list may never contain the accounts origin itself, so a page served by the relay operator can never be a key-holding device (relay C1, D1).

**Ruling R-4: the desktop end is the Tauri Rust host, not the Node core.** The desktop signing and ECDH private keys already live only in the OS secret store of the Rust host (`desktop/src-tauri/src/account_oauth.rs`, `DEVICE_KEYS_ACCOUNT`), and every reply must be signed by the key the device pinned through the SAS. Moving that key into the Node core would put it in two places and in the process that runs agents. The Rust host therefore:
1. owns the outbound WSS connection;
2. keeps the root key, epoch and desktop-authoritative device registry (relay 4.6) in the OS secret store;
3. verifies, decrypts, encrypts and signs every envelope;
4. passes the plain Host API frames to the core it spawned over `ws://127.0.0.1:<core port>/host-api/relay-bridge`. That path opens only with the bus host proof header (`x-llmide-host-nonce`, `extension/core/host-approval.mjs` `verifyBusHostProof`), from a loopback peer, with no `Origin`.
An adopted (foreign) core never gets the proof, so relaying fails closed there. The relay runs only while the desktop app runs; there is no background daemon in v1.

**Ruling R-5: Host API v1 frames travel unchanged inside envelopes, and the core's existing gateway, auth and scopes do the rest.** Each live device session is one Host API connection: device to relay to Rust host to bridge to `createGateway()`.
- At link confirm, the Rust host pairs that device with the core through the bridge (`host.auth.pair` with a PIN the Settings UI mints via `POST /host-api/pin`). It then puts the resulting Host API device token inside the signed wrap, so it reaches the device E2E-encrypted. The device's `HostConnection` then authenticates with `host.auth.token` as it does today.
- A bridge connection carries `x-llmide-relay-tier: web|ios` (honoured only with the host proof). The gateway caps both the issued token's scopes and every session grant on that connection to the tier: `web` = `host`, `chat`, `read` (relay D1: no approvals from the web tier); `ios` = everything served.
- Revoking the Host API device in Settings (`DELETE /host-api/devices/:id`) keeps working.

**Ruling R-6: E2E key material for this slice.** Per epoch the desktop holds a root `K_root` (32 bytes). For each linked device it derives exactly two AEAD keys with HKDF: `request` (device to desktop) and `reply` (desktop to that device). `info` names both sender and recipient, so device B can never open device A's replies. This is a recipient-binding refinement of relay 4.1, recorded in the spec for G-EXT. The desktop sends the two keys and the Host API token in a **signed wrap** (relay 4.4, C2): an explicit ECDH P-256 + HKDF-SHA-256 + AES-256-GCM construction, with no HPKE library. The device verifies the wrap against the desktop signing key it pinned when it computed the SAS, requires the epoch to be strictly greater than its current one, and returns a signed `keyconfirm`. The desktop refuses every `open` or `request` from a device that has not confirmed. Live sessions get freshness from a desktop-chosen 128-bit session id issued in reply to the device's `open` nonce, with a strictly increasing `seq` per direction inside the session. That makes replay across sessions or desktop restarts impossible without durable counters. Durable record-before-execute (relay 5.2) arrives with the queued inbox in a later slice.

**Ruling R-7: no public exposure before G-EXT.** The relay switch `ACCOUNTS_RELAY=1` is off by default, `deploy/vps/accounts.llm-ide.com.nginx` gets **no** `/relay/` location in this plan, and the README says so. Local and private-network testing only.

**Ruling R-8: iOS and Swift are out of this slice.** The shared vectors (`schema/relay/v1/vectors/v1.json`) are written so the later Swift client (sub-project 4) consumes the same file. The real browser device on its own origin (`app.llm-ide.com` with the BFF) is also sub-project 4. The device side here is the `web/src/relay/` library, tested in Node, plus a scripted device in tests.

## What the relay sees (relay 4.10, accounts P5/P6)

| Visible to the relay | Not visible |
|---|---|
| user id, desktop id, device ids; who is online and when (peer events) | Host API commands, chat text, results, approvals, project names |
| envelope purpose (`open`, `opened`, `request`, `reply`, `wrap`, `keyconfirm`), epoch, session id, seq, issuedAt, tier | the Host API device token (inside the wrap), subkeys, root key |
| ciphertext length **as a padding bucket** (1, 4, 16, 64, 256 or 1024 KiB) | exact frame sizes |
| timing, message counts, client IP (audit rows only, nulled at 72 h) | private keys of any party |

What a malicious relay can still do (stated, not hidden): drop, delay or freeze traffic; read the metadata above; refuse service; replay ciphertext, which receivers reject (session and seq); and serve a wrong wrap, which devices reject (signature against the pinned key).

- [ ] **Step 1: Write the spec `schema/relay/v1/README.md`**

```markdown
# Relay v1 wire and crypto (live envelopes, slice R1/R2)

Design: docs/superpowers/plans/2026-10-31-relay-design.md. Plan: docs/superpowers/plans/2026-11-05-relay.md.
Frozen for the external review (G-EXT). Any change bumps `v` and the vectors.

## Canonical encoding `enc(fields)`
Concatenation over fields of `u32be(len(b)) || b`. A field is an unsigned integer (encoded as 8-byte
big-endian u64, so `len = 8`), a UTF-8 string, or raw bytes. No other encoding is ever signed or used as AAD.

## Header (clear, routable, bound as AAD and signed)
Field order: `1 (version) | purpose | userId | desktopId | from | to | epoch | session | seq | issuedAt | tier`.
- purpose: `open` `opened` `request` `reply` `wrap` `keyconfirm`. Up (device→desktop): open, request, keyconfirm.
  Down (desktop→device): opened, reply, wrap.
- ids: account-service ids (`[A-Za-z0-9_-]{1,64}`). `from` is the sender's device id (the desktop's own `devices.id`).
- epoch, seq, issuedAt (ms): u64. session: 22-char base64url (16 bytes) or "" for open/wrap/keyconfirm.
- tier: `web` or `ios` on a wrap, "" otherwise.

## Keys
- `salt = SHA-256("llmide-relay-v1" || enc([userId, desktopId]))`.
- `subkey = HKDF-SHA-256(ikm = K_root[epoch], salt, info = enc([purpose, epoch, "", sender, recipient]), L = 32)`.
- request key: purpose `request`, sender = deviceId, recipient = desktopId. Used for open, request, keyconfirm.
- reply key: purpose `reply`, sender = desktopId, recipient = deviceId. Used for opened, reply.
- At most 2^24 messages per key; the sender refuses beyond it.

## Plaintext padding
`u32be(len(frame)) || frame || 0x00…` to the smallest bucket ≥ len+4 among 1024, 4096, 16384, 65536, 262144,
1048576 bytes. A frame over 1,048,572 bytes is refused. Unpadding rejects a non-bucket size, a length past the
end, and any non-zero pad byte.

## Seal
`nonce` = 12 random bytes. `extra` = the wrap's ephemeral SPKI DER, empty otherwise.
`AAD = enc(header ++ [extra])`. `ct = AES-256-GCM(key, nonce, pad(plaintext), AAD)` with the 16-byte tag appended.
`sig = ECDSA-P256-SHA256-P1363(sender signing key, "llmide/<purpose>/v1\0" || enc(header ++ [extra, nonce, ct]))`.
JSON: header fields by name, `v: 1`, `nonce`, `ct`, `sig` (base64url, no padding), `eph` on a wrap only.
Receivers verify the signature first, then decrypt, then unpad. Any failure drops the envelope. Unknown `v` fails closed.

## Wrap (desktop → device, signed, relay design 4.4)
- `eph` = fresh P-256 key pair; `Z` = ECDH(eph, device ECDH public) x-coordinate (32 bytes).
- `wrapKey = HKDF-SHA-256(Z, salt = SHA-256(enc([ephSPKI, deviceEcdhSPKI])), info = enc(["llmide/wrap/v1",
  epoch, deviceId, SHA-256(deviceEcdhSPKI), SHA-256(desktopSigningSPKI), tier]), 32)`.
- plaintext = `enc([requestKey, replyKey, hostApiToken])`; sealed with `wrapKey`, `extra = ephSPKI`, signed by the desktop.
- The device accepts only if the signature verifies under the desktop signing key it pinned at SAS time, `to` is its
  own id, and `epoch` > its current epoch. It then sends `keyconfirm`: plaintext = `SHA-256("llmide/keyconfirm/v1" ||
  sig bytes of the wrap)`, under the request key.

## Session
Device sends `open` (plaintext: 16 random bytes `nD`). Desktop answers `opened` with a fresh `session` and plaintext
`nD`. Within a session `seq` starts at 1 and strictly increases per direction; a receiver drops anything else.
`issuedAt` outside ±10 minutes of the receiver's clock is dropped and surfaced.

## Connection (WebSocket, JSON text)
relay → client: `{t:"challenge",nonce}` `{t:"ready",role,userId,deviceId,desktopId}` `{t:"peer",id,online}`
`{t:"err",code,ref?}` `{t:"ping"}` `{t:"env",env}`.
client → relay: `{t:"auth",token,proof}` `{t:"pong"}` `{t:"env",env}`.
`proof = ECDSA-P256-SHA256-P1363(key, "llmide/relay/auth/v1\n" + nonce + "\n" + role + "\n" + tokenHash)`.
desktop tokenHash = hex SHA-256(access token string); device tokenHash = hex SHA-256(decoded 32-byte token).
Close codes: 4001 auth, 4003 revoked, 4008 rate limited, 4009 replaced, 1008 protocol, 1001 idle.
Error codes: auth_failed, not_authenticated, invalid_message, bad_sender, bad_direction, bad_recipient,
peer_offline, rate_limited.
```

```js
// Independent node:crypto reference for schema/relay/v1 (both desktop and device sides). Used to generate and check
// the shared vectors and as the fake desktop/device in web tests. Never shipped in a client.
import { createCipheriv, createDecipheriv, createHash, createPublicKey, diffieHellman, generateKeyPairSync, hkdfSync, randomBytes, sign, verify } from 'node:crypto';

export const VERSION = 1;
export const BUCKETS = [1024, 4096, 16384, 65536, 262144, 1048576];
export const MAX_FRAME = BUCKETS.at(-1) - 4;
export const PURPOSES = ['open', 'opened', 'request', 'reply', 'wrap', 'keyconfirm'];
const ID_KEYS = ['purpose', 'userId', 'desktopId', 'from', 'to', 'epoch', 'session', 'seq', 'issuedAt', 'tier'];
const context = (purpose) => Buffer.from(`llmide/${purpose}/v1\0`);
const b = (s) => Buffer.from(s, 'base64url');
const sha256 = (...parts) => createHash('sha256').update(Buffer.concat(parts.map((p) => Buffer.from(p)))).digest();

export function enc(fields) {
  return Buffer.concat(fields.flatMap((f) => {
    let v;
    if (typeof f === 'number' || typeof f === 'bigint') {
      if (typeof f === 'number' && !Number.isSafeInteger(f)) throw new Error('bad_integer');
      v = Buffer.alloc(8); v.writeBigUInt64BE(BigInt(f));
    } else if (typeof f === 'string') v = Buffer.from(f, 'utf8');
    else v = Buffer.from(f);
    const len = Buffer.alloc(4); len.writeUInt32BE(v.length);
    return [len, v];
  }));
}

export function decodeEnc(buf, count) {
  const out = []; let off = 0;
  while (off < buf.length) {
    if (off + 4 > buf.length) throw new Error('bad_encoding');
    const n = buf.readUInt32BE(off); off += 4;
    if (off + n > buf.length) throw new Error('bad_encoding');
    out.push(buf.subarray(off, off + n)); off += n;
  }
  if (out.length !== count) throw new Error('bad_encoding');
  return out;
}

export const headerFields = (h) => [VERSION, h.purpose, h.userId, h.desktopId, h.from, h.to, h.epoch, h.session, h.seq, h.issuedAt, h.tier];
const headerOf = (env) => Object.fromEntries(ID_KEYS.map((k) => [k, env[k]]));

export function pad(bytes) {
  const body = Buffer.from(bytes);
  if (body.length > MAX_FRAME) throw new Error('frame_too_large');
  const out = Buffer.alloc(BUCKETS.find((s) => s >= body.length + 4));
  out.writeUInt32BE(body.length); body.copy(out, 4);
  return out;
}

export function unpad(buf) {
  if (!BUCKETS.includes(buf.length)) throw new Error('bad_padding');
  const n = buf.readUInt32BE(0);
  if (n > buf.length - 4) throw new Error('bad_padding');
  for (let i = 4 + n; i < buf.length; i++) if (buf[i] !== 0) throw new Error('bad_padding');
  return buf.subarray(4, 4 + n);
}

export const relaySalt = (userId, desktopId) => sha256(Buffer.from('llmide-relay-v1'), enc([userId, desktopId]));

export function subkey(root, { userId, desktopId, purpose, epoch, sender, recipient }) {
  return Buffer.from(hkdfSync('sha256', root, relaySalt(userId, desktopId), enc([purpose, epoch, '', sender, recipient]), 32));
}

export function deviceKeys(root, { userId, desktopId, deviceId }, epoch) {
  return {
    request: subkey(root, { userId, desktopId, purpose: 'request', epoch, sender: deviceId, recipient: desktopId }),
    reply: subkey(root, { userId, desktopId, purpose: 'reply', epoch, sender: desktopId, recipient: deviceId }),
  };
}

export function seal({ header, key, plaintext, signingKey, nonce = randomBytes(12), extra = Buffer.alloc(0) }) {
  const fields = headerFields(header);
  const c = createCipheriv('aes-256-gcm', key, nonce);
  c.setAAD(enc([...fields, extra]));
  const ct = Buffer.concat([c.update(pad(plaintext)), c.final(), c.getAuthTag()]);
  const sig = sign('sha256', Buffer.concat([context(header.purpose), enc([...fields, extra, nonce, ct])]), { key: signingKey, dsaEncoding: 'ieee-p1363' });
  return { v: VERSION, ...headerOf(header), nonce: nonce.toString('base64url'), ct: ct.toString('base64url'), sig: sig.toString('base64url'), ...(extra.length ? { eph: extra.toString('base64url') } : {}) };
}

export function open({ env, key, verifyKey, expect = {} }) {
  if (env.v !== VERSION) throw new Error('bad_version');
  if (!PURPOSES.includes(env.purpose)) throw new Error('bad_purpose');
  const header = headerOf(env);
  for (const [k, v] of Object.entries(expect)) if (header[k] !== v) throw new Error(`bad_${k}`);
  const extra = env.eph ? b(env.eph) : Buffer.alloc(0);
  const nonce = b(env.nonce); const ct = b(env.ct);
  if (nonce.length !== 12 || ct.length < 16 + BUCKETS[0]) throw new Error('bad_ciphertext');
  const fields = headerFields(header);
  if (!verify('sha256', Buffer.concat([context(env.purpose), enc([...fields, extra, nonce, ct])]), { key: verifyKey, dsaEncoding: 'ieee-p1363' }, b(env.sig))) throw new Error('bad_signature');
  const d = createDecipheriv('aes-256-gcm', key, nonce);
  d.setAAD(enc([...fields, extra])); d.setAuthTag(ct.subarray(-16));
  let pt;
  try { pt = Buffer.concat([d.update(ct.subarray(0, -16)), d.final()]); } catch { throw new Error('bad_ciphertext'); }
  return unpad(pt);
}

function wrapKey({ z, ephSpki, deviceEcdhSpki, epoch, deviceId, desktopSigningSpki, tier }) {
  return Buffer.from(hkdfSync('sha256', z, sha256(enc([ephSpki, deviceEcdhSpki])),
    enc(['llmide/wrap/v1', epoch, deviceId, sha256(deviceEcdhSpki), sha256(desktopSigningSpki), tier]), 32));
}

export function makeWrap({ ids, epoch, tier, deviceEcdhSpki, desktopSigningSpki, keys, hostApiToken, signingKey, eph = generateKeyPairSync('ec', { namedCurve: 'prime256v1' }), nonce, seq = 1, issuedAt = Date.now() }) {
  const ephSpki = eph.publicKey.export({ type: 'spki', format: 'der' });
  const z = diffieHellman({ privateKey: eph.privateKey, publicKey: createPublicKey({ key: deviceEcdhSpki, format: 'der', type: 'spki' }) });
  const key = wrapKey({ z, ephSpki, deviceEcdhSpki, epoch, deviceId: ids.deviceId, desktopSigningSpki, tier });
  const header = { purpose: 'wrap', userId: ids.userId, desktopId: ids.desktopId, from: ids.desktopId, to: ids.deviceId, epoch, session: '', seq, issuedAt, tier };
  return seal({ header, key, plaintext: enc([keys.request, keys.reply, hostApiToken]), signingKey, extra: ephSpki, ...(nonce ? { nonce } : {}) });
}

export function unwrap({ env, ecdhPrivate, deviceEcdhSpki, desktopSigningSpki, verifyKey, currentEpoch, deviceId }) {
  if (env.purpose !== 'wrap' || !env.eph) throw new Error('bad_purpose');
  if (env.to !== deviceId) throw new Error('bad_to');
  if (!(env.epoch > currentEpoch)) throw new Error('stale_epoch');
  const ephSpki = b(env.eph);
  const z = diffieHellman({ privateKey: ecdhPrivate, publicKey: createPublicKey({ key: ephSpki, format: 'der', type: 'spki' }) });
  const key = wrapKey({ z, ephSpki, deviceEcdhSpki, epoch: env.epoch, deviceId, desktopSigningSpki, tier: env.tier });
  const [request, reply, token] = decodeEnc(open({ env, key, verifyKey, expect: { purpose: 'wrap' } }), 3);
  if (request.length !== 32 || reply.length !== 32) throw new Error('bad_wrap');
  return { request: Buffer.from(request), reply: Buffer.from(reply), hostApiToken: token.toString('utf8') };
}

export const keyConfirmPlaintext = (wrapSig) => sha256(Buffer.from('llmide/keyconfirm/v1'), Buffer.from(wrapSig));
export const authMessage = (challenge, role, tokenHash) => Buffer.from(`llmide/relay/auth/v1\n${challenge}\n${role}\n${tokenHash}`);
```

```js
// Closed-schema parsing of client → relay messages (schema/relay/v1/README.md). Unknown types or fields are refused,
// never ignored. The relay cannot verify envelope crypto (it holds no keys); it checks shape only.
export class ProtocolError extends Error {
  constructor(code) { super(code); this.code = code; }
}

const ID = /^[A-Za-z0-9_-]{1,64}$/;
const B64 = /^[A-Za-z0-9_-]+$/;
const UP = new Set(['open', 'request', 'keyconfirm']);
const DOWN = new Set(['opened', 'reply', 'wrap']);
const ENV_KEYS = new Set(['v', 'purpose', 'userId', 'desktopId', 'from', 'to', 'epoch', 'session', 'seq', 'issuedAt', 'tier', 'nonce', 'ct', 'sig', 'eph']);
const MAX_CT = 1_398_200; // base64url of 1 MiB + 16-byte tag

const uint = (n) => Number.isSafeInteger(n) && n >= 0;
const b64len = (s, min, max) => typeof s === 'string' && s.length >= min && s.length <= max && B64.test(s);
const fail = (code) => { throw new ProtocolError(code); };

export const isUp = (purpose) => UP.has(purpose);

function only(obj, keys) {
  for (const k of Object.keys(obj)) if (!keys.has(k)) fail('invalid_message');
}

export function envelope(e) {
  if (!e || typeof e !== 'object' || Array.isArray(e)) fail('invalid_message');
  only(e, ENV_KEYS);
  if (e.v !== 1) fail('invalid_message');
  if (!UP.has(e.purpose) && !DOWN.has(e.purpose)) fail('invalid_message');
  for (const k of ['userId', 'desktopId', 'from', 'to']) if (typeof e[k] !== 'string' || !ID.test(e[k])) fail('invalid_message');
  for (const k of ['epoch', 'seq', 'issuedAt']) if (!uint(e[k])) fail('invalid_message');
  if (!(e.session === '' || b64len(e.session, 22, 22))) fail('invalid_message');
  if (!['', 'web', 'ios'].includes(e.tier)) fail('invalid_message');
  // 1040 bytes (smallest bucket + tag) = 1387 base64url characters.
  if (!b64len(e.nonce, 16, 16) || !b64len(e.ct, 1387, MAX_CT) || !b64len(e.sig, 86, 86)) fail('invalid_message');
  if (e.purpose === 'wrap' ? !b64len(e.eph, 80, 256) : e.eph !== undefined) fail('invalid_message');
  return e;
}

export function parseClient(text) {
  let m;
  try { m = JSON.parse(text); } catch { fail('invalid_message'); }
  if (!m || typeof m !== 'object' || Array.isArray(m)) fail('invalid_message');
  if (m.t === 'auth') {
    only(m, new Set(['t', 'token', 'proof']));
    if (!b64len(m.token, 43, 43) || !b64len(m.proof, 86, 86)) fail('invalid_message');
    return m;
  }
  if (m.t === 'pong') { only(m, new Set(['t'])); return m; }
  if (m.t === 'env') { only(m, new Set(['t', 'env'])); return { t: 'env', env: envelope(m.env) }; }
  fail('invalid_message');
}
```

```js
// Relay connection auth (plan ruling R-3): the existing bearer token, sender-constrained by a signature over a
// relay challenge with the key the account service registered for it. Every failure returns the same null.
import { createHash, createPublicKey, randomBytes, verify } from 'node:crypto';

export const DEVICE_IDLE_MS = 30 * 24 * 60 * 60_000;
const SEEN_WRITE_MS = 60 * 60_000; // last_seen_at granularity: one write per hour at most
export const newChallenge = () => randomBytes(32).toString('base64url');
export const authMessage = (challenge, role, tokenHash) => Buffer.from(`llmide/relay/auth/v1\n${challenge}\n${role}\n${tokenHash}`);
const hex256 = (b) => createHash('sha256').update(b).digest('hex');

function proofOk(spki, message, proof) {
  try {
    const key = createPublicKey({ key: Buffer.from(spki, 'base64url'), format: 'der', type: 'spki' });
    return verify('sha256', message, { key, dsaEncoding: 'ieee-p1363' }, Buffer.from(proof, 'base64url'));
  } catch {
    return false;
  }
}

const liveDesktop = (db, userId) => db.prepare("SELECT * FROM devices WHERE user_id = ? AND kind = 'desktop' AND status = 'linked'").get(userId);
const activeUser = (db, userId) => db.prepare("SELECT 1 FROM users WHERE id = ? AND status = 'active'").get(userId);

export function authenticate(ctx, { token, proof, challenge }) {
  const t = ctx.now();
  // Desktop: the OAuth access token; desktop_tokens.id_hash is SHA-256 of the token STRING (oauth.mjs).
  const deskHash = hex256(Buffer.from(token, 'utf8'));
  const access = ctx.db.prepare("SELECT * FROM desktop_tokens WHERE id_hash = ? AND kind = 'access' AND revoked_at IS NULL AND expires_at > ?").get(deskHash, t);
  if (access) {
    const desktop = activeUser(ctx.db, access.user_id) && liveDesktop(ctx.db, access.user_id);
    if (!desktop || !proofOk(desktop.signing_key, authMessage(challenge, 'desktop', deskHash), proof)) return null;
    return { role: 'desktop', kind: 'desktop', userId: access.user_id, deviceId: desktop.id, desktopId: desktop.id, tokenHash: deskHash, expiresAt: access.expires_at };
  }
  // Device: the client-held 32-byte token; devices.token_hash is SHA-256 of the DECODED bytes (public/link.js).
  const raw = Buffer.from(token, 'base64url');
  if (raw.length !== 32) return null;
  const devHash = hex256(raw);
  const dev = ctx.db.prepare("SELECT * FROM devices WHERE token_hash = ? AND status = 'linked' AND kind IN ('web', 'ios')").get(devHash);
  if (!dev || !activeUser(ctx.db, dev.user_id)) return null;
  if (t - (dev.last_seen_at ?? dev.linked_at ?? 0) > DEVICE_IDLE_MS) return null;
  const desktop = liveDesktop(ctx.db, dev.user_id);
  if (!desktop || !proofOk(dev.signing_key, authMessage(challenge, 'device', devHash), proof)) return null;
  if (t - (dev.last_seen_at ?? 0) > SEEN_WRITE_MS) ctx.db.prepare('UPDATE devices SET last_seen_at = ? WHERE id = ?').run(t, dev.id);
  return { role: 'device', kind: dev.kind, userId: dev.user_id, deviceId: dev.id, desktopId: desktop.id, tokenHash: devHash, expiresAt: null };
}
```

```js
// Minimal masked WebSocket client for relay tests (the service parser is server-side only).
import http from 'node:http';
import { randomBytes, sign } from 'node:crypto';

function parse(buf) {
  if (buf.length < 2) return null;
  let len = buf[1] & 0x7f; let off = 2;
  if (len === 126) { if (buf.length < 4) return null; len = buf.readUInt16BE(2); off = 4; }
  else if (len === 127) { if (buf.length < 10) return null; len = Number(buf.readBigUInt64BE(2)); off = 10; }
  if (buf.length < off + len) return null;
  return { opcode: buf[0] & 0x0f, payload: buf.subarray(off, off + len), size: off + len };
}

function masked(payload) {
  const mask = randomBytes(4); const len = payload.length;
  let head;
  if (len < 126) head = Buffer.from([0x81, 0x80 | len]);
  else if (len < 65536) { head = Buffer.alloc(4); head[0] = 0x81; head[1] = 0x80 | 126; head.writeUInt16BE(len, 2); }
  else { head = Buffer.alloc(10); head[0] = 0x81; head[1] = 0x80 | 127; head.writeBigUInt64BE(BigInt(len), 2); }
  const body = Buffer.from(payload);
  for (let i = 0; i < len; i++) body[i] ^= mask[i & 3];
  return Buffer.concat([head, mask, body]);
}

function client(socket, head) {
  const inbox = []; const waiters = []; let buf = head?.length ? Buffer.from(head) : Buffer.alloc(0); let code = null;
  const push = (m) => { const w = waiters.shift(); if (w) w(m); else inbox.push(m); };
  const drain = () => {
    for (let f = parse(buf); f; f = parse(buf)) {
      buf = buf.subarray(f.size);
      if (f.opcode === 1) push(JSON.parse(f.payload.toString('utf8')));
      if (f.opcode === 8) { code = f.payload.length >= 2 ? f.payload.readUInt16BE(0) : 1005; push({ t: '__closed', code }); }
    }
  };
  socket.on('data', (d) => { buf = Buffer.concat([buf, d]); drain(); });
  socket.on('close', () => { if (code === null) push({ t: '__closed', code: 1006 }); });
  drain();
  return {
    send(obj) { socket.write(masked(Buffer.from(typeof obj === 'string' ? obj : JSON.stringify(obj)))); },
    next(ms = 2000) {
      if (inbox.length) return Promise.resolve(inbox.shift());
      return new Promise((resolve, reject) => {
        const timer = setTimeout(() => reject(new Error('timeout')), ms);
        waiters.push((m) => { clearTimeout(timer); resolve(m); });
      });
    },
    close() { socket.destroy(); },
  };
}

export function wsConnect(base, { origin, path = '/relay/v1' } = {}) {
  return new Promise((resolve, reject) => {
    const req = http.request(base + path, { headers: { connection: 'Upgrade', upgrade: 'websocket', 'sec-websocket-version': '13', 'sec-websocket-key': randomBytes(16).toString('base64'), ...(origin ? { origin } : {}) } });
    req.on('upgrade', (_res, socket, head) => resolve(client(socket, head)));
    req.on('response', (res) => { res.resume(); resolve({ refused: res.statusCode }); });
    req.on('error', reject);
    req.end();
  });
}

export async function authed(base, { token, signingKey, role, tokenHash, origin }) {
```

```js
// Relay hub: authenticated sockets, routing between ONE account's desktop and its linked devices, caps, ping,
// stored wraps. Forwards ciphertext it cannot read; never logs bodies or tokens.
import { authenticate, newChallenge } from './auth.mjs';
import { isUp, parseClient, ProtocolError } from './protocol.mjs';

export const RELAY_LIMITS = Object.freeze({
  authDeadlineMs: 10_000, pingEveryMs: 30_000, pongDeadlineMs: 75_000,
  maxSockets: 1024, maxSocketsPerIp: 16, authFailuresPerIp: 10, authBlockMs: 10 * 60_000,
  envelopesPerMinute: 1200, bytesPerMinute: 32 * 1024 * 1024,
});
export const CLOSE = Object.freeze({ auth: 4001, revoked: 4003, limited: 4008, replaced: 4009, protocol: 1008, idle: 1001, internal: 1011 });

export function createHub(ctx, limits = RELAY_LIMITS) {
  const entries = new Set();
  const byDevice = new Map();
  const perIp = new Map();
  const blocked = new Map(); // ipKey -> until
  const stmt = {
    target: ctx.db.prepare("SELECT 1 FROM devices WHERE id = ? AND user_id = ? AND kind IN ('web', 'ios') AND status = 'linked'"),
    linked: ctx.db.prepare("SELECT 1 FROM devices WHERE id = ? AND user_id = ? AND status = 'linked'"),
    token: ctx.db.prepare('SELECT 1 FROM desktop_tokens WHERE id_hash = ? AND revoked_at IS NULL AND expires_at > ?'),
    wrapGet: ctx.db.prepare('SELECT envelope FROM relay_wraps WHERE device_id = ?'),
    wrapPut: ctx.db.prepare(`INSERT INTO relay_wraps (device_id, user_id, epoch, envelope, created_at) VALUES (?, ?, ?, ?, ?)
      ON CONFLICT(device_id) DO UPDATE SET epoch = excluded.epoch, envelope = excluded.envelope, created_at = excluded.created_at
      WHERE excluded.epoch >= relay_wraps.epoch`),
  };
  const timer = setInterval(tick, limits.pingEveryMs);
  timer.unref();

  const send = (entry, obj) => { try { entry.conn.send(JSON.stringify(obj)); } catch { /* closed */ } };
  const once = (key, limit, windowMs) => { try { ctx.limiter.hit(key, limit, windowMs); return true; } catch { return false; } };

  function admit(ipKey) {
    const until = blocked.get(ipKey);
    if (until && until > ctx.now()) return false;
    return entries.size < limits.maxSockets && (perIp.get(ipKey) ?? 0) < limits.maxSocketsPerIp;
  }

  function accept(conn, { ip, ipKey, origin }) {
    const entry = { conn, ip, ipKey, origin, challenge: newChallenge(), id: null, lastPong: ctx.now(), window: { start: ctx.now(), count: 0, bytes: 0 }, overs: 0 };
    entries.add(entry);
    perIp.set(ipKey, (perIp.get(ipKey) ?? 0) + 1);
    entry.deadline = setTimeout(() => { if (!entry.id) end(entry, CLOSE.auth); }, limits.authDeadlineMs);
    entry.deadline.unref?.();
    conn.on('message', (text) => {
      try { onMessage(entry, text); } catch (err) {
        if (err instanceof ProtocolError) { send(entry, { t: 'err', code: err.code }); end(entry, CLOSE.protocol); return; }
        console.error(JSON.stringify({ level: 'error', msg: 'relay_handler', name: err?.name, code: err?.code }));
        end(entry, CLOSE.internal);
      }
    });
    conn.on('close', () => closed(entry));
    send(entry, { t: 'challenge', nonce: entry.challenge });
  }

  function onMessage(entry, text) {
    const msg = parseClient(text);
    if (msg.t === 'pong') { entry.lastPong = ctx.now(); return; }
    if (msg.t === 'auth') return onAuth(entry, msg);
    if (!entry.id) throw new ProtocolError('not_authenticated');
    if (withinBudget(entry, text.length)) route(entry, msg.env);
  }

  function onAuth(entry, msg) {
    const id = authenticate(ctx, { token: msg.token, proof: msg.proof, challenge: entry.challenge });
    // ruling R-3: desktop and iOS never send an Origin; a web device always sends an allowlisted one (checked at upgrade).
    const originOk = id && (id.kind === 'web' ? entry.origin !== undefined : entry.origin === undefined);
    const sameDevice = !entry.id || (id && id.deviceId === entry.id.deviceId && id.role === 'desktop');
    if (!id || !originOk || !sameDevice) {
      if (once(`relay-authfail-audit:${entry.ipKey}`, 1, 60_000)) ctx.audit('relay_auth_failed', { ip: entry.ip });
      if (!once(`relay-authfail:${entry.ipKey}`, limits.authFailuresPerIp, limits.authBlockMs)) blocked.set(entry.ipKey, ctx.now() + limits.authBlockMs);
      send(entry, { t: 'err', code: 'auth_failed' });
      return end(entry, CLOSE.auth);
    }
    if (entry.id) { entry.id = id; return; } // desktop renewed its access token on the same socket
    clearTimeout(entry.deadline);
    entry.id = id;
    const old = byDevice.get(id.deviceId);
    if (old) end(old, CLOSE.replaced);
    byDevice.set(id.deviceId, entry);
    if (once(`relay-conn-audit:${id.deviceId}`, 1, 10 * 60_000)) ctx.audit('relay_connected', { userId: id.userId, ip: entry.ip, detail: { deviceId: id.deviceId, role: id.role } });
    send(entry, { t: 'ready', role: id.role, userId: id.userId, deviceId: id.deviceId, desktopId: id.desktopId });
    if (id.role === 'device') {
      const wrap = stmt.wrapGet.pluck().get(id.deviceId);
      if (wrap) send(entry, { t: 'env', env: JSON.parse(wrap) });
      send(entry, { t: 'peer', id: id.desktopId, online: byDevice.has(id.desktopId) });
      const desk = byDevice.get(id.desktopId);
      if (desk) send(desk, { t: 'peer', id: id.deviceId, online: true });
    } else {
      for (const e of byDevice.values()) {
        if (e === entry || e.id.userId !== id.userId) continue;
        send(entry, { t: 'peer', id: e.id.deviceId, online: true });
        send(e, { t: 'peer', id: id.deviceId, online: true });
      }
    }
  }

  function withinBudget(entry, bytes) {
    const t = ctx.now(); const w = entry.window;
    if (t - w.start >= 60_000) { w.start = t; w.count = 0; w.bytes = 0; }
    w.count += 1; w.bytes += bytes;
    if (w.count <= limits.envelopesPerMinute && w.bytes <= limits.bytesPerMinute) { entry.overs = 0; return true; }
    entry.overs += 1;
    if (once(`relay-limit-audit:${entry.id.deviceId}`, 1, 60_000)) ctx.audit('relay_rate_limited', { userId: entry.id.userId, detail: { deviceId: entry.id.deviceId } });
    send(entry, { t: 'err', code: 'rate_limited' });
    if (entry.overs >= 3) end(entry, CLOSE.limited);
    return false;
  }

  function route(entry, env) {
    const id = entry.id;
    const ref = { purpose: env.purpose, session: env.session, seq: env.seq };
    const refuse = (code) => send(entry, { t: 'err', code, ref });
    if (env.userId !== id.userId || env.desktopId !== id.desktopId || env.from !== id.deviceId) return refuse('bad_sender');
    const up = isUp(env.purpose);
    if (up !== (id.role === 'device')) return refuse('bad_direction');
    if (up ? env.to !== id.desktopId : !stmt.target.get(env.to, id.userId)) return refuse('bad_recipient');
    if (env.purpose === 'wrap') {
      stmt.wrapPut.run(env.to, id.userId, env.epoch, JSON.stringify(env), ctx.now());
      ctx.audit('relay_wrap_stored', { userId: id.userId, detail: { deviceId: env.to, epoch: env.epoch } });
    }
    const peer = byDevice.get(env.to);
    if (peer) send(peer, { t: 'env', env });
    else if (env.purpose !== 'wrap') refuse('peer_offline');
  }

  function stillValid(id, t) {
    if (id.role === 'desktop' && (id.expiresAt <= t || !stmt.token.get(id.tokenHash, t))) return false;
    return !!stmt.linked.get(id.deviceId, id.userId);
  }

  function tick() {
    const t = ctx.now();
    for (const entry of [...entries]) {
      if (!entry.id) continue;
      if (t - entry.lastPong > limits.pongDeadlineMs) { end(entry, CLOSE.idle); continue; }
      if (!stillValid(entry.id, t)) { end(entry, CLOSE.revoked); continue; }
      send(entry, { t: 'ping' });
    }
    for (const [k, until] of blocked) if (until <= t) blocked.delete(k);
  }

  function end(entry, code) {
    try { entry.conn.close(code); } catch { /* closed */ }
    closed(entry);
  }

  function closed(entry) {
    if (!entries.delete(entry)) return;
    clearTimeout(entry.deadline);
    const n = (perIp.get(entry.ipKey) ?? 1) - 1;
    if (n > 0) perIp.set(entry.ipKey, n); else perIp.delete(entry.ipKey);
    if (!entry.id || byDevice.get(entry.id.deviceId) !== entry) return;
    byDevice.delete(entry.id.deviceId);
    for (const e of byDevice.values()) if (e.id.userId === entry.id.userId) send(e, { t: 'peer', id: entry.id.deviceId, online: false });
  }

  function disconnect(deviceId, code = CLOSE.revoked) {
    const e = byDevice.get(deviceId);
    if (!e) return;
    ctx.audit('relay_closed_revoked', { userId: e.id.userId, detail: { deviceId } });
    end(e, code);
  }

  function disconnectUser(userId, code = CLOSE.revoked) {
    for (const e of [...byDevice.values()]) if (e.id.userId === userId) disconnect(e.id.deviceId, code);
  }

  function close() {
    clearInterval(timer);
    for (const e of [...entries]) end(e, 1001);
  }

  return { admit, accept, disconnect, disconnectUser, close, size: () => entries.size };
}
```

```js
// The relay's upgrade gate at /relay/v1 (plan ruling R-2/R-3). No query string (tokens never in URLs), exact path,
// Origin either absent (native) or allowlisted (web), per-IP upgrade rate, socket caps, then the RFC 6455 handshake.
import { clientIp } from '../guard.mjs';
import { ipBucket } from '../rate-limit.mjs';
import { CLOSE, createHub, RELAY_LIMITS } from './hub.mjs';
import { acceptUpgrade, handshakeRefusal } from './ws.mjs';

export const RELAY_PATH = '/relay/v1';
export { CLOSE };

function refuse(socket, status) {
  socket.end(`HTTP/1.1 ${status} Refused\r\nConnection: close\r\nContent-Length: 0\r\n\r\n`);
  socket.destroy();
}

function limitsFor(config, env) {
  if (config.prod) return RELAY_LIMITS;
  const n = (k, d) => (env[k] ? Number(env[k]) : d);
  return Object.freeze({ ...RELAY_LIMITS,
    authDeadlineMs: n('ACCOUNTS_RELAY_TEST_AUTH_DEADLINE_MS', RELAY_LIMITS.authDeadlineMs),
    envelopesPerMinute: n('ACCOUNTS_RELAY_TEST_ENVELOPES_PER_MIN', RELAY_LIMITS.envelopesPerMinute) });
}

export function attachRelay(server, ctx, env = process.env) {
  const hub = createHub(ctx, limitsFor(ctx.config, ctx.relayEnv ?? env));
  server.on('upgrade', (req, socket, head) => {
    socket.on('error', () => {});
    if (req.url !== RELAY_PATH) return refuse(socket, 404);
    const origin = req.headers.origin;
    if (origin !== undefined && !ctx.config.relay.webOrigins.has(origin)) return refuse(socket, 403);
    const ip = clientIp(req, ctx.config);
    const ipKey = ipBucket(ip);
    try { ctx.limiter.hit(`relay-up:${ipKey}`, 30, 60_000); } catch { return refuse(socket, 429); }
    if (!hub.admit(ipKey)) return refuse(socket, 503);
    const bad = handshakeRefusal(req);
    if (bad) return refuse(socket, bad);
    hub.accept(acceptUpgrade(req, socket, head), { ip, ipKey, origin });
  });
  return hub;
}
```

```ts
// schema/relay/v1 wire primitives: canonical encoding, padding, base64url. Pure, DOM-free.
export type Purpose = "open" | "opened" | "request" | "reply" | "wrap" | "keyconfirm";
export interface Header {
  purpose: Purpose; userId: string; desktopId: string; from: string; to: string;
  epoch: number; session: string; seq: number; issuedAt: number; tier: "" | "web" | "ios";
}
export interface Envelope extends Header { v: 1; nonce: string; ct: string; sig: string; eph?: string }

export const BUCKETS = [1024, 4096, 16384, 65536, 262144, 1048576] as const;
export const MAX_FRAME = 1048576 - 4;
export const KEY_MESSAGE_CAP = 2 ** 24;
const HEADER_KEYS = ["purpose", "userId", "desktopId", "from", "to", "epoch", "session", "seq", "issuedAt", "tier"] as const;
const te = new TextEncoder();

export const utf8 = (s: string): Uint8Array => te.encode(s);
export const context = (p: Purpose): Uint8Array => utf8(`llmide/${p}/v1\0`);

export function concat(...parts: Uint8Array[]): Uint8Array {
  const out = new Uint8Array(parts.reduce((n, p) => n + p.length, 0));
  let off = 0;
  for (const p of parts) { out.set(p, off); off += p.length; }
  return out;
}

export function enc(fields: ReadonlyArray<number | string | Uint8Array>): Uint8Array {
  return concat(...fields.flatMap((f) => {
    let v: Uint8Array;
    if (typeof f === "number") {
      if (!Number.isSafeInteger(f) || f < 0) throw new Error("bad_integer");
      v = new Uint8Array(8); new DataView(v.buffer).setBigUint64(0, BigInt(f));
    } else v = typeof f === "string" ? utf8(f) : f;
    const len = new Uint8Array(4); new DataView(len.buffer).setUint32(0, v.length);
    return [len, v];
  }));
}

export function decodeEnc(b: Uint8Array, count: number): Uint8Array[] {
  const out: Uint8Array[] = []; const dv = new DataView(b.buffer, b.byteOffset, b.byteLength); let off = 0;
  while (off < b.length) {
    if (off + 4 > b.length) throw new Error("bad_encoding");
    const n = dv.getUint32(off); off += 4;
    if (off + n > b.length) throw new Error("bad_encoding");
    out.push(b.subarray(off, off + n)); off += n;
  }
  if (out.length !== count) throw new Error("bad_encoding");
  return out;
}

export const headerFields = (h: Header) => [1, h.purpose, h.userId, h.desktopId, h.from, h.to, h.epoch, h.session, h.seq, h.issuedAt, h.tier];
export const headerOf = (e: Envelope): Header => Object.fromEntries(HEADER_KEYS.map((k) => [k, e[k]])) as unknown as Header;

export function pad(b: Uint8Array): Uint8Array {
  if (b.length > MAX_FRAME) throw new Error("frame_too_large");
  const out = new Uint8Array(BUCKETS.find((s) => s >= b.length + 4)!);
  new DataView(out.buffer).setUint32(0, b.length); out.set(b, 4);
  return out;
}

export function unpad(b: Uint8Array): Uint8Array {
  if (!(BUCKETS as readonly number[]).includes(b.length)) throw new Error("bad_padding");
  const n = new DataView(b.buffer, b.byteOffset, b.byteLength).getUint32(0);
  if (n > b.length - 4) throw new Error("bad_padding");
  for (let i = 4 + n; i < b.length; i++) if (b[i] !== 0) throw new Error("bad_padding");
  return b.subarray(4, 4 + n);
}

export function b64u(b: Uint8Array): string {
  let s = ""; for (const x of b) s += String.fromCharCode(x);
  return btoa(s).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

export function unb64u(s: string): Uint8Array {
  if (!/^[A-Za-z0-9_-]*$/.test(s)) throw new Error("bad_base64");
  const bin = atob(s.replace(/-/g, "+").replace(/_/g, "/") + "===".slice((s.length + 3) % 4));
  return Uint8Array.from(bin, (c) => c.charCodeAt(0));
}
```

```ts
// WebCrypto side of schema/relay/v1 for a linked device. Keys are imported non-extractable; raw subkey bytes from a
// wrap are zeroed after import. Verify first, then decrypt (relay design 4.2/4.4).
import { b64u, concat, context, decodeEnc, enc, headerFields, headerOf, pad, unb64u, unpad, utf8, type Envelope, type Header } from "./wire.ts";

const subtle = globalThis.crypto.subtle;
const ECDSA = { name: "ECDSA", hash: "SHA-256" } as const;

export class RelayCryptoError extends Error {
  readonly code: string;
  constructor(code: string) { super(code); this.code = code; this.name = "RelayCryptoError"; }
}

export async function sha256(...parts: Uint8Array[]): Promise<Uint8Array> {
  return new Uint8Array(await subtle.digest("SHA-256", concat(...parts)));
}
export const importVerifyKey = (spki: Uint8Array) => subtle.importKey("spki", spki, { name: "ECDSA", namedCurve: "P-256" }, false, ["verify"]);
export const importAesKey = (raw: Uint8Array, usage: "encrypt" | "decrypt") => subtle.importKey("raw", raw, "AES-GCM", false, [usage]);

const extraOf = (e: Envelope) => (e.eph ? unb64u(e.eph) : new Uint8Array(0));

export async function seal(header: Header, key: CryptoKey, plaintext: Uint8Array, signingKey: CryptoKey,
  nonce: Uint8Array = globalThis.crypto.getRandomValues(new Uint8Array(12))): Promise<Envelope> {
  const fields = headerFields(header); const extra = new Uint8Array(0);
  const ct = new Uint8Array(await subtle.encrypt({ name: "AES-GCM", iv: nonce, additionalData: enc([...fields, extra]), tagLength: 128 }, key, pad(plaintext)));
  const sig = new Uint8Array(await subtle.sign(ECDSA, signingKey, concat(context(header.purpose), enc([...fields, extra, nonce, ct]))));
  return { v: 1, ...headerOf(header as Envelope), nonce: b64u(nonce), ct: b64u(ct), sig: b64u(sig) };
}

export async function open(env: Envelope, key: CryptoKey, verifyKey: CryptoKey, expect: Partial<Header>): Promise<Uint8Array> {
  if (env.v !== 1) throw new RelayCryptoError("bad_version");
  const header = headerOf(env);
  for (const [k, v] of Object.entries(expect)) if ((header as unknown as Record<string, unknown>)[k] !== v) throw new RelayCryptoError(`bad_${k}`);
  const fields = headerFields(header); const extra = extraOf(env);
  const nonce = unb64u(env.nonce); const ct = unb64u(env.ct);
  if (nonce.length !== 12 || ct.length < 1040) throw new RelayCryptoError("bad_ciphertext");
  const ok = await subtle.verify(ECDSA, verifyKey, unb64u(env.sig), concat(context(header.purpose), enc([...fields, extra, nonce, ct])));
  if (!ok) throw new RelayCryptoError("bad_signature");
  let pt: ArrayBuffer;
  try { pt = await subtle.decrypt({ name: "AES-GCM", iv: nonce, additionalData: enc([...fields, extra]), tagLength: 128 }, key, ct); }
  catch { throw new RelayCryptoError("bad_ciphertext"); }
  try { return unpad(new Uint8Array(pt)); } catch { throw new RelayCryptoError("bad_padding"); }
}

export interface UnwrapOptions {
  deviceId: string; ecdhPrivate: CryptoKey; ecdhSpki: Uint8Array;
  desktopVerify: CryptoKey; desktopSigningSpki: Uint8Array; currentEpoch: number;
}

export async function unwrap(env: Envelope, o: UnwrapOptions) {
  if (env.purpose !== "wrap" || !env.eph) throw new RelayCryptoError("bad_purpose");
  if (env.to !== o.deviceId) throw new RelayCryptoError("bad_to");
  if (!(env.epoch > o.currentEpoch)) throw new RelayCryptoError("stale_epoch");
  const eph = unb64u(env.eph);
  const ephKey = await subtle.importKey("spki", eph, { name: "ECDH", namedCurve: "P-256" }, false, []);
  const z = new Uint8Array(await subtle.deriveBits({ name: "ECDH", public: ephKey }, o.ecdhPrivate, 256));
  const hk = await subtle.importKey("raw", z, "HKDF", false, ["deriveBits"]);
  const info = enc(["llmide/wrap/v1", env.epoch, o.deviceId, await sha256(o.ecdhSpki), await sha256(o.desktopSigningSpki), env.tier]);
  const raw = new Uint8Array(await subtle.deriveBits({ name: "HKDF", hash: "SHA-256", salt: await sha256(enc([eph, o.ecdhSpki])), info }, hk, 256));
  z.fill(0);
  const wrapKey = await importAesKey(raw, "decrypt"); raw.fill(0);
  const bundle = await open(env, wrapKey, o.desktopVerify, { purpose: "wrap" });
  const [req, rep, token] = decodeEnc(bundle, 3);
  if (req.length !== 32 || rep.length !== 32) throw new RelayCryptoError("bad_wrap");
  const request = await importAesKey(req, "encrypt");
  const reply = await importAesKey(rep, "decrypt");
  req.fill(0); rep.fill(0);
  return { request, reply, hostApiToken: new TextDecoder().decode(token), sig: unb64u(env.sig) };
}

export const keyConfirmPlaintext = (wrapSig: Uint8Array) => sha256(utf8("llmide/keyconfirm/v1"), wrapSig);

export async function authProof(signingKey: CryptoKey, challenge: string, role: "device", tokenHashHex: string): Promise<string> {
  return b64u(new Uint8Array(await subtle.sign(ECDSA, signingKey, utf8(`llmide/relay/auth/v1\n${challenge}\n${role}\n${tokenHashHex}`))));
}
```

```ts
// A SocketLike over the relay (schema/relay/v1): HostConnection sends and receives plain Host API frames, this
// adapter seals them for the desktop and opens the desktop's replies. One relay session per instance. Never logs.
import type { SocketLike } from "../host-api/connection.ts";
import { authProof, keyConfirmPlaintext, open, RelayCryptoError, seal, sha256, unwrap, importVerifyKey } from "./crypto.ts";
import { b64u, KEY_MESSAGE_CAP, unb64u, type Envelope, type Header } from "./wire.ts";

export interface RelayDeviceKeys { token: string; signingKey: CryptoKey; ecdhKey: CryptoKey; ecdhSpki: Uint8Array; desktopSigningSpki: Uint8Array }
export interface RelaySession { epoch: number; request: CryptoKey | null; reply: CryptoKey | null; hostApiToken: string | null; sent: number }
export interface RelaySocketOptions {
  url: string; device: RelayDeviceKeys; session: RelaySession;
  createWs?: (url: string) => SocketLike; now?: () => number; onSession?: (s: RelaySession) => void;
}

const SKEW_MS = 10 * 60_000;
const hexOf = (b: Uint8Array) => [...b].map((x) => x.toString(16).padStart(2, "0")).join("");

export function createRelaySocket(o: RelaySocketOptions): SocketLike {
  const now = o.now ?? Date.now;
  const ws = (o.createWs ?? ((u) => new WebSocket(u) as unknown as SocketLike))(o.url);
  let ids: { userId: string; deviceId: string; desktopId: string } | null = null;
  let desktopVerify: CryptoKey | null = null;
  let openNonce: Uint8Array | null = null;
  let sid = ""; let sendSeq = 0; let recvSeq = 0;
  let state = 0; // 0 connecting, 1 open, 3 closed
  let chain = Promise.resolve();

  const self: SocketLike = {
    get readyState() { return state; },
    send(data: string) { chain = chain.then(() => sendFrame(data)).catch(fail); },
    close() { finish(); },
    onopen: null, onmessage: null, onclose: null, onerror: null,
  };

  function finish() {
    if (state === 3) return;
    state = 3;
    try { ws.close(); } catch { /* closed */ }
    self.onclose?.();
  }
  function fail() { self.onerror?.(); finish(); }
  const raw = (obj: unknown) => ws.send(JSON.stringify(obj));
  const header = (purpose: Header["purpose"], session: string, seq: number): Header => ({
    purpose, userId: ids!.userId, desktopId: ids!.desktopId, from: ids!.deviceId, to: ids!.desktopId,
    epoch: o.session.epoch, session, seq, issuedAt: now(), tier: "",
  });
  async function up(h: Header, plaintext: Uint8Array) {
    if (!o.session.request || ++o.session.sent > KEY_MESSAGE_CAP) throw new RelayCryptoError("key_exhausted");
    raw({ t: "env", env: await seal(h, o.session.request, plaintext, o.device.signingKey) });
  }
  async function sendOpen() {
    if (!ids || !o.session.request) return;
    openNonce = globalThis.crypto.getRandomValues(new Uint8Array(16));
    await up(header("open", "", 0), openNonce);
  }
  async function sendFrame(data: string) {
    if (state !== 1) throw new RelayCryptoError("not_open");
    await up(header("request", sid, ++sendSeq), new TextEncoder().encode(data));
  }

  async function onEnv(env: Envelope) {
    if (!ids) return;
    if (Math.abs(now() - env.issuedAt) > SKEW_MS) return; // surfaced by the caller's connection timeout
    desktopVerify ??= await importVerifyKey(o.device.desktopSigningSpki);
    if (env.purpose === "wrap") {
      const w = await unwrap(env, { deviceId: ids.deviceId, ecdhPrivate: o.device.ecdhKey, ecdhSpki: o.device.ecdhSpki, desktopVerify, desktopSigningSpki: o.device.desktopSigningSpki, currentEpoch: o.session.epoch });
      Object.assign(o.session, { epoch: env.epoch, request: w.request, reply: w.reply, hostApiToken: w.hostApiToken, sent: 0 });
      o.onSession?.(o.session);
      await up(header("keyconfirm", "", 0), await keyConfirmPlaintext(w.sig));
      return;
    }
    if (!o.session.reply) return;
    const expect = { from: ids.desktopId, to: ids.deviceId, userId: ids.userId, desktopId: ids.desktopId, epoch: o.session.epoch };
    if (env.purpose === "opened" && openNonce && state === 0) {
      const echo = await open(env, o.session.reply, desktopVerify, { ...expect, purpose: "opened" });
      if (b64u(echo) !== b64u(openNonce)) return;
      sid = env.session; sendSeq = 0; recvSeq = 0; openNonce = null; state = 1;
      self.onopen?.();
      return;
    }
    if (env.purpose === "reply" && state === 1 && env.session === sid && env.seq > recvSeq) {
      const pt = await open(env, o.session.reply, desktopVerify, { ...expect, purpose: "reply", session: sid });
      recvSeq = env.seq;
      self.onmessage?.({ data: new TextDecoder().decode(pt) });
    }
  }

  async function onControl(m: Record<string, unknown>) {
    if (m.t === "challenge") {
      const hash = hexOf(await sha256(unb64u(o.device.token)));
      raw({ t: "auth", token: o.device.token, proof: await authProof(o.device.signingKey, String(m.nonce), "device", hash) });
    } else if (m.t === "ready") {
      ids = { userId: String(m.userId), deviceId: String(m.deviceId), desktopId: String(m.desktopId) };
    } else if (m.t === "ping") {
      raw({ t: "pong" });
    } else if (m.t === "peer" && ids && m.id === ids.desktopId) {
      if (m.online === true && state === 0) await sendOpen();
      if (m.online === false) finish();
    } else if (m.t === "env") {
      await onEnv(m.env as Envelope);
    } else if (m.t === "err" && m.code === "auth_failed") {
      fail();
    }
  }

  ws.onmessage = (e) => {
    let m: Record<string, unknown>;
    try { m = JSON.parse(String(e.data)); } catch { return fail(); }
    // Crypto failures drop the one envelope (a hostile relay cannot crash the session by sending junk).
    chain = chain.then(() => onControl(m)).catch((err) => { if (!(err instanceof RelayCryptoError) || err.code === "key_exhausted") fail(); });
  };
  ws.onclose = () => finish();
  ws.onerror = () => fail();
  return self;
}
```

```js
// Loopback WebSocket path the desktop host uses to carry relay-delivered Host API frames into the gateway (relay plan
// ruling R-4/R-5). Only the host that spawned this core can open it (bus host proof); never a browser (no Origin).
// After the upgrade the session is an ordinary Host API session: hello, then PIN pairing or a device token.
import { handshakeRefusal, acceptUpgrade } from './ws-server.mjs';
import { verifyBusHostProof } from '../core/host-approval.mjs';
import { RELAY_TIER_SCOPES } from '../core/host-api-relay.mjs';

export const RELAY_BRIDGE_PATH = '/host-api/relay-bridge';
const LOOPBACK = new Set(['127.0.0.1', '::1', '::ffff:127.0.0.1']);

export function bridgeRefusal(req, env = process.env) {
  if (req.url !== RELAY_BRIDGE_PATH) return 404;
  if (!LOOPBACK.has(req.socket?.remoteAddress)) return 403;
  if (req.headers.origin !== undefined) return 403;
  if (!verifyBusHostProof(req, env)) return 403;
  if (!Object.hasOwn(RELAY_TIER_SCOPES, req.headers['x-llmide-relay-tier'] ?? '')) return 400;
  return handshakeRefusal(req);
}

export function attachRelayBridge(server, { ensureGateway, env = process.env, maxConnections = 8 }) {
  let nextId = 0;
  const live = new Set();
  server.on('upgrade', (req, socket, head) => {
    socket.on('error', () => {});
    const status = bridgeRefusal(req, env) ?? (live.size >= maxConnections ? 503 : null);
    if (status) {
      socket.end(`HTTP/1.1 ${status} Refused\r\nConnection: close\r\nContent-Length: 0\r\n\r\n`);
      socket.destroy();
      return;
    }
    socket.pause(); // the gateway loads lazily; keep early frames buffered until it exists
    ensureGateway().then((gateway) => {
      const conn = acceptUpgrade(req, socket, head);
      socket.resume();
      const session = { id: `relay-${++nextId}`, conn, relayTier: req.headers['x-llmide-relay-tier'] };
      live.add(conn);
      conn.on('message', (text) => gateway.receive(session, text));
      conn.on('close', () => { live.delete(conn); gateway.closed(session); });
      gateway.opened(session, socket.remoteAddress);
    }, () => socket.destroy());
  });
  return { close: () => { for (const c of live) { try { c.close(1001); } catch { /* closed */ } } } };
}
```

```rust
use aes_gcm::aead::{Aead, KeyInit, Payload};
use aes_gcm::{Aes256Gcm, Nonce};
use base64::engine::general_purpose::URL_SAFE_NO_PAD;
use base64::Engine;
use hkdf::Hkdf;
use p256::ecdsa::signature::{Signer, Verifier};
use p256::ecdsa::{Signature, SigningKey, VerifyingKey};
use p256::pkcs8::{DecodePublicKey, EncodePublicKey};
use p256::{PublicKey, SecretKey};
use rand_core::{OsRng, RngCore};
use serde::{Deserialize, Serialize};
use sha2::{Digest, Sha256};

pub const BUCKETS: [usize; 6] = [1024, 4096, 16384, 65536, 262144, 1048576];
pub const MAX_FRAME: usize = 1048576 - 4;
pub const KEY_MESSAGE_CAP: u64 = 1 << 24;
pub type Result<T> = std::result::Result<T, &'static str>;

pub enum F<'a> { U(u64), S(&'a str), B(&'a [u8]) }

pub fn enc(fields: &[F]) -> Vec<u8> {
    let mut out = Vec::new();
    for f in fields {
        let v: Vec<u8> = match f { F::U(n) => n.to_be_bytes().to_vec(), F::S(s) => s.as_bytes().to_vec(), F::B(b) => b.to_vec() };
        out.extend_from_slice(&(v.len() as u32).to_be_bytes());
        out.extend_from_slice(&v);
    }
    out
}

pub fn decode_enc(b: &[u8], count: usize) -> Result<Vec<Vec<u8>>> {
    let (mut out, mut off) = (Vec::new(), 0usize);
    while off < b.len() {
        if off + 4 > b.len() { return Err("bad_encoding"); }
        let n = u32::from_be_bytes(b[off..off + 4].try_into().unwrap()) as usize;
        off += 4;
        if off + n > b.len() { return Err("bad_encoding"); }
        out.push(b[off..off + n].to_vec());
        off += n;
    }
    if out.len() != count { return Err("bad_encoding"); }
    Ok(out)
}

#[derive(Clone, Debug, PartialEq)]
pub struct Header { pub purpose: String, pub user_id: String, pub desktop_id: String, pub from: String, pub to: String,
    pub epoch: u64, pub session: String, pub seq: u64, pub issued_at: u64, pub tier: String }

#[derive(Clone, Debug, Serialize, Deserialize)]
#[serde(rename_all = "camelCase", deny_unknown_fields)]
pub struct Envelope { pub v: u64, pub purpose: String, pub user_id: String, pub desktop_id: String, pub from: String, pub to: String,
    pub epoch: u64, pub session: String, pub seq: u64, pub issued_at: u64, pub tier: String,
    pub nonce: String, pub ct: String, pub sig: String, #[serde(skip_serializing_if = "Option::is_none")] pub eph: Option<String> }

impl Envelope {
    pub fn header(&self) -> Header {
        Header { purpose: self.purpose.clone(), user_id: self.user_id.clone(), desktop_id: self.desktop_id.clone(), from: self.from.clone(), to: self.to.clone(),
            epoch: self.epoch, session: self.session.clone(), seq: self.seq, issued_at: self.issued_at, tier: self.tier.clone() }
    }
}

fn header_fields(h: &Header) -> Vec<F<'_>> {
    vec![F::U(1), F::S(&h.purpose), F::S(&h.user_id), F::S(&h.desktop_id), F::S(&h.from), F::S(&h.to), F::U(h.epoch), F::S(&h.session), F::U(h.seq), F::U(h.issued_at), F::S(&h.tier)]
}
fn with<'a>(h: &'a Header, rest: &[&'a [u8]]) -> Vec<u8> {
    let mut f = header_fields(h);
    for r in rest { f.push(F::B(r)); }
    enc(&f)
}
fn context(purpose: &str) -> Vec<u8> { format!("llmide/{purpose}/v1\0").into_bytes() }
fn sha(parts: &[&[u8]]) -> [u8; 32] { let mut d = Sha256::new(); for p in parts { d.update(p); } d.finalize().into() }
fn hkdf32(ikm: &[u8], salt: &[u8], info: &[u8]) -> [u8; 32] {
    let mut out = [0u8; 32];
    Hkdf::<Sha256>::new(Some(salt), ikm).expand(info, &mut out).expect("32 bytes is a valid HKDF length");
    out
}
fn b64d(s: &str) -> Result<Vec<u8>> { URL_SAFE_NO_PAD.decode(s).map_err(|_| "bad_base64") }

pub fn pad(b: &[u8]) -> Result<Vec<u8>> {
    if b.len() > MAX_FRAME { return Err("frame_too_large"); }
    let size = *BUCKETS.iter().find(|&&s| s >= b.len() + 4).unwrap();
    let mut out = vec![0u8; size];
    out[..4].copy_from_slice(&(b.len() as u32).to_be_bytes());
    out[4..4 + b.len()].copy_from_slice(b);
    Ok(out)
}

pub fn unpad(b: &[u8]) -> Result<Vec<u8>> {
    if !BUCKETS.contains(&b.len()) { return Err("bad_padding"); }
    let n = u32::from_be_bytes(b[..4].try_into().unwrap()) as usize;
    if n > b.len() - 4 || b[4 + n..].iter().any(|&x| x != 0) { return Err("bad_padding"); }
    Ok(b[4..4 + n].to_vec())
}

pub fn device_keys(root: &[u8; 32], user_id: &str, desktop_id: &str, device_id: &str, epoch: u64) -> ([u8; 32], [u8; 32]) {
    let salt = sha(&[b"llmide-relay-v1", &enc(&[F::S(user_id), F::S(desktop_id)])]);
    let key = |purpose: &str, sender: &str, recipient: &str| hkdf32(root, &salt, &enc(&[F::S(purpose), F::U(epoch), F::S(""), F::S(sender), F::S(recipient)]));
    (key("request", device_id, desktop_id), key("reply", desktop_id, device_id))
}

pub fn seal(h: &Header, key: &[u8; 32], plaintext: &[u8], signer: &SigningKey, extra: &[u8], nonce: Option<[u8; 12]>) -> Result<Envelope> {
    let nonce = nonce.unwrap_or_else(|| { let mut n = [0u8; 12]; OsRng.fill_bytes(&mut n); n });
    let ct = Aes256Gcm::new(key.into()).encrypt(Nonce::from_slice(&nonce), Payload { msg: &pad(plaintext)?, aad: &with(h, &[extra]) }).map_err(|_| "encrypt")?;
    let mut msg = context(&h.purpose);
    msg.extend(with(h, &[extra, &nonce, &ct]));
    let sig: Signature = signer.sign(&msg);
    Ok(Envelope { v: 1, purpose: h.purpose.clone(), user_id: h.user_id.clone(), desktop_id: h.desktop_id.clone(), from: h.from.clone(), to: h.to.clone(),
        epoch: h.epoch, session: h.session.clone(), seq: h.seq, issued_at: h.issued_at, tier: h.tier.clone(),
        nonce: URL_SAFE_NO_PAD.encode(nonce), ct: URL_SAFE_NO_PAD.encode(&ct), sig: URL_SAFE_NO_PAD.encode(sig.to_bytes()),
        eph: (!extra.is_empty()).then(|| URL_SAFE_NO_PAD.encode(extra)) })
}

/// Signature check alone (verify before any decryption).
pub fn verify_envelope(env: &Envelope, verifier: &VerifyingKey) -> Result<(Vec<u8>, Vec<u8>, Vec<u8>)> {
    if env.v != 1 { return Err("bad_version"); }
    let extra = match &env.eph { Some(e) => b64d(e)?, None => Vec::new() };
    let (nonce, ct) = (b64d(&env.nonce)?, b64d(&env.ct)?);
    if nonce.len() != 12 || ct.len() < BUCKETS[0] + 16 { return Err("bad_ciphertext"); }
    let sig = Signature::from_slice(&b64d(&env.sig)?).map_err(|_| "bad_signature")?;
    let h = env.header();
    let mut msg = context(&h.purpose);
    msg.extend(with(&h, &[&extra, &nonce, &ct]));
    verifier.verify(&msg, &sig).map_err(|_| "bad_signature")?;
    Ok((extra, nonce, ct))
}

pub fn open(env: &Envelope, key: &[u8; 32], verifier: &VerifyingKey) -> Result<Vec<u8>> {
    let (extra, nonce, ct) = verify_envelope(env, verifier)?;
    let pt = Aes256Gcm::new(key.into()).decrypt(Nonce::from_slice(&nonce), Payload { msg: &ct, aad: &with(&env.header(), &[&extra]) }).map_err(|_| "bad_ciphertext")?;
    unpad(&pt)
}

pub struct WrapInput<'a> { pub user_id: &'a str, pub desktop_id: &'a str, pub device_id: &'a str, pub epoch: u64, pub tier: &'a str,
    pub seq: u64, pub issued_at: u64, pub device_ecdh_spki: &'a [u8], pub desktop_signing_spki: &'a [u8],
    pub request: &'a [u8; 32], pub reply: &'a [u8; 32], pub host_api_token: &'a str }

pub fn make_wrap(w: &WrapInput, signer: &SigningKey, eph: Option<&SecretKey>, nonce: Option<[u8; 12]>) -> Result<Envelope> {
    let fresh;
    let eph = match eph { Some(k) => k, None => { fresh = SecretKey::random(&mut OsRng); &fresh } };
    let eph_spki = eph.public_key().to_public_key_der().map_err(|_| "eph")?.as_bytes().to_vec();
    let device = PublicKey::from_public_key_der(w.device_ecdh_spki).map_err(|_| "bad_device_key")?;
    let z = p256::ecdh::diffie_hellman(eph.to_nonzero_scalar(), device.as_affine());
    let info = enc(&[F::S("llmide/wrap/v1"), F::U(w.epoch), F::S(w.device_id), F::B(&sha(&[w.device_ecdh_spki])), F::B(&sha(&[w.desktop_signing_spki])), F::S(w.tier)]);
    let key = hkdf32(z.raw_secret_bytes(), &sha(&[&enc(&[F::B(&eph_spki), F::B(w.device_ecdh_spki)])]), &info);
    let h = Header { purpose: "wrap".into(), user_id: w.user_id.into(), desktop_id: w.desktop_id.into(), from: w.desktop_id.into(), to: w.device_id.into(),
        epoch: w.epoch, session: String::new(), seq: w.seq, issued_at: w.issued_at, tier: w.tier.into() };
    seal(&h, &key, &enc(&[F::B(w.request), F::B(w.reply), F::S(w.host_api_token)]), signer, &eph_spki, nonce)
}
```

```rust
//! The desktop-authoritative device registry (relay design 4.6, C3) plus the epoch root. Stored only in the OS
//! secret store (integrity-protected by the OS), written only by the user's link confirm, keyconfirm and revoke.
//! Rotation and every wrap go only to devices listed here; the relay's copy is never trusted.
use base64::engine::general_purpose::URL_SAFE_NO_PAD;
use base64::Engine;
use rand_core::{OsRng, RngCore};
use serde::{Deserialize, Serialize};

use crate::secrets::SecretBackend;

pub const ACCOUNT: &str = "relay-registry-v1";

#[derive(Clone, Debug, Default, Serialize, Deserialize)]
pub struct Registry { pub version: u32, pub enabled: bool, pub epoch: u64, pub root: String, pub desktop_id: String, pub user_id: String, pub devices: Vec<Device> }

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct Device { pub device_id: String, pub label: String, pub tier: String, pub signing_key: String, pub ecdh_key: String, pub linked_at: u64,
    pub confirmed: bool, pub host_api_token: String, pub wrap: Option<String>, pub wrap_sig: String, pub reply_count: u64 }

pub fn load(store: &dyn SecretBackend) -> Result<Registry, String> {
    match store.get(ACCOUNT).map_err(|e| e.to_string())? {
        Some(raw) => serde_json::from_str(&raw).map_err(|_| "the relay registry is unreadable".to_string()),
        None => Ok(Registry { version: 1, ..Default::default() }),
    }
}

pub fn save(store: &dyn SecretBackend, r: &Registry) -> Result<(), String> {
    store.set(ACCOUNT, &serde_json::to_string(r).map_err(|e| e.to_string())?).map_err(|e| e.to_string())
}

impl Registry {
    pub fn ensure_root(&mut self) {
        if self.epoch == 0 {
            let mut k = [0u8; 32];
            OsRng.fill_bytes(&mut k);
            self.root = URL_SAFE_NO_PAD.encode(k);
            self.epoch = 1;
        }
    }
    pub fn root_bytes(&self) -> Result<[u8; 32], String> {
        URL_SAFE_NO_PAD.decode(&self.root).ok().and_then(|v| v.try_into().ok()).ok_or_else(|| "the relay root is unreadable".to_string())
    }
    pub fn add(&mut self, d: Device) {
        self.devices.retain(|x| x.device_id != d.device_id);
        self.devices.push(d);
    }
    pub fn device(&self, id: &str) -> Option<&Device> { self.devices.iter().find(|d| d.device_id == id) }
    /// Marks the device confirmed only when it proves it unwrapped THIS wrap (relay 4.4 key confirmation).
    pub fn confirm(&mut self, id: &str, plaintext: &[u8]) -> bool {
        let Some(d) = self.devices.iter_mut().find(|d| d.device_id == id) else { return false };
        let Ok(sig) = URL_SAFE_NO_PAD.decode(&d.wrap_sig) else { return false };
        let want = crate::relay::crypto::key_confirm_plaintext(&sig);
        let ok = plaintext.len() == 32 && plaintext.iter().zip(want.iter()).fold(0u8, |a, (x, y)| a | (x ^ y)) == 0;
        if ok { d.confirmed = true; d.wrap = None; }
        ok
    }
    pub fn remove(&mut self, id: &str) { self.devices.retain(|d| d.device_id != id); }
}
```

```rust
//! Loopback client for the core's /host-api/relay-bridge (relay plan R-4/R-5). Sends the bus host proof and the
//! device tier; the core treats the connection as an ordinary Host API session. Never logs frames.
use std::net::TcpStream;
use std::sync::mpsc::{channel, Receiver, Sender};
use std::time::Duration;

use tungstenite::client::IntoClientRequest;
use tungstenite::http::HeaderValue;
use tungstenite::{Message, WebSocket};

pub fn bridge_url(core_url: &str) -> Result<String, String> {
    let u = url::Url::parse(core_url).map_err(|_| "bad core url")?;
    if u.scheme() != "http" || u.host_str() != Some("127.0.0.1") { return Err("the relay bridge is loopback-only".into()); }
    Ok(format!("ws://127.0.0.1:{}/host-api/relay-bridge", u.port_or_known_default().unwrap_or(80)))
}

fn connect(core_url: &str, tier: &str) -> Result<WebSocket<TcpStream>, String> {
    let url = bridge_url(core_url)?;
    let mut req = url.as_str().into_client_request().map_err(|e| e.to_string())?;
    let proof = crate::host_approval::bus_proof()?;
    req.headers_mut().insert("x-llmide-host-nonce", HeaderValue::from_str(&proof).map_err(|_| "bad proof")?);
    req.headers_mut().insert("x-llmide-relay-tier", HeaderValue::from_str(tier).map_err(|_| "bad tier")?);
    let stream = TcpStream::connect(url.trim_start_matches("ws://").split('/').next().unwrap()).map_err(|e| e.to_string())?;
    stream.set_read_timeout(Some(Duration::from_millis(50))).map_err(|e| e.to_string())?;
    let (ws, _) = tungstenite::client(req, stream).map_err(|_| "the core refused the relay bridge".to_string())?;
    Ok(ws)
}

/// One bridged Host API connection, pumped by its own thread: core frames arrive on `rx`, frames to the core go on `tx`.
pub struct BridgeSession { tx: Sender<Option<String>>, rx: Receiver<String> }

impl BridgeSession {
    pub fn connect(core_url: &str, tier: &str) -> Result<Self, String> {
        let mut ws = connect(core_url, tier)?;
        let (to_core, from_main) = channel::<Option<String>>();
        let (to_main, rx) = channel::<String>();
        std::thread::spawn(move || loop {
            while let Ok(item) = from_main.try_recv() {
                match item { Some(t) => { if ws.send(Message::text(t)).is_err() { return; } } None => { let _ = ws.close(None); return; } }
            }
            match ws.read() {
                Ok(Message::Text(t)) => { if to_main.send(t.to_string()).is_err() { return; } }
                Ok(Message::Close(_)) => return,
                Ok(_) => {}
                Err(tungstenite::Error::Io(e)) if matches!(e.kind(), std::io::ErrorKind::WouldBlock | std::io::ErrorKind::TimedOut) => {}
                Err(_) => return,
            }
        });
        Ok(BridgeSession { tx: to_core, rx })
    }
    pub fn send(&self, frame: &str) -> bool { self.tx.send(Some(frame.to_string())).is_ok() }
    pub fn try_recv(&self) -> Option<String> { self.rx.try_recv().ok() }
    pub fn close(&self) { let _ = self.tx.send(None); }
}

/// Pairs a relay device with the core through the bridge and returns its Host API device token (capped to `tier`).
pub fn pair(core_url: &str, tier: &str, label: &str, pin: &str) -> Result<String, String> {
    let s = BridgeSession::connect(core_url, tier)?;
    let frame = |id: &str, command: &str, payload: serde_json::Value| serde_json::json!({ "apiVersion": 1, "id": id, "type": "request", "command": command, "payload": payload, "ts": 0 }).to_string();
    s.send(&frame("h", "host.hello", serde_json::json!({ "clientName": label, "clientVersion": "relay-1", "platform": if tier == "ios" { "ios" } else { "web" }, "apiVersions": [1] })));
    s.send(&frame("p", "host.auth.pair", serde_json::json!({ "pin": pin })));
    let deadline = std::time::Instant::now() + Duration::from_secs(10);
    while std::time::Instant::now() < deadline {
        if let Some(text) = s.try_recv() {
            let v: serde_json::Value = serde_json::from_str(&text).map_err(|_| "bad core frame")?;
            if v["replyTo"] == "p" {
                s.close();
                return v["result"]["token"].as_str().map(str::to_string).ok_or_else(|| "The PIN was refused. Try again.".into());
            }
        } else { std::thread::sleep(Duration::from_millis(20)); }
    }
    s.close();
    Err("The core did not answer the pairing in time.".into())
}
```

```rust
//! Outbound relay connection (relay plan R-4): one WSS socket to accounts/relay, challenge auth with the desktop
//! signing key, desktop-side verification of every envelope against the LOCAL registry, one loopback bridge session
//! per device session. Off by default (registry.enabled); off means no outbound traffic at all.
use std::collections::HashMap;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use base64::engine::general_purpose::URL_SAFE_NO_PAD;
use base64::Engine;
use p256::ecdsa::{signature::Signer, Signature, SigningKey, VerifyingKey};
use p256::pkcs8::DecodePublicKey;
use rand_core::{OsRng, RngCore};
use sha2::{Digest, Sha256};

use super::crypto::{self, Envelope, Header, KEY_MESSAGE_CAP};
use super::registry::Registry;

const SKEW_MS: u64 = 10 * 60_000;
const MAX_SESSIONS: usize = 4;
const MAX_SESSIONS_PER_DEVICE: usize = 2;

#[derive(Debug)]
pub enum Out { Relay(String), Bridge { device: String, session: String, frame: String }, OpenBridge { device: String, session: String, tier: String }, CloseDevice(String) }

struct Session { device: String, recv_seq: u64, send_seq: u64 }

pub struct Desktop { pub reg: Registry, pub signer: SigningKey, sessions: HashMap<String, Session> }

impl Desktop {
    pub fn new(reg: Registry, signer: SigningKey) -> Self { Desktop { reg, signer, sessions: HashMap::new() } }

    fn keys(&self, device: &str) -> Option<([u8; 32], [u8; 32])> {
        let root = self.reg.root_bytes().ok()?;
        Some(crypto::device_keys(&root, &self.reg.user_id, &self.reg.desktop_id, device, self.reg.epoch))
    }
    fn header(&self, purpose: &str, device: &str, session: &str, seq: u64, now: u64) -> Header {
        Header { purpose: purpose.into(), user_id: self.reg.user_id.clone(), desktop_id: self.reg.desktop_id.clone(), from: self.reg.desktop_id.clone(),
            to: device.into(), epoch: self.reg.epoch, session: session.into(), seq, issued_at: now, tier: String::new() }
    }
    fn seal_down(&mut self, purpose: &str, device: &str, session: &str, seq: u64, pt: &[u8], now: u64) -> Option<String> {
        let d = self.reg.devices.iter_mut().find(|d| d.device_id == device)?;
        d.reply_count += 1;
        if d.reply_count > KEY_MESSAGE_CAP { return None; } // refuse; rotation is a later slice (R4)
        let (_, rp) = self.keys(device)?;
        let env = crypto::seal(&self.header(purpose, device, session, seq, now), &rp, pt, &self.signer, &[], None).ok()?;
        serde_json::to_string(&serde_json::json!({ "t": "env", "env": env })).ok()
    }

    /// Every check fails closed and silently (a hostile relay learns nothing from refusals).
    pub fn on_env(&mut self, env: Envelope, now: u64) -> Vec<Out> {
        let ok_header = env.user_id == self.reg.user_id && env.desktop_id == self.reg.desktop_id && env.to == self.reg.desktop_id && env.epoch == self.reg.epoch;
        if !ok_header || now.abs_diff(env.issued_at) > SKEW_MS { return vec![]; }
        let Some(dev) = self.reg.device(&env.from).cloned() else { return vec![] }; // C3: local registry only
        let Ok(spki) = URL_SAFE_NO_PAD.decode(&dev.signing_key) else { return vec![] };
        let Ok(vk) = VerifyingKey::from_public_key_der(&spki) else { return vec![] };
        let Some((rq, _)) = self.keys(&dev.device_id) else { return vec![] };
        let Ok(pt) = crypto::open(&env, &rq, &vk) else { return vec![] };
        match env.purpose.as_str() {
            "keyconfirm" => { self.reg.confirm(&dev.device_id, &pt); vec![] }
            _ if !dev.confirmed => vec![],
            "open" if pt.len() == 16 && env.session.is_empty() => {
                let per_device = self.sessions.values().filter(|s| s.device == dev.device_id).count();
                if self.sessions.len() >= MAX_SESSIONS || per_device >= MAX_SESSIONS_PER_DEVICE { return vec![]; }
                let mut sid = [0u8; 16];
                OsRng.fill_bytes(&mut sid);
                let sid = URL_SAFE_NO_PAD.encode(sid);
                self.sessions.insert(sid.clone(), Session { device: dev.device_id.clone(), recv_seq: 0, send_seq: 0 });
                let Some(opened) = self.seal_down("opened", &dev.device_id, &sid, 0, &pt, now) else { return vec![] };
                vec![Out::OpenBridge { device: dev.device_id.clone(), session: sid, tier: dev.tier.clone() }, Out::Relay(opened)]
            }
            "request" => {
                let Some(s) = self.sessions.get_mut(&env.session) else { return vec![] };
                if s.device != dev.device_id || env.seq <= s.recv_seq { return vec![]; }
                s.recv_seq = env.seq;
                match String::from_utf8(pt) { Ok(frame) => vec![Out::Bridge { device: dev.device_id, session: env.session, frame }], Err(_) => vec![] }
            }
            _ => vec![],
        }
    }

    pub fn reply(&mut self, device: &str, session: &str, frame: &str, now: u64) -> Option<String> {
        let s = self.sessions.get_mut(session)?;
        if s.device != device { return None; }
        s.send_seq += 1;
        let seq = s.send_seq;
        self.seal_down("reply", device, session, seq, frame.as_bytes(), now)
    }

    pub fn drop_device(&mut self, device: &str) -> Vec<String> {
        let gone: Vec<String> = self.sessions.iter().filter(|(_, s)| s.device == device).map(|(k, _)| k.clone()).collect();
        for k in &gone { self.sessions.remove(k); }
        gone
    }
}

pub fn auth_proof(signer: &SigningKey, challenge: &str, access_token: &str) -> String {
    let hash: String = Sha256::digest(access_token.as_bytes()).iter().map(|b| format!("{b:02x}")).collect();
    let sig: Signature = signer.sign(crypto::auth_message(challenge, "desktop", &hash).as_bytes());
    URL_SAFE_NO_PAD.encode(sig.to_bytes())
}
```

Below the state machine, the socket loop (`pub fn start(cfg: ClientConfig) -> RelayHandle`) runs on one `std::thread`:
1. If `registry.enabled` is false, return a handle and open no socket (zero outbound traffic).
2. Connect with `tungstenite::connect(req)` (WSS via rustls) and set a 50 ms read timeout on the underlying `TcpStream`; for `MaybeTlsStream::Rustls`, use `get_ref().sock`. Read `challenge`, then send `{t:"auth", token, proof: auth_proof(...)}` and expect `ready` (store `desktopId`/`userId`, and fail if they differ from the registry).
3. Main loop: (a) read one relay message: on `ping` send `pong`; on `env` call `Desktop::on_env`, perform each `Out` (`OpenBridge` → `BridgeSession::connect(core_url, tier)` kept in `HashMap<session, BridgeSession>`; `Bridge` → `session.send(frame)`; `Relay(t)` → `ws.send`); on `peer {online:false}` call `drop_device` and close those bridges; on `peer {online:true}` resend that device's pending `wrap`. (b) For every bridge, `try_recv()` core frames → `Desktop::reply` → `ws.send`. (c) Every 10 minutes, call `cfg.token()` for a refreshed access token and send `auth` again on the same socket. (d) After a `keyconfirm` changes `reg`, `registry::save` it.
4. On any error, close all bridges, then back off 1 s, 2 s, 4 s … up to 60 s with ±20 % jitter (`OsRng`), and reconnect.
