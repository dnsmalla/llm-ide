# Encrypted Sync SP6: Box Storage Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Box becomes a second sync storage behind the existing `SyncStore` interface, next to MEGA. The desktop
uploads, downloads, lists, deletes, removes trees and watches one dedicated Box folder. The web app and the iPhone app
read snapshots and queue prompts through Box, signed in with the user's own Box app. Settings lets the user choose
MEGA, Box or (disabled until SP5) Own server, and switching storage resets the wraps.

**Architecture:** The desktop adapter `extension/connectors/sync-store/box.mjs` reuses the Library Box connector's
HTTP layer (`extension/connectors/box.mjs`: pinned fetch, Box host allowlist, redirect re-validation, byte caps, 429
back-off, 401 re-auth). That layer is generalized from GET-only to any method plus token forms. The desktop signs in
once with Box OAuth 2.0 consent in the system browser and a loopback callback on the core
(`/kb/sync/box/callback`). The single-use refresh token lives in the core vault and is rewritten on every rotation.
The browser (`web/src/sync/box-store.ts`) and the iPhone (`ios_app/SharedProtocol/.../BoxClient.swift`) each sign in
with the same user-owned Box app. Its client id and secret reach them in the pairing QR. Everything stored in Box is
a sealed sync v1 envelope. No envelope, manifest or key format changes. The QR gains two optional fields for Box.

**Tech Stack:** Node 22 core (pure `node:http`, better-sqlite3, Node test runner), React 19 + TypeScript (desktop
Settings card and PWA), WebCrypto, Swift 5.9 / SwiftPM (SharedProtocol, swift-testing), SwiftUI +
`ASWebAuthenticationSession` (iOS 16). No new dependency anywhere.

## Decisions for the user (secure, free defaults; the plan builds the default)

| # | Decision | Default built here | Why |
|---|---|---|---|
| D1 | Desktop Box auth: CCG (subject = user) or one-time OAuth consent | **One-time OAuth consent only.** CCG is not built in SP6 | One "User Authentication (OAuth 2.0)" Box app then serves desktop, web and iPhone with one client id and secret. A CCG app is a different app type and cannot do the devices' consent, so CCG would mean two apps and two secrets. CCG with a user subject needs "App + Enterprise Access", "Generate user access tokens" and admin authorization; whether a free Box Individual account can authorize it is **unverified**. The existing Library connector usually runs as the enterprise service account, which sync must refuse anyway (spec §8.2). Spec Q6 already counts the consent as setup, not login. This changes the spec's Q6 *default order* (CCG first); the user should confirm. |
| D2 | How phone and web get the Box app's client secret | **In the pairing QR** (new optional fields `bi` = client id, `bs` = client secret, only when `st` is `box:…`), then kept in device storage (iOS Keychain, browser IndexedDB device record) | Box documents `client_secret` for the code exchange and no PKCE for third-party apps, so a device needs the secret. The device needs it *before* it can read anything from Box, so it cannot ride the encrypted ack or wrap. The QR is the optical, MITM-resistant channel already used for `es`. No VPS token-exchange shim (spec Q7: it would put a credential on a server). |
| D3 | Which Box account holds the sync folder | **A Box account kept only for LLM-IDE** (free Individual, 10 GB), recommended in plain words on every setup screen; the user's main account works but is warned about | Box has no app-folder scope. Writing the inbox needs `root_readwrite`, so every device token reaches the whole account. A dedicated account limits a stolen device token to ciphertext. |
| D4 | Box tokens in the browser | **Memory only, per app session**, revoked (`POST /oauth2/revoke`) on Lock and on page close; a "Connect Box" click each session (Box's own login cookie makes it one click) | Same rule as the MEGA password (spec §8.3 item 5). Nothing a script could later read from IndexedDB grants Box access. The client id and secret do sit in IndexedDB: they are the user's own app credentials, useless without a Box login of the user, and revocable in the Box console. |
| D5 | Switching storage kind (MEGA ↔ Box) | **Resets publish state (SP1 store-change reset), forgets paired devices and rotates keys** | Each device's pairing names the old storage (`st`), so it can never read the new one. Leaving the rows would keep wraps for devices that cannot use them. A change *within* one kind (new MEGA folder or account) keeps SP1's behaviour: reset only. |
| D6 | Old data after a kind switch | **Delete `<syncId>/` on the old storage, best effort**, before switching | Leaves no ciphertext behind. A failure does not block the switch. |
| D7 | iPhone redirect URI | **`llmide-box://oauth`** (custom scheme caught by `ASWebAuthenticationSession`); fallback: the PWA's `https://<pwa-origin>/box-callback.html`, which forwards an `i.`-prefixed state to `llmide-box://oauth` | Box's current OAuth guide names only https and loopback redirect URIs. Box's own older iOS SDK used custom schemes (`boxsdk-<clientId>://boxsdkoauth2redirect`). Task 10 checks this in the Box console before building the UI. |
| D8 | Old versions of replaced files | **Deleted through the API after every replace** (`DELETE /files/:id/versions/:vid`); the deleted versions sit in Box's trash until Box purges them | Only `key.bin`, `wrap.bin` and `manifest.bin` are replaced in place; everything else has a fresh name. Box documents version deletion as "move to trash" and documents no permanent purge for versions. The trashed copies are ciphertext under keys that rotation retires. Box tracks versions only on paid plans, so on a free account there is nothing to delete. |

## Global Constraints

- Storage holds only sealed sync v1 envelopes. The one exception stays the Settings probe: two bytes `ok` under a random name, deleted at once.
- A path segment matches `^[A-Za-z0-9_.-]{1,64}$` and is never `.` or `..`. A path has 1 to 6 segments. A file is at most 1,052,672 bytes (`MAX_FILE_BYTES = 1048576 + 4096`). Every adapter calls `checkPath` before any I/O.
- Folder layout is unchanged (spec §3): `<syncId>/d/<dir>/{key.bin, wrap.bin, manifest.bin, s/…, in/…, out/…}` and `<syncId>/e/<slot>/`. On Box the root is a folder named `llmide-sync` (editable, one segment) directly under the account's "All Files" (folder id `0`).
- `put` is atomic (old bytes or new bytes, never a mix). On Box a replace is an upload of a new **version** of the existing file, never delete-then-upload.
- `remove` and `removeTree` purge permanently: `DELETE /files/:id` (or `/folders/:id?recursive=true`), then `DELETE …/trash`. A missing file is not an error.
- Devices write only new, uniquely named files (`in/`, `e/<slot>/`). They never replace and never delete.
- Rate limits: Box answers 429 with `retry-after` in seconds. The desktop adapter waits at most 10 s in-process (`MAX_WAIT_MS`), at most 3 times (the existing `MAX_HTTP_RETRIES`). A longer `retry-after` surfaces at once as `SYNC_RATE_LIMITED`, and the scheduler's existing back-off (60 s doubling to 15 min) takes over. Devices never sleep in the store; they surface `SYNC_RATE_LIMITED` and the web controller doubles its poll interval (existing code). Budget (spec §10): Box allows 1000 requests per minute per user and 240 uploads per minute per user; sync uses about 30 per minute.
- Refresh tokens are single use and expire after 60 days unused. Every rotation is persisted **before** the new access token is used: desktop in the vault (`sync.boxRefreshToken`), iPhone in the Keychain, web in memory only (D4).
- Secrets never appear in a log line, an error message, a route response or a fixture: the client secret, refresh tokens, access tokens, authorization codes and the PKCE verifier. Errors carry `SYNC_*` codes only. Box's own error text is never echoed to the callback page or to a client.
- Where each secret lives: desktop, the core vault (keychain-rooted; keys `sync.boxClientSecret`, `sync.boxRefreshToken`, both server-internal); the non-secret `clientId`, `folder` and masked `account` live in `sync_state.store_config`. iPhone, the Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, service `com.llmide.sync`, account `box-session`). Browser: tokens in memory only; client id and secret in the IndexedDB device record.
- Box OAuth endpoints: authorize `https://account.box.com/api/oauth2/authorize`, token `https://api.box.com/oauth2/token`, revoke `https://api.box.com/oauth2/revoke`. API `https://api.box.com/2.0`, uploads `https://upload.box.com/api/2.0`. Direct upload is limited to 50 MB, far above our 1 MiB files.
- PKCE (`code_challenge`, S256) is sent on every authorize request and `code_verifier` on every code exchange. Box does not document it: Box may accept it or ignore it, and nothing relies on it. The client secret is always sent too.
- Redirect URIs the user registers in the Box app: `http://127.0.0.1/kb/sync/box/callback` (desktop; Box's guide says loopback URIs match on any port), `https://<pwa-origin>/box-callback.html` (web, and the iPhone fallback), `llmide-box://oauth` (iPhone, D7). CORS domain: the PWA origin. Scope: "Read and write all files and folders stored in Box".
- No Rust change (`desktop/src-tauri` is being edited by another workstream). The desktop opens the authorize page through the existing host command `open_external_url`.
- No new npm or Swift dependency.
- Module layers (ESLint-enforced, zero violations): `connectors/` may import `core`, `kb`, `server` libs. `routes/sync/*` are route modules: nothing imports them except `server.mjs` and other `routes/sync` modules. `server/auth-routes.mjs` is a route module too, so shared helpers move to `server/route-http.mjs`.
- Wire change: `SERVER_API_VERSION` 113 → **114**, with the new routes in `ALL_ENDPOINTS`, `schema/http/sync.schema.json` + fixtures, regenerated `extension/src/lib/api-types.ts`, `docs/reference/api/openapi.yaml`, `schema/http/INVENTORY.md`, and `mac/Sources/APIContractLab/Routes.swift` skip entries.
- Commits: Conventional Commits, one concern per commit, on `main` (user rule: no branches). Do not push. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

3. Split the byte reader (keep `readCapped`'s text-double fallback):

```js
function checkLength(res, max) {
  const len = Number(res.headers?.get?.('content-length'));
  if (Number.isFinite(len) && len > max) { try { void res.body?.cancel?.(); } catch { /* ignore */ } throw refuse(`response larger than ${max} bytes`); }
}

/** A body as a Buffer with a hard byte cap; an absent body is empty. */
export async function readCappedBuffer(res, max) {
  checkLength(res, max);
  const reader = res.body?.getReader?.();
  if (!reader) {
    if (res.body === null || res.body === undefined) return Buffer.alloc(0);
    const b = Buffer.from(await res.arrayBuffer());
    if (b.length > max) throw refuse(`response larger than ${max} bytes`);
    return b;
  }
  const chunks = [];
  let total = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    total += value.byteLength;
    if (total > max) { try { await reader.cancel(); } catch { /* ignore */ } throw refuse(`response larger than ${max} bytes`); }
    chunks.push(value);
  }
  return Buffer.concat(chunks);
}

// Test doubles without a stream fall back to text()/json() (null here).
async function readCapped(res, max) {
  if (!res.body?.getReader) { checkLength(res, max); return null; }
  return (await readCappedBuffer(res, max)).toString('utf8');
}
```

```js
// Authenticated request with 429/Retry-After back-off (#7) and a one-time 401 token refresh (#6). `retryDelayMs`
// overrides the wait (tests pass 0). A retry-after above `maxWaitMs` returns the 429 at once, so a caller with a time
// budget (the sync adapter) hands the wait to its own scheduler instead of sleeping past it.
export async function boxRequest(session, url, { method = 'GET', body, headers, retryDelayMs, fetchImpl, maxWaitMs = Infinity } = {}) {
  let refreshed = false;
  for (let attempt = 0; ; attempt++) {
    const token = await session.ensure();
    const res = await boxFetch(url, { token, headers, fetchImpl, method, body });
    if (res.status === 429 && attempt < MAX_HTTP_RETRIES) {
      const ra = retryAfterMs(res);
      if (ra !== null && ra > maxWaitMs) return res;
      try { await res.body?.cancel?.(); } catch { /* ignore */ }
      await sleep(retryDelayMs ?? ra ?? 1000 * (attempt + 1));
      continue;
    }
    if (res.status === 401 && !refreshed) {
      refreshed = true;
      try { await res.body?.cancel?.(); } catch { /* ignore */ }
      await session.refresh();
      continue;
    }
    return res;
  }
}
const boxGet = (session, url, opts) => boxRequest(session, url, opts);
```

```js
        { code: 'BOX_AUTH_FAILED', status: res.status, boxError: typeof data.error === 'string' ? data.error : null });
    }
    return data;
  } finally {
    clearTimeout(timer);
  }
}

async function exchangeCCGToken(creds) {
  return { accessToken: (await postToken(buildTokenForm(creds))).access_token };
}

export function buildAuthCodeForm({ clientId, clientSecret, code, redirectUri, codeVerifier }) {

    redirect_uri: redirectUri, ...(codeVerifier ? { code_verifier: codeVerifier } : {}) }).toString();
}

export function buildRefreshForm({ clientId, clientSecret, refreshToken }) {
  return new URLSearchParams({ grant_type: 'refresh_token', refresh_token: refreshToken, client_id: clientId, client_secret: clientSecret }).toString();
```

```js
// (409 conflicts as Box sends them), multipart upload and upload-new-version, downloads through a dl.boxcloud.com
// redirect, trash and purge, versions (premium only) and user events. fetch(url, init) answers like Box. Without

    }

  }
  return fake;
```

```js
// SyncStore over Box (design 8.2, SP6). One dedicated folder (default "llmide-sync") under the account's All Files.
// Auth: the user's own Box OAuth app; the refresh token is single use, so every rotation goes to onRefreshToken (the
// vault) before its access token is used. HTTP: the Library connector's layer (connectors/box.mjs: pinned fetch, Box host
// allowlist, redirect re-validation with the bearer dropped off-origin, byte caps, 429 back-off, one 401 re-auth).
// Replace = upload a new version of the same file (atomic for readers), then delete the old versions (D8). Deletes purge
// the trash. Operations run one at a time per store. Only sealed envelopes are stored; secrets never reach an error.
import { randomBytes } from 'node:crypto';
import { checkPath, checkSize, MAX_FILE_BYTES } from './index.mjs';
import { API, UPLOAD_API, boxRequest, postToken, buildRefreshForm, readJson, readCappedBuffer } from '../box.mjs';
import { makePinnedFetch } from '../../server/pinned-fetch.mjs';

export const DEFAULT_BOX_FOLDER = 'llmide-sync';
export const BOX_APP_RE = /^[A-Za-z0-9]{16,128}$/;
const FOLDER_RE = /^[A-Za-z0-9_.-]{1,64}$/;
const MAX_WAIT_MS = 10_000; // longer Box retry-after: hand the wait to the scheduler's back-off
const PAGE = 1000;
const MESSAGES = {
  SYNC_AUTH_FAILED: 'Box refused the saved sign-in',
  SYNC_RATE_LIMITED: 'Box asked LLM-IDE to slow down',
  SYNC_QUOTA: 'The Box account is out of storage',
  SYNC_UNREACHABLE: 'Box not reachable',
  SYNC_TOO_LARGE: 'Sync file too large',
  SYNC_STALE: 'Box folder moved',
  SYNC_IO: 'Box operation failed',
};
const coded = (code) => Object.assign(new Error(MESSAGES[code] ?? MESSAGES.SYNC_IO), { code });
const isSync = (e) => String(e?.code ?? '').startsWith('SYNC_');

export function validateBoxConfig(c) {
  if (!c || typeof c.clientId !== 'string' || !BOX_APP_RE.test(c.clientId)) return 'clientId';
  if (typeof c.clientSecret !== 'string' || !BOX_APP_RE.test(c.clientSecret)) return 'clientSecret';
  if (typeof c.folder !== 'string' || !FOLDER_RE.test(c.folder) || c.folder === '.' || c.folder === '..') return 'folder';
  return null;
}

export function classifyBoxStatus(status, body = {}) {
  const code = String(body?.code ?? '');
  if (status === 401) return 'SYNC_AUTH_FAILED';
  if (status === 429) return 'SYNC_RATE_LIMITED';
  if (code === 'storage_limit_exceeded' || status === 507) return 'SYNC_QUOTA';
  if (code === 'file_size_limit_exceeded' || status === 413) return 'SYNC_TOO_LARGE';
  if (status >= 500) return 'SYNC_UNREACHABLE';
  return 'SYNC_IO';
}

const conflictId = (j) => { const c = j?.context_info?.conflicts; const id = Array.isArray(c) ? c[0]?.id : c?.id; return id ? String(id) : null; };

function oauthSession({ clientId, clientSecret, refreshToken }, { fetchImpl, onRefreshToken }) {
  let access = null;
  let refresh = refreshToken;
  let inflight = null;
  const renew = () => (inflight ??= (async () => {
    let data;
    try { data = await postToken(buildRefreshForm({ clientId, clientSecret, refreshToken: refresh }), { fetchImpl }); } catch (e) {
      if (e?.status === 429) throw coded('SYNC_RATE_LIMITED');
      throw coded(e?.code === 'BOX_AUTH_FAILED' && e.status >= 400 && e.status < 500 ? 'SYNC_AUTH_FAILED' : 'SYNC_UNREACHABLE');
    }
    if (typeof data.refresh_token !== 'string' || typeof data.access_token !== 'string') throw coded('SYNC_AUTH_FAILED');
    refresh = data.refresh_token;
    onRefreshToken(refresh); // single use: the vault holds the new one before its access token is used
    access = data.access_token;
    return access;
  })().finally(() => { inflight = null; }));
  return { ensure: async () => access ?? renew(), refresh: renew };
}

export function createBoxStore(config, secrets, { fetchImpl = makePinnedFetch(), retryDelayMs, onRefreshToken = () => {}, watchMs = 30_000 } = {}) {
  const folderName = config?.folder || DEFAULT_BOX_FOLDER;
  const session = oauthSession({ clientId: config?.clientId, clientSecret: secrets?.clientSecret, refreshToken: secrets?.refreshToken }, { fetchImpl, onRefreshToken });
  const folders = new Map(); // folder path below the sync folder ('' = the sync folder) -> Box folder id
  const watchers = new Set();
  let chain = Promise.resolve();
  const serial = (fn) => { const run = chain.then(fn); chain = run.catch(() => {}); return run; };

  async function call(url, opts = {}) {
    try { return await boxRequest(session, url, { ...opts, fetchImpl, retryDelayMs, maxWaitMs: MAX_WAIT_MS }); } catch (e) {
      if (isSync(e)) throw e;
      throw coded(e?.code === 'BOX_FETCH_REFUSED' ? 'SYNC_IO' : 'SYNC_UNREACHABLE');
    }
  }
  async function fail(res) { throw coded(classifyBoxStatus(res.status, await readJson(res).catch(() => ({})))); }
  /** Retry once with an empty folder cache when a cached folder id went stale (deleted or moved outside this store). */
  async function fresh(fn) {
    try { return await fn(); } catch (e) {
      if (e?.code !== 'SYNC_STALE') throw e;
      folders.clear();
      try { return await fn(); } catch (e2) { throw e2?.code === 'SYNC_STALE' ? coded('SYNC_IO') : e2; }
    }
  }
  async function children(id) {
    const out = [];
    for (let offset = 0; ; offset += PAGE) {
      const res = await call(`${API}/folders/${encodeURIComponent(id)}/items?fields=id,name,type,size,modified_at&limit=${PAGE}&offset=${offset}`);
      if (res.status === 404) throw coded('SYNC_STALE');
      if (!res.ok) await fail(res);
      const entries = (await readJson(res)).entries;
      const page = Array.isArray(entries) ? entries : [];
      out.push(...page);
      if (page.length < PAGE) return out;
    }
  }
  async function mkdir(parentId, name) {
    const res = await call(`${API}/folders`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name, parent: { id: parentId } }) });
    const j = await readJson(res);
    if (res.ok && j.id) return String(j.id);
    if (res.status === 409 && conflictId(j)) return conflictId(j); // a concurrent create won: use it
    if (res.status === 404) throw coded('SYNC_STALE');
    throw coded(classifyBoxStatus(res.status, j));
  }
  /** The id of the folder at `segs` below the sync folder; null when absent and `create` is false. */
  async function folderId(segs, create) {
    let id = folders.get('');
    if (!id) {
      id = (await children('0')).find((e) => e.type === 'folder' && e.name === folderName)?.id ?? (create ? await mkdir('0', folderName) : null);
      if (!id) return null;
      id = String(id); folders.set('', id);
    }
    let key = '';
    for (const name of segs) {
      key = key ? `${key}/${name}` : name;
      let next = folders.get(key);
      if (!next) {
        next = (await children(id)).find((e) => e.type === 'folder' && e.name === name)?.id ?? (create ? await mkdir(id, name) : null);
        if (!next) return null;
        next = String(next); folders.set(key, next);
      }
      id = next;
    }
    return id;
  }
  async function fileIn(dirId, name) { return (await children(dirId)).find((e) => e.type === 'file' && e.name === name) ?? null; }
  function multipart(attributes, data) {
    const boundary = `llmide${randomBytes(12).toString('hex')}`;
    const head = `--${boundary}\r\nContent-Disposition: form-data; name="attributes"\r\n\r\n${JSON.stringify(attributes)}\r\n`
      + `--${boundary}\r\nContent-Disposition: form-data; name="file"; filename="blob"\r\nContent-Type: application/octet-stream\r\n\r\n`;
    return { body: Buffer.concat([Buffer.from(head), data, Buffer.from(`\r\n--${boundary}--\r\n`)]), type: `multipart/form-data; boundary=${boundary}` };
  }
  async function upload(url, attributes, data) {
    const { body, type } = multipart(attributes, data);
    return call(url, { method: 'POST', headers: { 'Content-Type': type }, body });
  }
  async function purgeOldVersions(fileId) {
    const res = await call(`${API}/files/${encodeURIComponent(fileId)}/versions?fields=id&limit=1000`);
    if (res.status === 403 || res.status === 404) return; // free plans keep no versions
    if (!res.ok) await fail(res);
    for (const v of (await readJson(res)).entries ?? []) {
      const d = await call(`${API}/files/${encodeURIComponent(fileId)}/versions/${encodeURIComponent(v.id)}`, { method: 'DELETE' });
      if (!d.ok && d.status !== 404) await fail(d);
    }
  }
  async function purge(kind, id) {
    const del = await call(`${API}/${kind}/${encodeURIComponent(id)}${kind === 'folders' ? '?recursive=true' : ''}`, { method: 'DELETE' });
    if (!del.ok && del.status !== 404) await fail(del);
    const tr = await call(`${API}/${kind}/${encodeURIComponent(id)}/trash`, { method: 'DELETE' });
    if (!tr.ok && tr.status !== 404) await fail(tr);
  }

  return {
    async put(path, bytes) {
      const segs = checkPath(path); checkSize(bytes);
      const data = Buffer.from(bytes);
      const name = segs.at(-1);
      await serial(() => fresh(async () => {
        const dir = await folderId(segs.slice(0, -1), true);
        const res = await upload(`${UPLOAD_API}/files/content`, { name, parent: { id: dir } }, data);
        if (res.ok) return;
        if (res.status === 404) throw coded('SYNC_STALE');
        if (res.status !== 409) await fail(res);
        const id = conflictId(await readJson(res));
        if (!id) throw coded('SYNC_IO');
        const again = await upload(`${UPLOAD_API}/files/${encodeURIComponent(id)}/content`, { name }, data); // readers see old or new bytes
        if (!again.ok) await fail(again);
        await purgeOldVersions(id);
      }));
    },
    async get(path) {
      const segs = checkPath(path);
      return serial(() => fresh(async () => {
        const dir = await folderId(segs.slice(0, -1), false);
        const f = dir && await fileIn(dir, segs.at(-1));
        if (!f) return null;
        if ((f.size ?? 0) > MAX_FILE_BYTES) throw coded('SYNC_TOO_LARGE');
        const res = await call(`${API}/files/${encodeURIComponent(f.id)}/content`);
        if (res.status === 404) return null;
        if (!res.ok) await fail(res);
        try { return await readCappedBuffer(res, MAX_FILE_BYTES); } catch { throw coded('SYNC_TOO_LARGE'); }
      }));
    },
    async list(dir) {
      const segs = checkPath(dir);
      return serial(() => fresh(async () => {
        const id = await folderId(segs, false);
        if (!id) return [];
        return (await children(id)).filter((e) => e.type === 'file')
          .map((e) => ({ name: e.name, size: e.size ?? 0, mtimeMs: Date.parse(e.modified_at ?? '') || 0 }));
      }));
    },
    async remove(path) {
      const segs = checkPath(path);
      await serial(() => fresh(async () => {
        const dir = await folderId(segs.slice(0, -1), false);
        const f = dir && await fileIn(dir, segs.at(-1));
        if (f) await purge('files', f.id);
      }));
    },
    async removeTree(dir) {
      const segs = checkPath(dir);
      const key = segs.join('/');
      await serial(() => fresh(async () => {
        const id = await folderId(segs, false);
        if (id) await purge('folders', id);
        for (const k of [...folders.keys()]) if (k === key || k.startsWith(`${key}/`)) folders.delete(k);
      }));
    },
    // shortcut: polls GET /events every watchMs instead of Box's long-poll realtime server; switch to long-poll if the
    // scheduler starts using watch (today it polls the store itself and never calls this).
    watch(dir, onChange) {
      const segs = checkPath(dir);
      const w = { stopped: false, timer: null };
      watchers.add(w);
      let pos = 'now';
      const tick = async () => {
        try {
          const id = await serial(() => folderId(segs, false));
          const res = await call(`${API}/events?stream_type=changes&stream_position=${encodeURIComponent(pos)}&limit=100`);
          if (res.ok) {
            const j = await readJson(res);
            if (pos !== 'now' && id && (j.entries ?? []).some((e) => String(e?.source?.parent?.id ?? '') === id)) { try { onChange(); } catch { /* a watcher's bug never breaks sync */ } }
            if (j.next_stream_position != null) pos = String(j.next_stream_position);
          }
        } catch { /* the caller still polls */ }
        if (!w.stopped) { w.timer = setTimeout(() => { void tick(); }, watchMs); w.timer.unref?.(); }
      };
      void tick();
      return () => { w.stopped = true; clearTimeout(w.timer); watchers.delete(w); };
    },
    describe() { return { kind: 'box', root: folderName, account: config?.account ?? '' }; },
    async close() { for (const w of watchers) { w.stopped = true; clearTimeout(w.timer); } watchers.clear(); },
  };
}
```

```js
    const password = getSecret(db, userId, 'sync.megaPassword');

    // shortcut: a store recreated while the old one's refresh is in flight reads the older token and fails once
    // (SYNC_AUTH_FAILED turns sync off, Settings says reconnect); serialize store creation per user if it shows up.
    if (clientSecret && refreshToken) {
      store = createBoxStore(state.storeConfig, { clientSecret, refreshToken }, { onRefreshToken: (t) => setSecret(getDb(), userId, 'sync.boxRefreshToken', t) });
    }
  }
  if (!store) return null;
  const wrapped = withTimeouts(store);
  stores.set(userId, wrapped);
  return wrapped;
}
```

```js
// Box one-time consent for the sync store (design 8.2, SP6 D1). The desktop opens Box's authorize page in the system
// browser; Box redirects to the core's loopback callback; the core trades the code (client secret + PKCE verifier) for
// tokens. Pending connects are in memory only, 10 minutes, one per user. The client secret waits here and reaches the
// vault only through `commit`, after Box accepted it, so an abandoned attempt leaves nothing behind. The page text never
// echoes Box's error text.
import { randomBytes, createHash } from 'node:crypto';
import { AUTHORIZE_URL, API, boxRequest, postToken, buildAuthCodeForm, readJson } from '../../connectors/box.mjs';
import { maskEmail } from '../../connectors/sync-store/index.mjs';

export const BOX_CONNECT_TTL_MS = 10 * 60_000;
const pending = new Map(); // state -> { userId, clientId, clientSecret, folder, verifier, createdAt, phase, code }
const latest = new Map();  // userId -> state

export const boxRedirectUri = (port) => `http://127.0.0.1:${port}/kb/sync/box/callback`;
export function _resetBoxConnectsForTest() { pending.clear(); latest.clear(); }

function sweep(now) {
  for (const [s, p] of pending) {
    if (now - p.createdAt <= BOX_CONNECT_TTL_MS) continue;
    pending.delete(s);
    if (latest.get(p.userId) === s) latest.delete(p.userId);
  }
}

export function startBoxConnect(userId, { clientId, clientSecret, folder }, { port, now = Date.now() }) {
  sweep(now);
  const old = latest.get(userId);
  if (old) pending.delete(old);
  const state = randomBytes(16).toString('base64url');
  const verifier = randomBytes(32).toString('base64url');
  pending.set(state, { userId, clientId, clientSecret, folder, verifier, createdAt: now, phase: 'waiting', code: null });
  latest.set(userId, state);
  const q = new URLSearchParams({ response_type: 'code', client_id: clientId, redirect_uri: boxRedirectUri(port), state,
    code_challenge: createHash('sha256').update(verifier).digest('base64url'), code_challenge_method: 'S256' });
  return { authorizeUrl: `${AUTHORIZE_URL}?${q}` };
}

/** A final phase is reported once, then 'none'. */
export function pollBoxConnect(userId, now = Date.now()) {
  sweep(now);
  const state = latest.get(userId);
  const p = state && pending.get(state);
  if (!p) return { phase: 'none', code: null };
  if (p.phase !== 'waiting') { pending.delete(state); latest.delete(userId); }
  return { phase: p.phase, code: p.code };
}

export async function finishBoxConnect(query, { port, fetchImpl, commit, now = Date.now() }) {
  sweep(now);
  const p = pending.get(query.get('state') ?? '');
  if (!p) return 'This Box sign-in link has expired. Start again from LLM-IDE Settings.';
  if (p.phase !== 'waiting') return 'This Box sign-in link was already used. Start again from LLM-IDE Settings.';
  const end = (phase, code, text) => { p.phase = phase; p.code = code; p.clientSecret = ''; p.verifier = ''; return text; };
  if (query.get('error')) return end('failed', 'cancelled', 'Box sign-in was cancelled. You can close this tab.');
  try {
    const tok = await postToken(buildAuthCodeForm({ clientId: p.clientId, clientSecret: p.clientSecret, code: query.get('code') ?? '',
      redirectUri: boxRedirectUri(port), codeVerifier: p.verifier }), { fetchImpl });
    if (typeof tok.refresh_token !== 'string') return end('failed', 'SYNC_AUTH_FAILED', 'Box sign-in failed. Return to LLM-IDE for details.');
    const once = { ensure: async () => tok.access_token, refresh: async () => { throw Object.assign(new Error('Box refused the new token'), { code: 'SYNC_AUTH_FAILED' }); } };
    const me = await boxRequest(once, `${API}/users/me?fields=login`, { fetchImpl });
    const login = me.ok ? String((await readJson(me)).login ?? '') : '';
    await commit(p.userId, { clientId: p.clientId, clientSecret: p.clientSecret, refreshToken: tok.refresh_token, folder: p.folder, account: maskEmail(login) });
    return end('done', null, 'Box is connected to LLM-IDE sync. You can close this tab.');
  } catch (e) {
    const code = e?.boxError === 'invalid_client' ? 'SYNC_BAD_CLIENT'
      : String(e?.code ?? '').startsWith('SYNC_') ? e.code
        : e?.code === 'BOX_AUTH_FAILED' ? 'SYNC_AUTH_FAILED' : 'SYNC_UNREACHABLE';
    return end('failed', code, 'Box sign-in failed. Return to LLM-IDE for details.');
  }
}
```

```ts
export type StoreKind = "mega" | "box" | "sftp";
export const STORE_CHOICES: ReadonlyArray<{ kind: StoreKind; label: string; built: boolean }> = [
  { kind: "mega", label: "MEGA", built: true },
  { kind: "box", label: "Box", built: true },
  { kind: "sftp", label: "Own server", built: false }, // SP5
];
/** Box matches loopback redirect URIs on any port, so this one entry covers whatever port the core runs on. */
export const BOX_DESKTOP_REDIRECT = "http://127.0.0.1/kb/sync/box/callback";
export interface BoxSetup { clientId: string; clientSecret: string; folder: string }
export interface BoxConnectStart { authorizeUrl: string }
export interface BoxConnectPoll { phase: "none" | "waiting" | "done" | "failed"; code: string | null }
const BOX_PHASES = new Set(["none", "waiting", "done", "failed"]);

export function decodeBoxStart(v: unknown): BoxConnectStart {
  if (isRecord(v) && typeof v.authorizeUrl === "string" && v.authorizeUrl.startsWith("https://account.box.com/api/oauth2/authorize?")) return { authorizeUrl: v.authorizeUrl };
  throw new ApiError(0, "BAD_RESPONSE");
}
export function decodeBoxPoll(v: unknown): BoxConnectPoll {
  if (isRecord(v) && typeof v.phase === "string" && BOX_PHASES.has(v.phase) && strOrNull(v.code)) return { phase: v.phase as BoxConnectPoll["phase"], code: v.code as string | null };
  throw new ApiError(0, "BAD_RESPONSE");
}
export const startBoxConnect = async (client: CoreClient, cfg: BoxSetup) => decodeBoxStart(await call(client, "POST", "/kb/sync/box/start", cfg));
export const pollBoxConnect = async (client: CoreClient) => decodeBoxPoll(await call(client, "POST", "/kb/sync/box/poll", {}));

/** Poll one at a time until the browser round trip ends. 10 minutes is the core's pending-consent lifetime. */
export async function waitBoxConnect(client: CoreClient, { intervalMs = 2000, timeoutMs = 600_000, sleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms)), now = () => Date.now() }:
  { intervalMs?: number; timeoutMs?: number; sleep?: (ms: number) => Promise<void>; now?: () => number } = {}): Promise<{ phase: "done" | "failed" | "timeout"; code: string | null }> {
  const until = now() + timeoutMs;
  for (;;) {
    const p = await pollBoxConnect(client);
    if (p.phase === "done" || p.phase === "failed") return { phase: p.phase, code: p.code };
    if (p.phase === "none" || now() >= until) return { phase: "timeout", code: null };
    await sleep(intervalMs);
  }
}
```

```ts
// The browser's view of the Box sync folder (design 8.2, SP6; the desktop side is extension/connectors/sync-store/box.mjs).
// Sign-in: Box OAuth 2.0 with the user's OWN Box app, whose client id and secret came in the pairing link (Box documents
// no public-client flow, SP6 D2). A popup carries the consent. The tokens live in this page's memory only and the refresh
// token is revoked on close (per app session, D4). PKCE is sent too (undocumented by Box: accepted or ignored). Writes
// create only new, uniquely named files and never replace or delete anything (one writer per file, design 3).
import { b64u } from "../relay/wire.ts";
import { checkPath, MAX_FILE_BYTES, SyncStoreError, type OpenedStore } from "./mega-store.ts";

const API = "https://api.box.com/2.0";
const UPLOAD = "https://upload.box.com/api/2.0";
const TOKEN = "https://api.box.com/oauth2/token";
const REVOKE = "https://api.box.com/oauth2/revoke";
const AUTHORIZE = "https://account.box.com/api/oauth2/authorize";
const APP_RE = /^[A-Za-z0-9]{16,128}$/;
const SEGMENT = /^[A-Za-z0-9_.-]{1,64}$/;
const CHANNEL = "llmide-box-auth";
export interface Authorize { run(url: string): Promise<URLSearchParams>; close(): void }
interface Entry { type: string; id: string; name: string; size?: number }
type Fetch = (url: string, init?: RequestInit) => Promise<Response>;

export const callbackUrl = (origin: string) => `${origin}/box-callback.html`;
const rand = (n: number) => b64u(globalThis.crypto.getRandomValues(new Uint8Array(n)));

/** Opens the popup NOW (call it inside the click, or the browser blocks it) and points it at Box once the URL is ready.
 *  box-callback.html posts the redirect's query on a same-origin BroadcastChannel and closes itself. */
export function popupAuthorize(): Authorize {
  const popup = (globalThis as { open?: (u: string, n: string, f: string) => Window | null }).open?.("", "llmide-box-auth", "popup,width=520,height=720") ?? null;
  return {
    run: (url) => new Promise((resolve, reject) => {
      if (!popup) { reject(new SyncStoreError("SYNC_POPUP_BLOCKED")); return; }
      const ch = new BroadcastChannel(CHANNEL);
      let closedTicks = 0;
      const stop = () => { clearInterval(timer); ch.close(); };
      const timer = setInterval(() => { if (popup.closed && ++closedTicks > 1) { stop(); reject(new SyncStoreError("SYNC_AUTH_CANCELLED")); } }, 1000);
      ch.onmessage = (ev) => { if (typeof ev.data === "string") { stop(); resolve(new URLSearchParams(ev.data)); } };
      popup.location.href = url;
    }),
    close: () => { try { if (popup && !popup.closed) popup.close(); } catch { /* cross-origin or gone */ } },
  };
}

function multipart(attributes: object, data: Uint8Array): { body: Uint8Array; type: string } {
  const boundary = `llmide${rand(12).replace(/[-_]/g, "x")}`;
  const te = new TextEncoder();
  const head = te.encode(`--${boundary}\r\nContent-Disposition: form-data; name="attributes"\r\n\r\n${JSON.stringify(attributes)}\r\n`
    + `--${boundary}\r\nContent-Disposition: form-data; name="file"; filename="blob"\r\nContent-Type: application/octet-stream\r\n\r\n`);
  const tail = te.encode(`\r\n--${boundary}--\r\n`);
  const body = new Uint8Array(head.length + data.length + tail.length);
  body.set(head); body.set(data, head.length); body.set(tail, head.length + data.length);
  return { body, type: `multipart/form-data; boundary=${boundary}` };
}

export async function openBoxStore({ clientId, clientSecret, folder }: { clientId: string; clientSecret: string; folder: string },
  { fetch: f = globalThis.fetch.bind(globalThis) as Fetch, authorize = popupAuthorize(), origin = globalThis.location?.origin ?? "" }:
  { fetch?: Fetch; authorize?: Authorize; origin?: string } = {}): Promise<OpenedStore> {
  if (!APP_RE.test(clientId) || !APP_RE.test(clientSecret)) { authorize.close(); throw new SyncStoreError("SYNC_BAD_CLIENT"); }
  if (!SEGMENT.test(folder) || folder === "." || folder === "..") { authorize.close(); throw new SyncStoreError("SYNC_BAD_PATH"); }

  async function token(form: Record<string, string>): Promise<{ access: string; refresh: string }> {
    let r: Response;
    try {
      r = await f(TOKEN, { method: "POST", headers: { "Content-Type": "application/x-www-form-urlencoded" },
        body: new URLSearchParams({ ...form, client_id: clientId, client_secret: clientSecret }).toString() });
    } catch { throw new SyncStoreError("SYNC_UNREACHABLE"); }
    const j = await r.json().catch(() => ({})) as Record<string, unknown>;
    if (r.status === 429) throw new SyncStoreError("SYNC_RATE_LIMITED");
    if (!r.ok || typeof j.access_token !== "string" || typeof j.refresh_token !== "string") throw new SyncStoreError(j.error === "invalid_client" ? "SYNC_BAD_CLIENT" : "SYNC_AUTH_FAILED");
    return { access: j.access_token, refresh: j.refresh_token };
  }

  const verifier = rand(32);
  const challenge = b64u(new Uint8Array(await globalThis.crypto.subtle.digest("SHA-256", new TextEncoder().encode(verifier))));
  const state = `w.${rand(16)}`;
  const redirect = callbackUrl(origin);
  const q = new URLSearchParams({ response_type: "code", client_id: clientId, redirect_uri: redirect, state, code_challenge: challenge, code_challenge_method: "S256" });
  let back: URLSearchParams;
  try { back = await authorize.run(`${AUTHORIZE}?${q}`); } finally { authorize.close(); }
  if (back.get("state") !== state) throw new SyncStoreError("SYNC_AUTH_FAILED");
  if (back.get("error")) throw new SyncStoreError("SYNC_AUTH_CANCELLED");
  let tokens: { access: string; refresh: string } | null = await token({ grant_type: "authorization_code", code: back.get("code") ?? "", redirect_uri: redirect, code_verifier: verifier });

  async function api(url: string, init: RequestInit = {}): Promise<Response> {
    for (let again = true; ; again = false) {
      if (!tokens) throw new SyncStoreError("SYNC_SESSION_EXPIRED");
      let r: Response;
      try { r = await f(url, { ...init, headers: { ...((init.headers as Record<string, string>) ?? {}), Authorization: `Bearer ${tokens.access}` } }); }
      catch { throw new SyncStoreError("SYNC_UNREACHABLE"); }
      if (r.status === 401 && again) { tokens = await token({ grant_type: "refresh_token", refresh_token: tokens.refresh }); continue; }
      if (r.status === 401) throw new SyncStoreError("SYNC_SESSION_EXPIRED");
      if (r.status === 429) throw new SyncStoreError("SYNC_RATE_LIMITED");
      return r;
    }
  }
  const ids = new Map<string, string>(); // folder path below the sync folder ("" = the sync folder) -> Box id
  async function items(id: string): Promise<Entry[] | null> {
    const out: Entry[] = [];
    for (let offset = 0; ; offset += 1000) {
      const r = await api(`${API}/folders/${encodeURIComponent(id)}/items?fields=id,name,type,size&limit=1000&offset=${offset}`);
      if (r.status === 404) return null;
      if (!r.ok) throw new SyncStoreError("SYNC_IO");
      const e = ((await r.json()) as { entries?: Entry[] }).entries ?? [];
      out.push(...e);
      if (e.length < 1000) return out;
    }
  }
  async function mkdir(parent: string, name: string): Promise<string> {
    const r = await api(`${API}/folders`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ name, parent: { id: parent } }) });
    const j = await r.json().catch(() => ({})) as { id?: string; context_info?: { conflicts?: { id?: string } | Array<{ id?: string }> } };
    if (r.ok && j.id) return String(j.id);
    const c = j.context_info?.conflicts;
    const id = Array.isArray(c) ? c[0]?.id : c?.id;
    if (r.status === 409 && id) return String(id);
    throw new SyncStoreError("SYNC_IO");
  }
  /** Folders below the sync folder; segments at index >= mkdirFrom may be created, the rest must exist. */
  async function walk(segs: string[], mkdirFrom: number): Promise<string | null> {
    let id = ids.get("");
    if (!id) {
      const f = (await items("0"))?.find((e) => e.type === "folder" && e.name === folder);
      if (!f) return null; // the desktop creates the sync folder; a device never does
      id = String(f.id); ids.set("", id);
    }
    let key = "";
    for (let i = 0; i < segs.length; i++) {
      key = key ? `${key}/${segs[i]}` : segs[i];
      let next = ids.get(key);
      if (!next) {
        const kids = await items(id);
        if (!kids) { ids.clear(); return null; }
        const f = kids.find((e) => e.type === "folder" && e.name === segs[i]);
        if (f) next = String(f.id);
        else if (i >= mkdirFrom) next = await mkdir(id, segs[i]);
        else return null;
        ids.set(key, next);
      }
      id = next;
    }
    return id;
  }

  return {
    get: async (path) => {
      const segs = checkPath(path);
      const dir = await walk(segs.slice(0, -1), Infinity);
      if (!dir) return null;
      const kids = await items(dir);
      if (!kids) { ids.clear(); return null; }
      const file = kids.find((e) => e.type === "file" && e.name === segs[segs.length - 1]);
      if (!file) return null;
      if ((file.size ?? 0) > MAX_FILE_BYTES) throw new SyncStoreError("SYNC_TOO_LARGE");
      const r = await api(`${API}/files/${encodeURIComponent(file.id)}/content`); // the browser follows Box's redirect and drops the bearer cross-origin
      if (r.status === 404) return null;
      if (!r.ok) throw new SyncStoreError("SYNC_IO");
      const bytes = new Uint8Array(await r.arrayBuffer());
      if (bytes.length > MAX_FILE_BYTES) throw new SyncStoreError("SYNC_TOO_LARGE");
      return bytes;
    },
    put: async (path, bytes, mkdirFrom = Infinity) => {
      const segs = checkPath(path);
      if (bytes.length > MAX_FILE_BYTES) throw new SyncStoreError("SYNC_TOO_LARGE");
      const dir = await walk(segs.slice(0, -1), mkdirFrom);
      if (!dir) throw new SyncStoreError("SYNC_MISSING");
      const { body, type } = multipart({ name: segs[segs.length - 1], parent: { id: dir } }, bytes);
      const r = await api(`${UPLOAD}/files/content`, { method: "POST", headers: { "Content-Type": type }, body });
      if (r.ok || r.status === 409) return; // 409: names are unique per write, so this is a retry of a write that landed
      if (r.status === 404) { ids.clear(); throw new SyncStoreError("SYNC_MISSING"); }
      const j = await r.json().catch(() => ({})) as { code?: string };
      throw new SyncStoreError(j.code === "storage_limit_exceeded" ? "SYNC_QUOTA" : "SYNC_IO");
    },
    async close() {
      const t = tokens; tokens = null;
      if (t) await f(REVOKE, { method: "POST", headers: { "Content-Type": "application/x-www-form-urlencoded" },
        body: new URLSearchParams({ client_id: clientId, client_secret: clientSecret, token: t.refresh }).toString() }).catch(() => undefined);
    },
  };
}
```

```swift
import Foundation

/// A minimal Box API client for the sync folder (design §8.2, SP6; no SDK). The user's OWN Box app (client id + secret
/// from the pairing QR, SP6 D2). Box refresh tokens are single use, so every rotation is reported through `onTokens`
/// before the new access token is used (the app saves it in the Keychain). HTTPS only; creates only new files; never
/// deletes. PKCE is sent on authorize and exchange (undocumented by Box: accepted or ignored).
@MainActor
public final class BoxClient: SyncRemoteStore {
    public struct App: Codable, Equatable, Sendable {
        public var clientId: String; public var clientSecret: String
        public init(clientId: String, clientSecret: String) { self.clientId = clientId; self.clientSecret = clientSecret }
    }
    public struct Tokens: Codable, Equatable, Sendable {
        public var access: String; public var refresh: String
        public init(access: String, refresh: String) { self.access = access; self.refresh = refresh }
    }
    public enum Failure: Error, Equatable, Sendable { case authFailed, badClient, rateLimited, quota, tooLarge, missing, badResponse, http(Int) }
    public typealias Transport = (URLRequest) async throws -> (Data, HTTPURLResponse)

    public static let redirectURI = "llmide-box://oauth"
    static let api = "https://api.box.com/2.0"
    static let uploadURL = URL(string: "https://upload.box.com/api/2.0/files/content")!
    static let tokenURL = URL(string: "https://api.box.com/oauth2/token")!
    static let revokeURL = URL(string: "https://api.box.com/oauth2/revoke")!
    static let authorizeBase = URL(string: "https://account.box.com/api/oauth2/authorize")!

    /// URLSession follows Box's download redirect itself; this keeps it on https and drops the bearer off the API host.
    nonisolated static func redirected(_ req: URLRequest, from original: URLRequest?) -> URLRequest? {
        guard req.url?.scheme == "https" else { return nil }
        var next = req
        if req.url?.host != original?.url?.host { next.setValue(nil, forHTTPHeaderField: "Authorization") }
        return next
    }
    final class RedirectGuard: NSObject, URLSessionTaskDelegate {
        func urlSession(_ session: URLSession, task: URLSessionTask, willPerformHTTPRedirection response: HTTPURLResponse,
                        newRequest request: URLRequest) async -> URLRequest? {
            BoxClient.redirected(request, from: task.originalRequest)
        }
    }
    private static let urlSession = URLSession(configuration: .ephemeral)
    private static let redirectGuard = RedirectGuard()
    public static let urlSessionTransport: Transport = { request in
        let (data, response) = try await urlSession.data(for: request, delegate: redirectGuard)
        guard let http = response as? HTTPURLResponse else { throw Failure.badResponse }
        return (data, http)
    }

    public let folder: String
    public let app: App
    public private(set) var tokens: Tokens
    public var onTokens: ((Tokens) -> Void)?
    private let transport: Transport
    private var ids: [String: String] = [:]  // folder path below the sync folder ("" = the sync folder) -> Box id

    public init(folder: String, app: App, tokens: Tokens, transport: @escaping Transport = BoxClient.urlSessionTransport) {
        self.folder = folder; self.app = app; self.tokens = tokens; self.transport = transport
    }

    public static func pkce() -> (verifier: String, challenge: String) {
        let v = SyncB64.encode(SyncCrypto.randomBytes(32))
        return (v, SyncB64.encode(SyncCrypto.sha256(Data(v.utf8))))
    }
    public static func authorizeURL(app: App, state: String, challenge: String, redirectURI: String = BoxClient.redirectURI) -> URL {
        var c = URLComponents(url: authorizeBase, resolvingAgainstBaseURL: false)!
        c.percentEncodedQuery = String(decoding: form([("response_type", "code"), ("client_id", app.clientId), ("redirect_uri", redirectURI),
                                                        ("state", state), ("code_challenge", challenge), ("code_challenge_method", "S256")]), as: UTF8.self)
        return c.url!
    }
    static func form(_ items: [(String, String)]) -> Data {
        let ok = CharacterSet(charactersIn: "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~")
        return Data(items.map { "\($0.0)=\($0.1.addingPercentEncoding(withAllowedCharacters: ok) ?? "")" }.joined(separator: "&").utf8)
    }
    static func token(_ items: [(String, String)], app: App, transport: Transport) async throws -> Tokens {
        var req = URLRequest(url: tokenURL); req.httpMethod = "POST"
        req.setValue("application/x-www-form-urlencoded", forHTTPHeaderField: "Content-Type")
        req.httpBody = form(items + [("client_id", app.clientId), ("client_secret", app.clientSecret)])
        let (data, resp) = try await transport(req)
        if resp.statusCode == 429 { throw Failure.rateLimited }
        let j = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any] ?? [:]
        guard resp.statusCode == 200, let a = j["access_token"] as? String, let r = j["refresh_token"] as? String else {
            throw (j["error"] as? String) == "invalid_client" ? Failure.badClient : Failure.authFailed
        }
        return Tokens(access: a, refresh: r)
    }
    public static func exchange(code: String, verifier: String, app: App, redirectURI: String = BoxClient.redirectURI,
                                transport: @escaping Transport = BoxClient.urlSessionTransport) async throws -> Tokens {
        try await token([("grant_type", "authorization_code"), ("code", code), ("redirect_uri", redirectURI), ("code_verifier", verifier)], app: app, transport: transport)
    }

    private func send(_ build: () -> URLRequest) async throws -> (Data, HTTPURLResponse) {
        var refreshed = false
        while true {
            var req = build()
            req.setValue("Bearer \(tokens.access)", forHTTPHeaderField: "Authorization")
            let (data, resp) = try await transport(req)
            if resp.statusCode == 401, !refreshed {
                refreshed = true
                tokens = try await Self.token([("grant_type", "refresh_token"), ("refresh_token", tokens.refresh)], app: app, transport: transport)
                onTokens?(tokens)  // single use: saved before the new access token is used
                continue
            }
            if resp.statusCode == 401 { throw Failure.authFailed }
            if resp.statusCode == 429 { throw Failure.rateLimited }
            return (data, resp)
        }
    }
    private func items(_ id: String) async throws -> [[String: Any]]? {
        let (data, resp) = try await send { URLRequest(url: URL(string: "\(Self.api)/folders/\(id)/items?fields=id,name,type,size&limit=1000")!) }
        if resp.statusCode == 404 { return nil }
        guard resp.statusCode == 200, let j = try? JSONSerialization.jsonObject(with: data) as? [String: Any] else { throw Failure.http(resp.statusCode) }
        return j["entries"] as? [[String: Any]] ?? []
    }
    private func mkdir(_ parent: String, _ name: String) async throws -> String {
        let (data, resp) = try await send {
            var r = URLRequest(url: URL(string: "\(Self.api)/folders")!); r.httpMethod = "POST"
            r.setValue("application/json", forHTTPHeaderField: "Content-Type")
            r.httpBody = try? JSONSerialization.data(withJSONObject: ["name": name, "parent": ["id": parent]])
            return r

        if (200...201).contains(resp.statusCode), let id = j["id"] as? String { return id }
        let c = (j["context_info"] as? [String: Any])?["conflicts"]
        if resp.statusCode == 409, let id = ((c as? [[String: Any]])?.first?["id"] ?? (c as? [String: Any])?["id"]) as? String { return id }
        throw Failure.http(resp.statusCode)
    }
    /// Folders below the sync folder; segments at index >= createFrom may be created, the rest must exist.
    private func walk(_ segs: [String], createFrom: Int) async throws -> String? {
        var id = ids[""]
        if id == nil {
            guard let f = try await items("0")?.first(where: { $0["type"] as? String == "folder" && $0["name"] as? String == folder }),
                  let fid = f["id"] as? String else { return nil }  // the desktop creates the sync folder; a device never does
            id = fid; ids[""] = fid
        }
        var key = ""
        for (i, name) in segs.enumerated() {
            key = key.isEmpty ? name : "\(key)/\(name)"
            if let known = ids[key] { id = known; continue }
            guard let kids = try await items(id!) else { ids.removeAll(); return nil }
            let next: String
            if let f = kids.first(where: { $0["type"] as? String == "folder" && $0["name"] as? String == name }), let fid = f["id"] as? String { next = fid }
            else if i >= createFrom { next = try await mkdir(id!, name) }
            else { return nil }
            ids[key] = next; id = next
        }
        return id
    }

    public func get(_ path: String) async throws -> Data? {
        let segs = try SyncPath.check(path)
        guard let dir = try await walk(Array(segs.dropLast()), createFrom: .max), let kids = try await items(dir) else { return nil }
        guard let f = kids.first(where: { $0["type"] as? String == "file" && $0["name"] as? String == segs.last }), let fid = f["id"] as? String else { return nil }
        if (f["size"] as? Int ?? 0) > SyncPath.maxFileBytes { throw Failure.tooLarge }
        let (data, resp) = try await send { URLRequest(url: URL(string: "\(Self.api)/files/\(fid)/content")!) }
        if resp.statusCode == 404 { return nil }
        guard resp.statusCode == 200 else { throw Failure.http(resp.statusCode) }
        guard data.count <= SyncPath.maxFileBytes else { throw Failure.tooLarge }
        return data
    }

    public func put(_ path: String, _ bytes: Data, createFolders: Int) async throws {
        let segs = try SyncPath.check(path)
        guard bytes.count <= SyncPath.maxFileBytes else { throw Failure.tooLarge }
        guard let dir = try await walk(Array(segs.dropLast()), createFrom: createFolders) else { throw Failure.missing }
        let boundary = "llmide\(SyncB64.encode(SyncCrypto.randomBytes(12)).replacingOccurrences(of: "-", with: "x").replacingOccurrences(of: "_", with: "x"))"
        let attrs = String(decoding: try JSONSerialization.data(withJSONObject: ["name": segs.last!, "parent": ["id": dir]]), as: UTF8.self)
        var body = Data("--\(boundary)\r\nContent-Disposition: form-data; name=\"attributes\"\r\n\r\n\(attrs)\r\n--\(boundary)\r\nContent-Disposition: form-data; name=\"file\"; filename=\"blob\"\r\nContent-Type: application/octet-stream\r\n\r\n".utf8)
        body.append(bytes); body.append(Data("\r\n--\(boundary)--\r\n".utf8))
        let (data, resp) = try await send {
            var r = URLRequest(url: Self.uploadURL); r.httpMethod = "POST"
            r.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type"); r.httpBody = body
            return r
        }
        if (200...201).contains(resp.statusCode) || resp.statusCode == 409 { return }  // 409: a retry of a write that landed
        if resp.statusCode == 404 { ids.removeAll(); throw Failure.missing }
        let code = ((try? JSONSerialization.jsonObject(with: data)) as? [String: Any])?["code"] as? String
        throw code == "storage_limit_exceeded" ? Failure.quota : Failure.http(resp.statusCode)
    }

        req.setValue("application/x-www-form-urlencoded", forHTTPHeaderField: "Content-Type")
        req.httpBody = Self.form([("client_id", app.clientId), ("client_secret", app.clientSecret), ("token", tokens.refresh)])
        _ = try? await transport(req)
    }
```

```swift
import AuthenticationServices
import UIKit
import SharedProtocol

/// Box consent for the sync store (SP6): ASWebAuthenticationSession on Box's authorize page with PKCE and a random state;
/// the redirect to llmide-box://oauth is caught by the session (no URL scheme registration needed). Ephemeral: no Box
/// cookies stay in Safari.
@MainActor
enum BoxAuth {
    enum Failure: Error { case cancelled, stateMismatch, noCode }
    private final class Anchor: NSObject, ASWebAuthenticationPresentationContextProviding {
        func presentationAnchor(for session: ASWebAuthenticationSession) -> ASPresentationAnchor {
            UIApplication.shared.connectedScenes.compactMap { ($0 as? UIWindowScene)?.keyWindow }.first ?? ASPresentationAnchor()
        }
    }
    private static let anchor = Anchor()

    static func signIn(app: BoxClient.App, redirectURI: String = BoxClient.redirectURI) async throws -> BoxClient.Tokens {
        let (verifier, challenge) = BoxClient.pkce()
        let state = "i." + SyncB64.encode(SyncCrypto.randomBytes(16))
        let url = BoxClient.authorizeURL(app: app, state: state, challenge: challenge, redirectURI: redirectURI)
        let callback: URL = try await withCheckedThrowingContinuation { cont in
            let s = ASWebAuthenticationSession(url: url, callbackURLScheme: "llmide-box") { u, e in
                if let u { cont.resume(returning: u) } else { cont.resume(throwing: (e as? ASWebAuthenticationSessionError)?.code == .canceledLogin ? Failure.cancelled : (e ?? Failure.noCode)) }
            }
            s.presentationContextProvider = anchor
            s.prefersEphemeralWebBrowserSession = true
            s.start()
        }
        let q = URLComponents(url: callback, resolvingAgainstBaseURL: false)?.queryItems ?? []
        guard q.first(where: { $0.name == "state" })?.value == state else { throw Failure.stateMismatch }
        if q.contains(where: { $0.name == "error" }) { throw Failure.cancelled }
        guard let code = q.first(where: { $0.name == "code" })?.value else { throw Failure.noCode }
        return try await BoxClient.exchange(code: code, verifier: verifier, app: app, redirectURI: redirectURI)
    }
}
```

## Not grounded (state these to the user; nothing in the plan depends on them silently)

1. **CCG on a free Box Individual account**: Box's CCG guide does not mention free or personal accounts. Not needed by this plan (D1 builds OAuth consent).
2. **PKCE**: Box's token reference documents no `code_verifier`; a 2026-09 community report shows Box's own Box Drive uses S256 PKCE. The plan sends PKCE and also the client secret. The live test proves only "accepted or ignored", not enforcement.
3. **`client_secret` on the refresh grant**: the token reference ties the secret to the code grant only; the plan sends it on refresh too (works either way with standard OAuth servers; confirmed by the live test).
4. **CORS**: checked with curl on 2026-11-06: preflights pass on `api.box.com` and `upload.box.com`, and the token endpoint returns `Access-Control-Allow-Origin: *`. **Unverified**: the per-app CORS answer on authenticated `api.box.com/2.0` calls from a listed origin, and whether the download host (`dl.boxcloud.com`) answers CORS after the browser follows `GET /files/:id/content`'s redirect. The live test reports both when `LLMIDE_SYNC_BOX_IT_ORIGIN` is set. If the download host refuses CORS, the web tier cannot read on Box and needs another read path (follow-up, not in this plan).
5. **Custom-scheme redirect URIs** (`llmide-box://oauth`): the current guide lists https and loopback only; Task 10 Step 1 checks it, with the https bounce as fallback.
6. **Loopback redirect on any port**: from Box's OAuth setup guide; exercised by the first real desktop connect.
7. **Version purge**: deleting a version moves it to trash; no documented permanent purge. Free plans keep no versions, so the issue only exists on paid accounts.
8. **Box terms** for automated, unattended clients and for inactive free accounts: not checked.
