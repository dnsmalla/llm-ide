# Archive

Specs (`docs/superpowers/specs/`) and plans (`docs/superpowers/plans/`) generated by the brainstorming/writing-plans skills move here once they no longer serve as active reference — the git history is preserved (`git mv`), so `git log --follow` still finds the full trail; this only keeps the working folders relevant to what's currently in flight or recently shipped.

## When to archive a spec/plan

Move a spec/plan pair here when **any** of these hold:

- **Shipped and stable.** The feature it describes has been merged and hasn't needed a follow-up spec in a while — it's pure historical record at that point.
- **Superseded.** A later spec on the same topic replaced its design; keep the earlier one for provenance, not as active reference.
- **Reverted.** The feature was built per the spec, then explicitly reverted — the spec still explains what was tried and why it didn't stick, which is worth keeping.

Don't archive a spec/plan whose implementation status is unconfirmed (can't tell from a quick `git log` check whether it shipped) — leave it active until someone can make that call, rather than guessing.

## History

The first 6 pairs here (2026-05-12 through 2026-05-19) were archived manually early in the project with no stated criteria.
