Security model

The cloud can’t read
what it never receives.

Your data lives on your desktop. Anything that leaves it is encrypted first. That is the core security decision.

Your storage holds

  • Encrypted snapshots only
  • File names, sizes and times

Desktop stores

  • Meetings, notes and chat
  • Source code and documents
  • Provider keys in OS keychain
  • Local project database

Loopback core

The local core is bound to 127.0.0.1 and is never a public API.

Encrypted sync

Snapshots are signed and encrypted on the desktop. Your storage provider sees only ciphertext.

Explicit actions

Tool calls and code edits go through approvals and protected paths.

Report a vulnerability

Email security@llm-ide.com with reproduction steps. Do not test against other users or their data.

Phones and browsers read encrypted sync from storage you own. Nothing readable leaves the desktop, and removing a device from the desktop rotates the keys. On the same network the web client can also pair live with a PIN.
