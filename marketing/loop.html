Agent workflow

A loop that
checks itself.

Loop is not one long prompt. It is a sequence of stages with checks, repair limits and a run record.

Plan the work

Choose a template or build stages. Each stage has a kind: shell command, skill, test, graph or regression sweep.

Act with limits

Stages run in order. A skill can edit code; a command can verify. Protected paths are enforced by the host.

Verify objectively

Tests, docs checks or a fault sweep decide whether the stage passed. A blocking failure stops or repairs; advisory findings are reported.
