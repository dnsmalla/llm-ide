Sign in with a passkey

Email identifies the account and a passkey signs in. In this preview no email verification is required. The cloud stores identity, sessions and device metadata.

  • No password
  • No meeting or code data
  • Passkey private key never leaves the device
Cloud identity

Work on your desktop

The local core opens the project database, captures meetings and runs AI with your credentials. It binds to loopback, not the internet.

  • Local SQLite + project files
  • Your Claude login / API key
  • Approvals and protected paths
Loopback only

Cross the boundary safely

A browser or phone is approved by the desktop. The relay carries encrypted envelopes; it cannot read your meetings, code or chats.

  • Desktop-controlled device list
  • No public core port
  • Revocable per device
No plaintext

Use the workspace anywhere

The approved browser or phone asks the desktop for answers and actions. The desktop remains the authority; the cloud remains blind.

  • Passkey sign-in
  • Desktop approval
  • Revoke at any time
Tiered access

Four steps to a project

1 · Create

Create an account with a passkey. No password, no email link in this preview.

2 · Open

Sign in to the desktop app and open the project folder.

3 · Connect

Capture a meeting, connect a source, or link the web app.

4 · Ask

Chat, review, plan and automate with the project in context.
