The unit of work

A project is a folder
with a memory.

Open a folder. LLM-IDE treats it as one workspace: its files, meetings, documents, issues, graph and AI context belong together.

What belongs in it

  • The source code or documents you already work on.
  • Meetings and notes captured while working on it.
  • Generated plans, documents, diagrams and graph data.
  • Issues, decisions and the context your agents need.

Everything is local. The account service never sees this folder.

Folders with a purpose

source/

Meetings, emails and documents that feed the Library.

code/

Imported or linked source; the code assistant and graph read it here.

llm-doc/

Plans and generated documents. Review them before sharing.

system/

Project metadata, graph JSON, memory and local database state.

Every feature is project-scoped.

Search, Chat, Issues, Graph, Doc Gen and Auto Tasks all read the active project. Change project and the context changes with it.
