Code Graph turns the project into a navigable map of symbols and dependencies, rendered locally.

What it answers

  • What calls this module?
  • What changes if I edit this file?
  • Where are the dense or isolated parts?
  • Which areas have no tests?

Generate the graph, choose a view, then inspect a node’s dependencies and metadata.

Generated locally

Modes

Switch between structure, dependency and change-oriented views without moving the project.

Node inspection

Read a node’s path, kind, community and connected edges. Jump to the related file.

Filters

Focus by node kind, community or search. The graph is weighted, not pruned, so dense areas remain readable.

Local cache

The graph lives under the project’s system/ memory. Regenerate when the code moves.
