Interactive guide

Start here

This guide walks from a fresh account to a working project. Tick each step as you go; your progress is stored only in this browser.

You can also take the interactive product tour first.

I understand that project data stays on my desktop.

Create your account

Open accounts.llm-ide.com, enter your email and display name, then create a passkey when the browser asks. There is no password.

  • The account is for identity and device linking.
  • It does not store your meetings, code, chats or AI keys.
  • Use the same passkey to sign in later.
My account is active and I have a passkey.

Sign in to the desktop app

The desktop app has its own local login. It is separate from the cloud account. Sign in to the local account, or create one on first run.

The local account unlocks this computer's workspace; the cloud account links phones and browsers later.

The desktop app is signed in.

Open a project

Choose File → Open Project and select the folder that holds your code, notes or work. LLM-IDE creates its local project folders and knowledge base on first open.

Use one project per body of work so search, chat and issues stay scoped.

I have opened a project.

Capture a meeting

Start a meeting in Google Meet, Microsoft Teams or Zoom and open the LLM-IDE capture surface. Captions become live notes; stopping the recording saves the transcript to this project.

  • Check the meeting title and platform.
  • Speak normally; captions are read from the platform.
  • Action items can become tracked issues.
I have captured or imported a meeting.

Use the Library

The Library is the project's hub: meetings, notes, documents, code and imported sources. Search across them, open a note, or attach a source to chat.

Try searching for a decision or a person's name, then open the matching note.

I found something in the Library.

Chat and code

Open Chat, choose a mode and ask a question about the project. For code changes, the assistant proposes edits; review the diff and approve or reject it.

Approvals are the boundary: nothing is applied to your working tree without your action.

I asked a project question and reviewed an approval.

Issues and Gantt

Turn action items into issues, then place them on the timeline. Issues carry status and ownership; Gantt shows sequence and schedule.

Use the board for what to do next and the timeline for when it happens.

I created or reviewed an issue on the timeline.

Graph and Doc Gen

Code Graph shows how the project is connected. Doc Gen turns sources into documents; Visual produces diagrams and images.

Start from a question like “what depends on this module?” rather than reading files one by one.

I opened the graph or generated a document.

Loop and Auto Tasks

Loop runs a staged workflow with verification and repair. Auto Tasks run repeatable checks on a schedule; custom Review tasks revert their edits after reporting.

Start with a small review task and read its log before scheduling it.

I inspected a loop or auto-task run.

Connect the web app

Open llm-ide.com/app. The host address is prefilled with the desktop host URL. In the desktop app open Settings → Host API pairing, show the PIN, enter it on the web page and pair.

The current web link is a temporary direct host connection. The encrypted relay is in development.

I paired the web app with the desktop.

Troubleshooting

  • No passkey prompt: use Safari/Chrome on a device with iCloud Keychain or Windows Hello; avoid in-app browsers.
  • Web app cannot pair: the desktop must be running, signed in, and showing the pairing PIN; check the host URL.
  • Empty project: open a project first; the Library and Chat are project-scoped.
  • AI unavailable: connect your Claude login or API key in Settings.
